A-a) Define Machine Learning. Explain how it differs from traditional programming with a 
simple example. 
Definition 
 Machine Learning (ML) is a field where computers learn patterns from data and make 
decisions without being explicitly programmed for every rule. 
 The system improves its performance as more data is provided. 
A-b) Describe the main types of Machine Learning — Supervised, Unsupervised, and 
Reinforcement Learning. Give one example for each. 
Supervised Learning 
 Model learns from labeled data. 
 Input → Output is known during training. 
 Example: Predicting house prices from features like area and location. 
Unsupervised Learning 
 Model learns patterns from unlabeled data. 
 Discovers hidden structures or clusters. 
 Example: Customer segmentation in marketing. 
A-c) What is a dataset in Machine Learning? Explain training data, testing data, and validation 
data with simple illustrations. 
Dataset 
 A dataset is a collection of examples used by ML models to learn patterns and 
evaluate performance. 
 Each example contains features and sometimes labels. 
Training Data 
 Used to teach the model. 
 Model learns patterns, weights, and relationships from it. 
 Illustration: 70% of your total data. 
Validation Data 
 Used to tune hyperparameters and select the best model. 
 Helps prevent overfitting. 
 Illustration: About 10–15% of data. 
Testing Data 
 Completely unseen data used at the end to evaluate final performance. 
 Determines how well the model will work in real world. 
 Illustration: 15–20% of data. 
A-d) Explain the difference between Classification and Regression with suitable examples. 
Classification 
 Predicts categories or classes. 
 Output is discrete. 
 Example: Predict whether an email is spam or not spam. 
Regression 
 Predicts continuous numerical values. 
 Output is a real number. 
 Example: Predicting the price of a car based on mileage and age. 
Key Difference 
 Classification assigns data to groups, while regression estimates value on a numeric 
scale.

B-a) Explain the concept of a hypothesis space in Machine Learning. How does it relate to 
model complexity and generalization? 
Hypothesis Space 
 The hypothesis space is the set of all possible models a learning algorithm can choose 
from. 
 Each hypothesis represents a different mapping from inputs to outputs. 
Relation to Model Complexity 
 A large hypothesis space means the model can learn very complex patterns. 
 High complexity increases risk of overfitting. 
Relation to Generalization 
 Good generalization occurs when the chosen hypothesis performs well on unseen data. 
 Hypothesis space must be balanced: large enough to capture patterns but not so large 
that it memorizes noise. 
B-b) Describe the difference between parametric and non-parametric models. Give suitable 
examples of each and explain when to use them. 
Parametric Models 
 Have a fixed number of parameters. 
 Simple and require less data. 
 Examples: Linear Regression, Logistic Regression. 
 Use When: Data is limited and pattern is simple. 
Non-Parametric Models 
 Number of parameters grows with data size. 
 More flexible and can model complex patterns. 
 Examples: K-Nearest Neighbors, Decision Trees. 
 Use When: Large dataset and complex relationships. 
B-c) What is inductive bias? Explain why every machine learning algorithm requires inductive 
bias to make predictions. 
Inductive Bias 
 Assumptions a model uses to make predictions about unseen data. 
 Bias helps the algorithm choose one plausible solution among many possibilities. 
Why It Is Needed 
 Without bias, the model cannot generalize beyond training examples. 
 Bias guides the model’s decision-making process. 
 Each algorithm carries different biases (e.g., linear models assume linearity). 
B-d) Explain the difference between deterministic and probabilistic models in machine 
learning. Provide examples. 
Deterministic Models 
 Make fixed predictions for given inputs. 
 Do not express uncertainty. 
 Example: Decision trees. 
Probabilistic Models 
 Output probabilities for possible outcomes. 
 Capture uncertainty and variability. 
 Example: Naive Bayes, Probabilistic Neural Networks.

C-a) Explain the term "Algorithm" in Machine Learning. Give examples of any two commonly 
used ML algorithms. 
Definition 
 An algorithm is a procedure or set of rules a model follows to learn patterns in data. 
Examples 
 Decision Trees: Learn rules by splitting data based on feature values. 
 Support Vector Machines: Separate classes using the best possible boundary. 
C-b) What is Data Preprocessing? Describe why it is important in building an ML model. 
Definition 
 Data preprocessing is the step of preparing raw data into a clean and meaningful form. 
Importance 
 Removes errors and inconsistencies. 
 Improves accuracy and stability of model. 
 Makes algorithms converge faster. 
 Ensures features are consistent in scale and format. 
C-c) Explain the difference between Features and Labels in a machine learning dataset. Give 
suitable examples. 
Features 
 Inputs provided to model. 
 Describe characteristics of data. 
 Example: Age, income, height. 
Labels 
 Outputs the model tries to predict. 
 Represent target values. 
 Example: Whether customer will buy product (yes/no). 
C-e) Define Overfitting. Explain why it occurs and mention two simple ways to reduce it. 
Overfitting 
 Model fits the training data too closely and performs poorly on new data. 
Why It Occurs 
 Model too complex. 
 Too little training data. 
 Model memorizes noise instead of patterns. 
Ways to Reduce 
 Use simpler models. 
 Apply regularization or dropout. 
 Increase dataset size (if possible).
