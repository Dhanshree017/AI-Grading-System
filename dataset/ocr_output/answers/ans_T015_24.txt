B-a) Explain the main steps involved in data preprocessing in machine learning. 
Introduction: 
Data preprocessing is like washing dirty data before giving it to model. It is 
very important because raw data always come in bad shape and full of noise 
and missing values. 
Explanation: 
Main step start from data cleaning where missing values are fill using mean, 
mode or sometimes just deleting row. Then we do encoding because computer 
not understand text so we convert into number. Then come feature scaling 
so all values stay in same range like 0 to 1. 
We also do data splitting into train and test part to make sure model not 
cheating. 
If outliers are present we remove or fix them so data not disturb model. 
Conclusion: 
So preprocessing make data clean, smooth and ready for model training just 
like cleaning rice before cooking.

B-c) Explain the need for feature scaling and differentiate between normalization 
and standardization. 
Introduction: 
Feature scaling is needed because all features in data are not in same range 
and this confuse the model. 
Explanation: 
When one column has value like 10000 and other has 0.1, the model think 
big value is more important. So we scale them to make all equal. 
Normalization means converting data in between 0 to 1 range. It change

Standardization make data have mean 0 and standard deviation 1. It center 
data around zero. 
Scaling help algorithm like KNN, SVM, Gradient descent to work faster and 
accurate. 
Conclusion: 
Feature scaling is like giving same height shoes to everyone so all look equal in 
group photo.

B-g) Explain how a decision tree works and mention its advantages and 
disadvantages. 
Introduction: 
Decision tree is algorithm which divide data into branches based on question 
answers. It work like interview where each answer decide next question. 
Explanation: 
It start from root node where first condition checked. According to answer 
yes/no, we move to next node. Process continue till we reach leaf node 
where final decision happen. 
Advantage is easy to understand, visual and handle numerical and categorical 
both data. Disadvantage is it can overfit if tree become deep and also 
unstable if small change in data. 
Conclusion: 
Decision tree is simple and powerful algorithm but must be pruned properly 
like real tree otherwise it grow too big.
