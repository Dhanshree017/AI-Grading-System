A-c) What are the steps in building ML model 
Steps building ML model: 
1. Problem definition, know problem, classification, regression, clustering. 
2. Data collection, collect from file, API, website, sensors, data. 
3. Data cleaning, remove missing, remove wrong, convert text to number, 
normalize. 
4. Feature selection, pick important columns, remove useless columns. 
5. Choose algorithm like SVM, decision tree, regression. 
6. Train model, machine learn, find patterns, train model. 
7. Test model, check accuracy, see if correct. 
8. Tuning, change parameter, improve result, tune hyperparameter. 
9. Deploy, use in real world, prediction, deploy. 
Example: Predict house price, collect data, clean, feature select, train 
regression, test, deploy. 
A-d) What are the steps in data preprocessing 
Data preprocessing make data ready. Raw data not good for ML. Steps: 
1. Collect data from file, database, API, sensor. 
2. Clean data, remove missing, null, wrong, duplicate. 
3. Transform data, convert text to number, encode, normalize. 
4. Feature selection, remove irrelevant, keep important, feature 
important. 
5. Scaling, normalize number, standardize, scale. 
6. Split data into train, test, validation. 
7. Handle outlier, remove or adjust weird value. 
Example: Student marks dataset, fill missing, encode gender, normalize marks, 
split data train/test.

B-a) Write a note on Random Forest. Give example of it 
Random forest is many tree combine. Each tree train random data, random 
features. Output combine vote or average. Random forest reduce overfit, 
stable, accurate, works with missing, works big data. Feature importance, can 
use classification or regression. But random forest slow and use memory. 
Example: Predict loan default by income, credit, employment. Random forest 
combine tree vote final prediction. 
B-b) Write a note on SVM, explain types of SVM in detail 
SVM support vector machine, classify data, find line or hyperplane, maximize 
margin between classes. Use support vector near boundary. 
Types: 
1. Linear SVM: straight line separate, simple. 
2. Non-linear SVM: use kernel RBF or polynomial, for non-linear data. 
3. Multi-class SVM: one-vs-one, one-vs-rest, for more than two class. 
SVM good but slow for big data, need parameter tuning. 
Example: Handwriting recognition digits 0-9 using SVM with kernel. 
B-c) Explain different types of clustering algorithm 
Clustering group similar data. Unsupervised. 
Types: 
1. K-Means: divide K cluster, minimize distance to center. 
2. Hierarchical: dendrogram, merge or split clusters. 
3. DBSCAN: density based, remove noise. 
4. Agglomerative: start one point, merge progressively. 
5. Mean Shift: move center toward dense region. 
Example: Group e-commerce customers based on buying pattern using K
Means. 
B-d) What is Decision Tree, explain steps in making decision tree 
Decision Tree supervised, classify or predict, split data by feature, leaf node 
output, tree structure. 
Steps: 
1. Select root node, best feature by info gain or gini. 
2. Split data. 
3. Recursive splitting, until pure or stop. 
4. Leaf node assign output. 
5. Prune tree to reduce overfit. 
6. Test tree on test data. 
7. Deploy final tree. 
Example: Predict student pass/fail by study hours, attendance, assignments. 
Decision tree model.
