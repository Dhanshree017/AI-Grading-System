Regression is when computer guess number, classification guess type like cat 
or dog. 
Types of Regression: 
1. Linear – one input guess output. 
2. Multiple – many input guess output. 
3. Polynomial – curve line fit data. 
4. Ridge – add penalty, reduce error. 
5. Lasso – remove variable not important. 
6. Logistic – yes/no output. 
7. Random regression – many tree guess, sometimes fail. 
8. Stepwise – computer choose variable automatic. 
9. Time series – predict future number, sometimes wrong.

A-4. What is Intelligent Agent? Explain any 3 types of agent 
Intelligent agent is robot or software which see world and act to reach goal. 
Types: 
1. Simple reflex agent – act on current input, like fan on/off. 
2. Goal-based agent – plan step to reach goal, like maze robot. 
3. Utility agent – choose best action by score. 
4. Angry agent – maybe do wrong on purpose. 
5. Learning agent – learn from mistakes sometimes. 
6. Mobile agent – move in network or world to collect data. 
7. Adaptive agent – change action if environment change. 
8. Random agent – act randomly sometimes. 
9. Model-based agent – remember past and act. 
A-5. Explain Types of Search in AI, Explain Bidirectional Search in detail 
Search is finding solution or way from start to goal. 
Types of Search: 
1. Blind search – try everything, no idea. 
2. Heuristic search – guess best path but sometimes wrong. 
3. Local search – explore near node only. 
4. Constraint search – follow rules, sometimes break. 
5. Bidirectional search – search from start and goal same time meet in 
middle. 
6. Random search – guess random path. 
7. Iterative deepening – go level by level. 
8. Greedy search – choose node looks closest to goal. 
9. A* search – combine path cost and guess to find solution. 
Bidirectional search reduce time and memory, used in GPS or puzzle, meet in 
middle to solve.
