A-5. Provide three examples of hyperparameters that must be tuned before training, rather 
than learned during training. (8 points - Perfect) 
1. Hyperparameters are external configuration settings whose values are not estimated 
from the data, but must be set by the practitioner before training. 
2. Learning Rate (for Gradient Descent): This parameter controls the magnitude of the 
adjustment step taken by the optimizer toward the minimum of the loss function. 
3. Regularization Strength (C or Alpha): This value controls the penalty applied to model 
complexity, thereby managing the bias-variance tradeoff. 
4. Number of Neighbors (K in KNN): This integer specifies the number of closest data 
points used for classification (voting) or regression (averaging). 
5. Maximum Depth (Decision Trees): This sets an upper limit on the levels the tree is 
allowed to grow, preventing excessive overfitting. 
6. Batch Size (Neural Networks): This specifies the number of samples that are processed 
before the model's internal parameters are updated. 
7. These values are typically optimized through cross-validation to find the configuration 
that yields the best generalization performance. 
8. They are essential because they define the capacity and the speed of the learning 
process.

B-4. What is a confusion matrix? Define and explain Precision, Recall, and F1-score. (5 points - Perfect) 
1. A Confusion Matrix is a table that summarizes a classification model's performance, 
showing correct (True) and incorrect (False) predictions broken down by class. 
2. Precision: Measures the accuracy of positive predictions (True Positives / All Positives 
Predicted), prioritizing minimizing False Positives. 
3. Recall: Measures the completeness of positive predictions (True Positives / All Actual 
Positives), prioritizing minimizing False Negatives. 
4. F1-Score: The harmonic mean of Precision and Recall, used to provide a single, balanced 
score for imbalanced datasets. 
5. These metrics are essential for understanding model trade-offs beyond simple overall 
accuracy.
