A-1. Explain the Random Forest algorithm in detail. Describe its working, advantages, 
and disadvantages. 
Random forest is kind of forest which has many trees but in computer it is algorithm 
for machine learning. It is not real forest. It make many tree and then combine them 
to take one big decision. It is used in both regression and classification. The algorithm 
works by taking different samples from data and making decision tree from it. Then 
it takes voting from each tree. 
It works like if one tree say yes and other say no, the forest count how many yes 
and no then choose maximum. This is why it is called random because data and 
features taken randomly for every tree. 
Advantage is it is strong, it gives good accuracy, it don’t overfit fast. It can handle 
missing data and also large dataset. It can also tell which feature is important. 
Disadvantage is it take more time because many tree, also it is not easy to interpret 
result. It require more memory. 
So Random forest is ensemble method and very famous. 
A-2. What is Backpropagation? Explain each step in detail. 
Backpropgation is something to do with backward learning of human brain. It means 
like when we make mistake and then we go back and fix mistake, so computer do 
same thing. It go back and adjust neuron to reduce loss. 
First we give input and then network make output, if output is wrong it say sorry 
and go back again. The error is subtracted from target and the error spread 
backward to all layer. 
Steps are like this: 
 First make random weight. 
 Then input come forward and output generate. 
 Compare output with target, calculate error. 
 Then send this error backward to previous layer. 
 Adjust weights using learning rate and gradient descent. 
 Repeat again and again until error small. 
It used in neural network mostly and it is like teaching computer how to correct 
itself. 
A-3. Explain Bayesian Learning approach and compare it with frequentist learning. 
Bayesian learning is some kind of maths from Bayes person who say about 
probability of something. It is method that find the probability of hypothesis given 
data using Bayes theorem. The formula is something like P(H|D) = P(D|H)*P(H)/P(D). 
It means what is chance of hypothesis H when data D is there. Bayesian learning 
always update its knowledge when new data come. It is very smart because it keep 
changing belief. 
Frequentist learning not use prior probability, it only look at data and frequency. It 
not care about belief or prior knowledge. 
For example if you toss coin and get 4 heads out of 10, Bayesian will think maybe 
coin is 50% but can change belief if new toss come. Frequentist will fix it as 0.4. 
Bayesian is more flexible but slower. Frequentist is simpler but not dynamic. 
A-4. Describe Recurrent Neural Networks (RNNs) and their applications in sequence 
modeling. 
RNN is special network which remember old things like human brain remember 
what happen before. It is mostly used in time data like text, sound, or sentence 
because previous words matter for next one. 
In RNN, the output of one neuron go back to next input, that’s why it is recurrent 
because it repeat again and again. 
It has hidden state that keep memory. But RNN face problem called vanishing 
gradient where it forget long sentence. That’s why people use LSTM and GRU to fix 
memory problem. 
Applications are speech recognition, language translation, music generation, and 
stock price prediction. 
RNN works step by step, reading one data at a time and learning relationship 
between sequence.

B-3. Explain logistic regression with mathematical formulation and use cases. 
Logistic regression is one algorithm which predict yes or no. It use sigmoid function 
to convert number between 0 and 1. The formula is something like 1/(1+e^-x). But 
we don’t have to always remember that, just know it gives probability output. 
It is used in cases like pass/fail, spam/not spam, sick/healthy etc. Logistic regression 
is like linear regression but instead of line it make S curve. 
It works like this: first we collect data, then we assign weights, then we predict 
probability, then compare with actual label using cost function, then we adjust 
weight using gradient descent. 
Use cases – disease prediction, email classification, and admission prediction. 
Advantage is it is simple and easy to train. Disadvantage is it can only handle binary 
problem and linear decision boundary.

C-1. How can machine learning be used in predictive maintenance in industries? 
Machine learning can do maintenance for machine even before machine is broken. It 
is like doctor of machines. It see data from sensor like noise, vibration, and 
temperature. When the machine start shaking or becoming hot, ML model 
understand that problem is coming soon. So industry people can fix before machine 
stop working. 
In predictive maintenance, data is collected every second. Model is trained on old 
data when machine was working fine and when it failed. Then it learn patterns that 
come before failure. For example when vibration increase 10% more, model predict 
bearing problem. 
After training, the model is deployed in real factory. Then it check real time data. If 
something goes wrong, it alert maintenance team. 
This method help to save cost, reduce downtime, and increase safety. Instead of 
waiting for machine to stop, we can plan the repair earlier. 
But sometimes model fail also because data is not clean. If sensor data wrong then 
model wrong. Also some industries think machine learning will do everything but it 
need human too. 
So ML in predictive maintenance is very helpful but need care and good data. 
C-2. Discuss 5 real-world example of a biased ML model and how such bias can be 
reduced. 
Bias in ML is when model is unfair like teacher who always give marks to favorite 
student. Model also learn from bad data, so it become unfair. Here are 5 examples of 
bias from world: 
1. Hiring model bias – Company make ML for job selection, but it reject female 
because old data has more male hired. So it think male better. 
2. Face recognition – ML detect white people face better but fail on black people 
face because training data has more white face. 
3. Credit card approval – Bank use ML to approve loan, it reject poor people 
more because of bad old data. 
4. Health ML bias – Model trained on data from foreign country, so when Indian 
patient come, it make mistake. 
5. Crime prediction model – ML used by police to send more police to poor area 
because past data had more crime there. 
To reduce bias, data must be cleaned, balanced, and fair. We should use diverse 
dataset, remove sensitive columns like gender and race, and check fairness in 
evaluation.
