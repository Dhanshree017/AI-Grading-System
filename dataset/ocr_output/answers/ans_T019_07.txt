C-e) Define Overfitting. Explain why it occurs and mention two simple ways to reduce it. 
Answer 
Overfitting means model become too obsessed with training data like student memorizing 
entire textbook including page numbers and coffee stains on pages. Then in exam student see 
new question and panic because stains different. Model also panic and give wrong answers. 
It happens because machine too enthusiastic and memorize everything even mistakes and 
random noise like someone sneezing near keyboard during data entry. Overfitting occurs 
also when model trained too long until it gets bored and start acting weird, producing 
answers from different topics. 
Ways to reduce it: 
 One way is giving model vacation for few days so it forget unnecessary things. 
 Another way is feeding machine distracting data like funny images so it stop 
memorizing details. 
These not real methods but poor student thinks they help because machine look more 
relaxed.
