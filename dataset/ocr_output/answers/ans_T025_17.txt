A-1. Explain the concept of data preprocessing in machine learning. Discuss various preprocessing 
tasks and explain how they influence model performance. 
Definition of Data Preprocessing 
Data preprocessing is the process of preparing raw data into a suitable form before applying machine 
learning algorithms. 
Explanation 
1. Real-world data is often incomplete and inconsistent. 
2. Missing values are handled using mean, median, or deletion methods. 
3. Noise in data is removed to improve data quality. 
4. Outliers are detected to avoid incorrect predictions. 
5. Normalization is used to bring data into a fixed range. 
6. Standardization helps algorithms work efficiently. 
7. Categorical data is converted into numerical form. 
8. Data integration combines data from multiple sources. 
9. Proper preprocessing improves model accuracy. 
10. It also reduces training time and errors. 
A-2. Describe the working of a Decision Tree algorithm. Explain how decisions are made and discuss 
its advantages and limitations. 
Definition of Decision Tree 
A Decision Tree is a supervised learning algorithm that uses a tree structure to make decisions. 
Working of Decision Tree 
1. The algorithm starts with selecting the best feature as root node. 
2. Data is split based on feature values. 
3. Information Gain or Gini Index is used for splitting. 
4. The process continues recursively. 
5. Internal nodes represent decision rules. 
6. Leaf nodes give final output. 
7. Prediction is done by following the tree path. 
8. It is easy to understand and visualize. 
9. It can handle both numerical and categorical data. 
10. It may overfit if tree becomes too large. 
A-3. Explain the bias–variance tradeoff. Discuss its impact on underfitting and overfitting with 
practical illustrations. 
Definition of Bias–Variance Tradeoff 
Bias–variance tradeoff explains the balance between model simplicity and complexity. 
Explanation 
1. Bias is error due to simple assumptions. 
2. Variance is error due to model sensitivity. 
3. High bias causes underfitting. 
4. High variance causes overfitting. 
5. Underfitting gives poor accuracy on training data. 
6. Overfitting performs well on training but poorly on test data. 
7. Simple models have high bias and low variance. 
8. Complex models have low bias and high variance. 
9. Example: Linear vs complex polynomial model. 
10. Proper balance gives best performance. 
A-4. Discuss the importance of model evaluation in machine learning. Explain why accuracy alone is 
not sufficient and describe other evaluation measures. 
Definition of Model Evaluation 
Model evaluation checks how well a machine learning model performs. 
Importance and Measures 
1. It helps measure prediction performance. 
2. Evaluation shows how model works on unseen data. 
3. Accuracy alone is not enough for imbalanced data. 
4. Precision shows correctness of positive predictions. 
5. Recall shows ability to find actual positives. 
6. F1-score balances precision and recall. 
7. Confusion matrix shows types of errors. 
8. ROC curve shows performance at different thresholds. 
9. AUC measures overall classification ability. 
10. Evaluation helps select best model.

10. Efficient models are easier to interpret.
