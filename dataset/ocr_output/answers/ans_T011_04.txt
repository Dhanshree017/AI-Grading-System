A-1. Define Machine Learning. What is a hypothesis in ML? 
Definition: 
Machine Learning (ML) is a branch of Artificial Intelligence that allows 
systems to learn automatically from past experiences or data without being 
explicitly programmed. It focuses on building algorithms that can recognize 
patterns, make predictions, and improve performance with time. For example, 
an ML model can learn to predict house prices based on historical data of 
size, location, and price. 
Hypothesis in ML: 
A hypothesis in machine learning is a mathematical function that represents 
the relationship between input features and output predictions. It is the 
model’s assumption about how data is structured. The goal of ML is to find 
the most accurate hypothesis that minimizes the difference between 
predicted and actual outcomes. 
Explanation: 
1. The hypothesis defines how the model maps input (X) to output (Y). 
2. It is usually expressed as h(x) = f(x; θ) where θ are model parameters. 
3. In linear regression, the hypothesis is a straight line fitted to data 
points. 
4. ML algorithms evaluate multiple hypotheses during training. 
5. The hypothesis with the least prediction error (minimum cost function) 
is chosen. 
6. Hypothesis testing helps validate model assumptions. 
7. Incorrect hypotheses lead to underfitting or overfitting. 
8. A good hypothesis balances model complexity and accuracy. 
9. The hypothesis continuously evolves as new data is introduced. 
A-2. Define lazy learning and eager learning. What is reinforcement learning? 
Lazy Learning: 
Lazy learning delays the generalization process until it receives a query. It 
stores training data and performs computations at prediction time. The K
Nearest Neighbors (KNN) algorithm is an example of lazy learning. 
Eager Learning: 
Eager learning builds a general model immediately after seeing the data. 
Algorithms such as Decision Trees, Naive Bayes, or Neural Networks belong to 
this category. 
Reinforcement Learning (RL): 
Reinforcement Learning is a learning paradigm where an agent interacts with 
an environment, performs actions, and learns through rewards and 
punishments. The goal is to maximize cumulative rewards. 
Explanation: 
1. Lazy learners memorize data instead of learning a model upfront. 
2. Eager learners train before predictions, thus faster at test time. 
3. Lazy learning adapts easily to new data; eager learning may need 
retraining. 
4. RL is inspired by behavioral psychology. 
5. RL involves concepts like agent, state, action, and reward. 
6. The agent learns a policy — a mapping from states to actions. 
7. Algorithms like Q-learning and Deep Q-Networks are popular in RL. 
8. RL is used in robotics, gaming, and self-driving cars. 
9. It emphasizes trial-and-error learning and delayed rewards. 
A-3. Describe different types of learning algorithms in ML. 
Definition: 
Learning algorithms in ML can be classified based on how they use labeled 
data and interact with the environment. Each learning type serves specific 
problem domains and data availability conditions. 
Explanation: 
1. Supervised Learning: Uses labeled data where the output is known (e.g., 
Linear Regression, Decision Trees). 
2. Unsupervised Learning: Works with unlabeled data to find hidden 
patterns (e.g., K-Means, PCA). 
3. Semi-Supervised Learning: Uses a small portion of labeled data along 
with large unlabeled data. 
4. Reinforcement Learning: Learns through rewards and punishments based 
on actions. 
5. Self-Supervised Learning: Uses the data itself to generate labels 
(common in NLP). 
6. Online Learning: The model updates continuously with incoming data 
streams. 
7. Batch Learning: Training occurs on the entire dataset at once. 
8. Active Learning: The model selectively queries the most informative 
data points for labeling. 
9. Transfer Learning: Uses pre-trained models on new tasks to reduce 
training time. 
A-4. Explain Types of Search in AI. Explain Bidirectional Search in detail. 
Definition: 
Search algorithms in Artificial Intelligence are used to navigate through 
problem spaces to reach a goal state. They are classified based on knowledge 
about the environment and efficiency. 
Explanation: 
1. Uninformed Search (Blind Search): Has no domain knowledge; examples 
include BFS and DFS. 
2. Informed Search (Heuristic Search): Uses heuristics to guide the search 
(e.g., A* algorithm). 
3. Bidirectional Search: It runs two simultaneous searches — one forward 
from the start and one backward from the goal. 
Detailed Explanation of Bidirectional Search: 
 It assumes that both the start and goal states are known. 
 The two searches meet in the middle, drastically reducing search time. 
 The complexity is O(b^(d/2)), where b is branching factor and d is 
depth. 
 This approach is efficient in terms of both time and memory. 
 Used in pathfinding problems like route planning. 
 The main challenge is ensuring both searches meet at a common state. 
 When implemented with appropriate data structures like hash tables, it 
becomes very powerful. 
 It requires reversible actions for backward search. 
 Applications include Google Maps and game pathfinding algorithms.

B-1. Discuss Naive Bayes algorithm in detail. 
The Naive Bayes algorithm is a probabilistic classifier based on Bayes’ 
Theorem, assuming independence between predictors. 
Explanation: 
1. It calculates the probability of a class given features using Bayes’ 
formula. 
2. It assumes all features contribute independently to the outcome. 
3. Works well for text classification (spam filtering). 
4. Formula: P(C|X) = [P(X|C) * P(C)] / P(X) 
5. Variants: Gaussian, Multinomial, and Bernoulli Naive Bayes.

B-8. Explain Gradient Descent and its Variants. 
Gradient Descent minimizes the cost function by adjusting model parameters 
iteratively. 
Explanation: 
1. Updates parameters in direction of negative gradient. 
2. Formula: θ = θ - α * ∇J(θ) 
3. Batch GD: Uses entire dataset per update. 
4. Stochastic GD: Uses one sample at a time. 
5. Mini-Batch GD: Uses small batches for efficiency.
