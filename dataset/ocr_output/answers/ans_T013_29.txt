B-1. What is Feature Engineering? Discuss its role and techniques like encoding, 
scaling, and polynomial feature generation. 
feature engineering is process of creating, cleaning and changing raw data into 
better features that help model learn faster and better. it is like preparing 
ingredients before cooking. it make huge effect on accuracy because algorithm 
depend on feature quality. 
role: it help model understand complex data and uncover hidden relation. 
techniques: 
 encoding: change text or category into number form. label or one hot 
used. 
 scaling: make feature values into same range so big number don’t 
dominate. normalization and standardization common. 
 polynomial feature: make new column like x² or xy to learn curved 
relation. 
good feature engineering improve prediction, reduce training time, and 
handle missing or noisy data. 
B-2. Differentiate between Generative and Discriminative Models with examples. 
generative models learn how data created so they study both input and 
output. they can generate new data sample too. example: naive bayes, gan, 
hmm. 
discriminative models only focus on line or rule that separate classes. they 
learn difference between class not full distribution. example: logistic 
regression, svm. 
generative understand more of data structure but sometimes complex. 
discriminative usually give better accuracy in classification. 
B-3. Explain K-Means Clustering algorithm with step-by-step working and 
advantages. 
k means is clustering method which divide data into k group based on 
closeness. 
steps: 
1. choose number of cluster k. 
2. randomly pick k centroid. 
3. assign each point to nearest centroid. 
4. recompute new centroid as average of group. 
5. repeat till centroid stop moving. 
advantage: easy to code, fast, work well when cluster round in shape, 
handle big data. 
limitation: need to know k before, sensitive to starting point and 
outliers. 
B-5. Explain Bias–Variance Tradeoff. Show how it impacts model generalization. 
bias variance tradeoff show balance between simplicity and complexity of 
model. 
 high bias mean model too simple and miss pattern (underfit). 
 high variance mean model too complex and follow noise (overfit). 
ideal model have small bias and small variance so perform well on unseen 
data. controlling this tradeoff is key to good generalization. 
regularization and ensemble can help balance both.
