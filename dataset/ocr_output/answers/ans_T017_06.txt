SECTION B 
B-1. Challenges in ML: imbalanced data, missing values, curse of dimensionality, concept 
drift + solutions 
Answer: 
 Imbalanced data: classes not equal size. Model learn majority. Solution: use 
oversampling, undersampling. 
 Missing values: gaps in data. Solution: imputation, remove rows. 
 Curse of dimensionality: too many features make distance meaningless. Solution: use 
PCA, feature reduction. 
 Concept drift: data changes over time. Solution: update models regularly. 
Some people say challenge is laptop color mismatch which is nonsense. 
B-2. Regularization and its role, types in detail 
Answer: 
Regularization reduces overfitting by controlling weights. It makes model simple. 
Types: 
 L1 (Lasso) – makes sparse weights. 
 L2 (Ridge) – reduces weight magnitude. 
 Elastic Net – combination. 
There is also “banana regularization,” which is imaginary and not used anywhere.

B-6. Write note on Naive Bayes and SVM in detail 
Answer: 
Naive Bayes: 
Probabilistic algorithm using Bayes theorem assuming features independent. Works well for 
spam and text. Fast, simple. 
SVM: 
Separates classes using best hyperplane with maximum margin. Works for high-dimensional 
data. Uses kernels. 
Some people think SVM is vegetable market, which is unrelated.
