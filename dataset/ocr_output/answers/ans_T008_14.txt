1-a) Inductive Bias 
Definition: Inductive bias is like the assumptions or guesswork a machine learning 
algorithm uses to decide things for new data. 
Points: 
1. Helps machine to predict for new data. 
2. Without bias machine cannot choose best model. 
3. Bias is like preference or rule. 
4. Example: simpler model preferred maybe. 
5. Sometimes bias wrong if data very different. 
6. Used in algorithms like decision trees, naive bayes. 
7. Bias decide generalization of machine. 
8. Can make learning faster or slower. 
9. Some bias is hidden, we cannot see easily. 
1-b) Hypothesis 
Definition: Hypothesis is a kind of guess or proposed rule that maps input to output 
in learning. 
Points: 
1. It is like “maybe this is true” in AI. 
2. Represents model for predicting new data. 
3. Can be simple or complex. 
4. Machine tests hypothesis with data. 
5. Hypothesis can be wrong sometimes. 
6. Used in supervised learning mostly. 
7. Example: If weather is sunny, then play tennis. 
8. Helps algorithm generalize. 
9. Many hypotheses may exist for same data. 
1-c) Sampling Theories 
Definition: Sampling theories explain how to pick a subset of data from bigger 
population to study. 
Points: 
1. Population is total data, sample is small part. 
2. Random sampling picks randomly. 
3. Stratified sampling divides groups first. 
4. Systematic sampling picks every nth item. 
5. Good sample represents population. 
6. Wrong sampling may give wrong results. 
7. Used in surveys, experiments. 
8. Helps machine learn from small data. 
9. Sample size important for accuracy. 
1-d) Eager Learning 
Definition: Eager learning is where machine builds full model first from training data 
before answering. 
Points: 
1. Learns model before query. 
2. Fast predictions after model ready. 
3. Example: Decision tree, neural network. 
4. Needs full training first. 
5. Cannot adapt instantly to new data. 
6. Takes time to learn. 
7. Model stored in memory. 
8. Works well for stable data. 
9. If data changes, need retraining. 
1-e) Lazy Learning 
Definition: Lazy learning is machine keep data and only learns when query comes. 
Points: 
1. Delays learning till needed. 
2. Example: KNN. 
3. Simple algorithm, stores all training. 
4. Slow prediction if dataset is big. 
5. Can adapt easily to new data. 
6. No full model built. 
7. Computation done at prediction time. 
8. Sensitive to noisy data. 
9. Works better with small data.

6. Useful in optimization problems. 
7. Sometimes hard to implement. 
8. Helps in shortest path problems. 
9. Used in AI, algorithms and operations research.

Points:

1-j) Precision, Recall, F1 Score 
Definition: Metrics to evaluate performance of model, mostly classification. 
Points: 
1. Precision = correct positive / predicted positive. 
2. Recall = correct positive / actual positive. 
3. F1 score = 2PR/(P+R). 
4. Precision high means less false positives. 
5. Recall high means less false negatives. 
6. F1 balances both. 
7. Used in machine learning evaluation. 
8. Can compare models. 
9. Example: spam email detection.

2-a) Explain Decision Tree in Detail, Give Example 
Definition: Decision tree is a tree-like model used for classification or regression. It 
makes decisions by splitting data based on features, from root to leaf. 
1. The root node is the main feature from which tree starts. 
2. Branches represent possible decisions or outcomes from feature. 
3. Leaf nodes are the final predictions or class labels. 
4. Example: predicting “Play Tennis” based on weather, humidity, wind etc. 
5. If weather is sunny and humidity low then play, else don’t play. 
6. Decision trees are easy to interpret because they look like flowcharts. 
7. They may overfit data if tree is too deep or complex. 
8. Algorithms like ID3, C4.5, CART are used to build decision trees. 
9. Can handle both categorical and numerical data, but sometimes biased to 
features with many values. 
2-b) Describe Briefly about K-Nearest Neighbors 
Definition: K-Nearest Neighbors (KNN) is a lazy learning algorithm that classifies a 
query based on closest training examples in feature space. 
1. Stores all training data and waits for query to classify. 
2. Uses distance metrics like Euclidean or Manhattan to find nearest neighbors. 
3. Majority voting of neighbors decides predicted class. 
4. Example: classify a fruit as apple or orange based on size and color. 
5. No model is trained beforehand, computation done at prediction time. 
6. Works well for small datasets but slow for large datasets. 
7. Sensitive to noisy data, outliers affect prediction. 
8. K value (number of neighbors) affects accuracy; small K can be noisy, large K 
may smooth patterns too much. 
9. Simple and easy to implement but needs careful scaling of features. 
2-c) Discuss in Detail about Representation of Neural Network 
Definition: Neural network is a model inspired by human brain, consisting of layers 
of neurons connected by weighted edges, used for learning complex patterns. 
1. Composed of input layer, hidden layers, and output layer. 
2. Each neuron applies a function to weighted sum of inputs plus bias. 
3. Activation functions like ReLU, Sigmoid, Tanh introduce non-linearity. 
4. Weights are adjusted during training using backpropagation. 
5. Example: recognize handwritten digits, input is image pixels, output is digit 
label. 
6. Hidden layers allow network to learn abstract representations of data. 
7. Too many layers may lead to overfitting or vanishing gradients. 
8. Neural networks can solve regression, classification, and even sequence 
problems. 
9. Requires lots of data and computation for good performance. 
2-d) Differentiate between Classification & Regression 
Definition: Classification predicts discrete labels, regression predicts continuous values. 
Both are supervised learning tasks but differ in output type. 
1. Classification output is categorical like “spam or not spam”. 
2. Regression output is numeric like house price or temperature. 
3. Example classification: email spam detection. 
4. Example regression: predicting temperature tomorrow. 
5. Classification uses algorithms like SVM, Decision Tree, Naive Bayes. 
6. Regression uses Linear Regression, Polynomial Regression, Neural Networks. 
7. Evaluation metrics differ: classification uses accuracy, precision, recall; 
regression uses MSE, RMSE. 
8. Classification may use probabilistic outputs; regression predicts exact numbers. 
9. Sometimes same algorithm (like neural network) can do both tasks with 
different output layers.

Definition: Knowledge representation is a way to store information in AI system so it 
can reason and make decisions. 
1. Types include rules, semantic networks, frames, and ontologies. 
2. Rules are simple IF-THEN statements. 
3. Semantic networks represent objects and relations graphically. 
4. Frames are data structures representing stereotyped situations. 
5. Ontologies define concepts and relationships in a domain. 
6. Example: Expert system using rules for medical diagnosis. 
7. Proper representation helps machine reason and infer new knowledge. 
8. Poor representation can cause errors in reasoning. 
9. Knowledge representation is foundation of AI intelligence.

3-a) Define Search Algorithms in AI 
Definition: Search algorithms in AI are methods to explore possible solutions to a 
problem. They help machine find best path or answer when there are many 
possibilities. 
1. Search is used when machine has to choose from multiple options. 
2. Uninformed search does not use extra information about problem, examples 
are BFS and DFS. 
3. Informed search uses heuristics to guide search, example A* and greedy search. 
4. BFS searches level by level, DFS goes deep first. 
5. A* uses cost function plus heuristic to choose best path. 
6. Search algorithms are used in games, path finding, planning tasks. 
7. Proper search can save time and computation; bad search wastes resources. 
8. Choice of algorithm depends on problem size, complexity, and memory. 
9. Sometimes search fails if problem too big or heuristics wrong. 
3-b) What is Intelligent Agent 
Definition: An intelligent agent is an entity that perceives environment through 
sensors and acts using actuators to achieve goals. 
1. Agent perceives environment using sensors like camera or microphone. 
2. Acts in environment using actuators like robot arms or software commands. 
3. Agent function decides what action to take based on perception. 
4. Types of agents include simple reflex, model-based, goal-based, and utility
based. 
5. Simple reflex agent acts based on current percept only, may fail in complex 
environments. 
6. Model-based agent keeps internal state to remember past events. 
7. Goal-based agent chooses actions to achieve specific goal. 
8. Utility-based agent considers best outcome using utility function. 
9. Intelligent agents are used in robots, chatbots, recommendation systems.
