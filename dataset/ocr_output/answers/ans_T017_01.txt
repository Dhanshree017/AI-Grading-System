A-2. What is data preprocessing and why is it important? 
Data preprocessing is the step of cleaning, transforming, and organizing raw data before 
training a model. 
It is important because it removes noise, handles missing values, normalizes features, and 
ensures the model learns meaningful patterns, leading to better accuracy and generalization.

model learns. 
Examples: 
1. Learning rate 
2. Number of decision tree depth or number of hidden layers

B-1. Challenges in ML (Imbalanced Data, Missing Values, Curse of Dimensionality, 
Concept Drift) with Solutions 
Imbalanced Data: 
When one class has far fewer samples. 
Solution: Oversampling, undersampling, SMOTE, class-weighted models. 
Missing Values: 
Incomplete records reduce model reliability. 
Solution: Imputation, removing irrelevant rows, using algorithms that handle missing data. 
Curse of Dimensionality: 
Too many features cause sparsity and slow learning. 
Solution: Feature selection, PCA, dimensionality reduction. 
Concept Drift: 
Data patterns change over time. 
Solution: Retraining models, online learning, sliding window techniques. 
B-2. What is Regularization? Explain its types. 
Regularization is a technique that reduces model overfitting by penalizing large weights. 
Types: 
1. L1 Regularization (Lasso): 
Adds absolute weight penalty; performs feature selection. 
2. L2 Regularization (Ridge): 
Adds squared weight penalty; distributes weights smoothly. 
3. Elastic Net: 
Combines L1 and L2 penalties for balanced regularization. 
Regularization stabilizes learning, improves generalization, and prevents overly complex 
models. 
B-3. What is Ensemble Learning? Explain Bagging and Boosting with examples. 
Ensemble learning combines multiple models to improve performance. 
Bagging: 
Builds several independent models on random subsets of data and averages predictions. 
Example: Random Forest uses many decision trees to reduce variance. 
Boosting: 
Trains models sequentially, each correcting previous errors. 
Example: AdaBoost and XGBoost focus on misclassified samples to improve accuracy. 
Ensemble methods provide stability, reduce overfitting, and increase predictive quality.

This pipeline ensures a structured workflow from raw data to reliable deployment.
