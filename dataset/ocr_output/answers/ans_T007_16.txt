A-a) Define AI and Write applications of machine learning 
Artificial Intelligence (AI) is the branch of computer science that focuses on 
creating machines that can perform tasks that normally require human 
intelligence. These tasks include learning from data, reasoning, problem 
solving, understanding language, and making decisions. AI systems are designed 
to mimic human cognitive functions and can operate in dynamic environments 
to provide solutions efficiently. 
Machine Learning (ML) is a subfield of AI where systems learn from data to 
improve their performance without being explicitly programmed for every 
task. ML allows machines to identify patterns, make predictions, and adapt 
to new data over time. 
Applications of Machine Learning: 
1. Spam Detection: ML filters emails and detects spam messages by 
learning from historical email data. 
2. Healthcare Predictions: ML predicts diseases such as diabetes, heart 
disease, or cancer based on patient history and medical tests. 
3. Recommendation Systems: Online platforms like Netflix and YouTube 
suggest content to users based on their viewing habits. 
4. Finance: Banks use ML to detect fraudulent transactions and assess 
credit risk for loans. 
5. Self-Driving Cars: ML enables cars to recognize road signs, pedestrians, 
and obstacles to make driving decisions. 
6. Voice Recognition: Assistants like Google Assistant and Siri understand 
and respond to spoken commands using ML. 
7. Chatbots: ML helps chatbots provide automated customer support and 
answer queries effectively. 
Example: Predicting student marks by analyzing past scores and study hours. 
The ML model learns patterns from past data to predict future performance 
accurately. 
A-b) Explain types of machine learning with example 
There are four main types of machine learning: 
1. Supervised Learning: The machine learns from labeled data where input 
features and output labels are known. The model predicts outcomes for 
new, unseen data. 
o Example: Predicting house prices using features such as area, 
location, and previous sales data. 
2. Unsupervised Learning: The machine learns from unlabeled data to 
identify patterns or groupings in the data without predefined output 
labels. 
o Example: Customer segmentation in e-commerce based on purchase 
behavior. 
3. Semi-Supervised Learning: The model is trained on a small amount of 
labeled data and a large amount of unlabeled data. This approach is 
helpful when labeling data is costly or time-consuming. 
o Example: Image recognition where only a few images are labeled 
while the majority remain unlabeled. 
4. Reinforcement Learning: The machine learns by interacting with an 
environment and receiving feedback in the form of rewards or penalties 
to improve its actions over time. 
o Example: Self-driving cars learning to drive safely in simulations by 
trial and error. 
A-c) What are the steps in building ML model 
Building a machine learning model involves the following steps: 
1. Problem Definition: Clearly define the problem type, whether it is 
classification, regression, or clustering. 
2. Data Collection: Gather relevant and sufficient data from multiple 
sources. 
3. Data Preprocessing: Clean the data, handle missing values, normalize or 
scale features, and encode categorical variables. 
4. Feature Selection and Engineering: Identify and create important 
features that improve model performance. 
5. Model Selection: Choose the most suitable algorithm based on the 
problem and dataset. 
6. Model Training: Train the model on the training dataset to learn 
patterns. 
7. Model Evaluation: Test the model on unseen data using metrics like 
accuracy, precision, recall, or RMSE. 
8. Hyperparameter Tuning: Adjust parameters to optimize model 
performance. 
9. Deployment: Deploy the model in real-world applications to make 
predictions. 
Example: Predicting housing prices. After collecting and cleaning housing data, 
selecting relevant features, training a regression model, testing, and deploying 
it, the model can predict house prices accurately. 
A-d) What are the steps in data preprocessing 
Data preprocessing prepares raw data for machine learning to improve model 
accuracy and reliability. 
1. Data Collection: Collect raw data from files, databases, APIs, or sensors. 
2. Data Cleaning: Handle missing values, remove duplicates, and correct 
errors. 
3. Data Transformation: Encode categorical features, normalize numerical 
data, and adjust skewed distributions. 
4. Feature Selection: Retain features that are relevant to the prediction 
task and remove irrelevant ones. 
5. Scaling and Normalization: Scale numerical features to a standard range 
to improve model performance. 
6. Data Splitting: Divide data into training, validation, and testing sets. 
7. Handling Outliers: Identify and remove or adjust outlier values that may 
affect model performance. 
Example: In a student performance dataset, missing marks can be filled with 
averages, gender encoded numerically, scores normalized, and the dataset split 
into training and testing sets.

B-a) Write a note on Random Forest. Give example of it 
Random Forest is an ensemble machine learning algorithm that constructs 
multiple decision trees during training and merges their outputs to improve 
predictive accuracy and reduce overfitting. Each tree is trained on a random 
subset of the data and features, and final predictions are made using 
majority voting for classification or averaging for regression. 
1. Reduces overfitting compared to individual decision trees. 
2. Can handle large datasets with high dimensionality efficiently. 
3. Works well with missing values. 
4. Provides feature importance scores. 
5. Suitable for both classification and regression tasks. 
6. More stable and accurate than a single decision tree. 
7. May require more computational resources due to multiple trees. 
Example: Predicting loan default using features like income, credit score, and 
employment status. Random Forest uses multiple trees to vote for the final 
prediction. 
B-b) Write a note on SVM, explain types of SVM in detail 
Support Vector Machine (SVM) is a supervised learning algorithm used for 
classification and regression tasks. It finds the optimal hyperplane that 
separates classes by maximizing the margin between the nearest points of the 
classes, known as support vectors. 
Types of SVM: 
1. Linear SVM: Separates linearly separable data using a straight 
hyperplane. 
2. Non-Linear SVM: Uses kernel functions such as RBF or polynomial to 
separate data that is not linearly separable. 
3. Multi-class SVM: Extends SVM for problems with more than two classes 
using strategies like one-vs-one or one-vs-rest. 
Example: Recognizing handwritten digits (0–9) using SVM with an RBF 
kernel. 
B-c) Explain different types of clustering algorithm 
Clustering is an unsupervised learning technique used to group similar data 
points together based on specific characteristics. 
Types of Clustering: 
1. K-Means Clustering: Divides data into K clusters by minimizing the 
distance between data points and cluster centroids. 
2. Hierarchical Clustering: Builds a tree-like structure (dendrogram) by 
either merging or splitting clusters iteratively. 
3. DBSCAN: Groups data points based on density and identifies noise 
points. 
4. Agglomerative Clustering: Each point starts as a cluster and merges 
progressively based on similarity. 
5. Mean Shift Clustering: Shifts cluster centers toward regions of higher 
density iteratively. 
Example: Segmenting e-commerce customers into groups based on purchasing 
behavior using K-Means clustering. 
B-d) What is Decision Tree, explain steps in making decision tree 
Decision Tree is a supervised learning algorithm used for classification and 
regression tasks. It creates a tree-like structure where internal nodes 
represent decisions on features, branches show possible outcomes, and leaf 
nodes indicate final predictions. 
Steps in Making a Decision Tree: 
1. Select Root Node: Choose the most significant feature based on 
Information Gain or Gini Index. 
2. Split Data: Divide dataset according to the root feature’s values. 
3. Recursive Splitting: Continue splitting subsets until they are pure or a 
stopping criterion is reached. 
4. Leaf Nodes: Assign final class labels or output values to the leaf nodes. 
5. Pruning: Remove branches that do not provide significant predictive 
power to reduce overfitting. 
6. Testing: Evaluate the decision tree on test data to assess accuracy. 
7. Deployment: Use the final tree to make predictions on new data. 
Example: Predicting whether a student will pass or fail based on attendance 
and study hours using a decision tree.
