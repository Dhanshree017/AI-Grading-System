A-2. What is data preprocessing? And why is it important? 
Data preprocessing is the phase where raw data is transformed into a structured 
and consistent format before being used for machine learning. It includes 
cleaning, handling missing values, normalization, encoding categories, and 
removing noise. It is important because models rely heavily on the quality of 
data; poor data leads to inaccurate patterns, unstable training, and weak 
predictions. 
A-3. What are hyperparameters? Give two examples 
Hyperparameters are external configuration settings of a model that control how 
training happens. They are not learned by the model but set manually. 
Two examples: learning rate, number of decision tree depth. 
A-4. Explain types of clustering 
1. K-Means Clustering: Divides data into k groups using distance to cluster 
centroids. 
2. Hierarchical Clustering: Builds a tree-like grouping through merging or 
splitting. 
3. DBSCAN: Forms clusters based on density, marking sparse areas as noise. 
4. Spectral Clustering: Uses graph structure and eigenvalues to cluster based 
on similarity matrices. 
A-5. What is classification and regression? Explain with examples 
Classification predicts a class label such as disease present or not present. 
Regression predicts numerical values such as price of a car. 
Example classification: Email spam detection. 
Example regression: Predicting rainfall amount.

A-7. How to make model underfit and overfit 
Underfit by reducing model complexity, using too few features, or limiting 
epochs. 
Overfit by increasing model complexity, training for many epochs, or using low 
regularization.

B-1. Challenges in ML – imbalanced data, missing values, curse of dimensionality, 
concept drift + solutions 
 Imbalanced Data: Some classes are extremely rare, making model biased. 
Solution: Oversampling, undersampling, SMOTE, class weighting. 
 Missing Values: Data may be incomplete. 
Solution: Imputation techniques or removing affected rows. 
 Curse of Dimensionality: Too many irrelevant features reduces learning 
efficiency. 
Solution: PCA, feature selection, regularization. 
 Concept Drift: Data relationships change over time. 
Solution: Online learning, incremental training, sliding-window models. 
B-2. What is Regularization? Explain its types 
Regularization prevents overfitting by reducing model complexity. 
L1 Regularization: Uses absolute weight penalty, leads to sparse models. 
L2 Regularization: Uses squared weight penalty, stabilizes model. 
Elastic Net: Mix of L1 and L2. 
Dropout: Randomly ignores neurons while training to avoid co-adaptation. 
B-3. What is Ensemble Learning? Explain Bagging and Boosting with examples 
Ensemble learning combines several models to enhance accuracy. 
Bagging: 
Creates multiple models on random data subsets and averages results. 
Example: Random Forest. 
Boosting: 
Models are built sequentially, each fixing previous errors. 
Example: AdaBoost, XGBoost.
