A-2. What is data preprocessing? And why it is important? 
Data preprocessing is the method where data is cleaned, arranged, adjusted, and put in proper 
sequence before using it for machine learning. It involves removing noise, normalizing 
scales, converting missing values, and preparing the dataset so that the model understands 
patterns better. It is important because raw data mostly comes messy, and without 
preprocessing the model becomes confused, gives bad predictions, and cannot learn 
meaningful relationships, which reduces accuracy. 
A-3. What are hyperparameters? Give two examples 
Hyperparameters are the setting values that we decide before training a machine learning 
model. They control behaviour like how fast model learns or how complex it becomes. 
Examples include learning rate and number of decision tree depth. 
A-4. Explain types of clustering 
1. K-Means Clustering groups points by measuring distance to cluster centres. 
2. Density-based clustering forms clusters by finding thick areas of data and separating 
noise. 
3. Hierarchical clustering builds connected clusters step by step either by merging or 
splitting. 
4. Grid clustering divides space into small blocks and assigns data based on cell density.

A-7. How to make model underfit and overfit 
Underfit by using fewer features, small model, less training, or high regularization. 
Overfit by training too long, too many parameters, low regularization, and memorizing 
dataset.

B-1. Challenges in ML – imbalanced data, missing values, curse of dimensionality, concept drift 
+ solutions 
 Imbalanced Data: Some classes have very little samples. 
Solution: Oversampling, undersampling, class-weight adjustment. 
 Missing Values: Many values absent in the dataset. 
Solution: Mean/Median imputation or using models to fill gaps. 
 Curse of Dimensionality: Too many features cause sparse patterns. 
Solution: Dimension reduction using PCA or feature selection. 
 Concept Drift: Data pattern changes over time. 
Solution: Re-training model with new data and online learning methods. 
B-2. What is Regularization and its role in ML? Explain its types 
Regularization reduces model complexity so that it does not memorize dataset. It makes the 
model simpler and more generalizable. 
Types: 
1. L1 (Lasso): Adds sum of absolute weights, makes weights go to zero. 
2. L2 (Ridge): Adds square of weights, reduces their magnitude. 
3. Elastic Net: Combination of L1 and L2. 
4. Dropout: Removes neurons during training randomly.

B-6. Write note on Naïve Bayes and SVM 
Naïve Bayes: 
Probabilistic classifier using Bayes theorem. Assumes features independent. Fast, simple, 
good for text classification. 
SVM: 
Separates classes using maximum margin hyperplane. Uses kernel trick for non-linear 
separation. Works well for small to medium datasets.
