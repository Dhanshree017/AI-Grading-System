A-2. What do you mean by Supervised and Unsupervised Learning? Give one example of 
each. 
Supervised and unsupervised learning are two types of learning techniques in machine 
learning. In supervised learning, the computer is trained using data which already has the 
output known. In unsupervised learning, only input data is given and the computer has to 
find pattern or structure itself. 
1. Supervised learning uses labeled data. 
2. Unsupervised learning uses unlabeled data. 
3. Supervised tries to predict values. 
4. Unsupervised tries to find group or cluster. 
5. Example of supervised is prediction of salary using experience. 
6. Example of unsupervised is grouping students by marks. 
7. Supervised is slow but more accurate. 
8. Unsupervised is fast but less accurate. 
9. Both are important in machine learning. 
A-5. What is Overfitting and Underfitting? Give examples of it. 
Overfitting means the model learns data too much and performs well on training but fails 
on new data. Underfitting means the model learns too little and cannot perform well even 
on training data. Both are problems of bad model fitting. 
1. Overfitting happens when model is too complex. 
2. Underfitting happens when model is too simple. 
3. Overfitting gives low test accuracy. 
4. Underfitting gives low training accuracy. 
5. Example of overfitting is learning by heart past question papers. 
6. Example of underfitting is not studying properly before exam. 
7. Regularization helps control overfitting. 
8. Using more data reduces both. 
9. Good model keeps balance between them.

B-1. Define the term Bias and Variance. Elaborate on Bias-Variance Tradeoff. 
Bias means the error caused when model makes wrong assumptions. Variance means the 
error caused when model changes a lot with different data. Bias-variance tradeoff means 
maintaining a balance between both errors so that the model performs well on all types 
of data. 
1. High bias leads to underfitting. 
2. High variance leads to overfitting. 
3. Both together form total error. 
4. Tradeoff is to balance between them. 
5. Simpler model has more bias. 
6. Complex model has more variance. 
7. Cross-validation helps maintain balance. 
8. Regularization helps reduce variance. 
9. Good model has both low bias and low variance.

1. Linear Regression 
2. Multiple Regression 
3. Polynomial Regression 
4. Ridge Regression 
5. Lasso Regression 
6. Logistic Regression 
7. Stepwise Regression 
8. Time Series Regression 
9. Bayesian Regression 
Each type is used for different types of data and complexity level. 
B-3. What is Decision Tree? Explain its steps to implement it. 
A Decision Tree is an algorithm that splits data into branches based on some conditions. 
It looks like a tree with nodes, branches, and leaves. Each node checks one condition and 
each leaf gives an output. 
Steps: 
1. Select the root node. 
2. Split data based on best feature. 
3. Create branches for each condition. 
4. Keep splitting until all data is classified. 
5. Stop when node becomes pure. 
6. Assign class label to leaf node. 
7. Prune the tree if it becomes too large. 
8. Test the tree with new data. 
9. Use the tree for prediction.

B-5. How Deep Learning is different from Machine Learning? Explain Regularization in 
detail. 
Deep Learning is a special part of Machine Learning which uses neural networks with many 
layers. Machine Learning models are simple and need manual feature extraction. Deep 
Learning can learn features automatically from data. 
Differences: 
1. Deep Learning uses multiple layers. 
2. Machine Learning uses fewer layers. 
3. Deep Learning needs large data. 
4. Machine Learning can work on small data. 
5. Deep Learning uses more computing power. 
6. Deep Learning is harder to interpret. 
7. Machine Learning algorithms include SVM and KNN. 
8. Deep Learning uses CNN, RNN, etc. 
9. Deep Learning gives better accuracy in complex problems. 
Regularization: 
Regularization is used to control overfitting by adding penalty terms to the model 
weights. 
1. Keeps model simpler. 
2. Improves generalization. 
3. L1 removes unwanted features. 
4. L2 reduces weight size. 
5. Dropout removes random neurons during training. 
6. Adds stability to model. 
7. Works with both ML and DL. 
8. Helps avoid memorization. 
9. Keeps bias-variance balanced.
