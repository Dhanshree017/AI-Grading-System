A-2. What is Backpropagation? Explain each step in detail. 
Backpropogation is the method by which neural network learn mistake and improve. 
it mean going back and changing weights like going reverse to see what wrong 
happen. 
first there is forward pass where data go inside model and get output. then we see 
difference between real and predicted called error. then we go backward and adjust 
weight using gradient something. 
so steps are: 
1. give input and calculate output 
2. check error by comparing with correct 
3. go backward to change weights

we can change learning rate to fix. 
backpropogation used in deep learning like picture recognition, sound etc. it main 
reason behind AI working.

and need more math.

A-6. Explain Normalization vs Standardization with examples. 
Normalization and standardization both are used to scale data so all feature same 
level. 
In normalization we convert data between 0 and 1. like if one feature has values 
from 10 to 100, we divide so it become 0 to 1 range. 
In standardization we minus mean and divide by deviation so data become mean 0 
and variance 1. 
for example, if height and weight both used in model, height small number, weight 
big, so model confuse. after scaling, both same range so model learn properly. 
but sometimes people mix both, normalization good for deep learning, 
standardization good for linear models.

B-5. Explain the concept of cross-entropy loss. 
Cross entropy is type of loss used when we have classification problem. it measure 
difference between real label and predicted probability. 
if prediction close to real, loss small, if far, loss big. 
it is better than MSE for classification because it punish confident wrong predictions 
more. 
it come from information theory. it tell how much extra information needed if we 
use wrong model. 
like if model predict cat=0.9 dog=0.1 but real was dog, then loss high. 
it used in neural network with softmax. more accuracy, less cross entropy. 
B-6. What is dimensionality curse? How does it affect machine learning models? 
Curse of dimensionality means when number of features too high, model start 
performing badly. because data become sparse and hard to generalize. 
for example if we have 10 feature then model easy, but 1000 feature then too 
complex and we need large data else overfitting. 
also computation become very high. algorithm like kNN become useless because all 
points look far. 
it affect memory, accuracy and interpretability. 
so we use PCA or feature selection to reduce dimension and fix problem.

C-2. Discuss 5 real-world example of a biased ML model and how such bias can be 
reduced. 
Bias in ML is big problem. model learn from data, if data unfair then model unfair 
also. here are 5 example from real world where ML model was biased: 
1. Hiring system bias – some company used ML to select candidate but system 
reject women because old data had more male hired. this bias because model 
think male is better. to reduce it, use balanced dataset and remove gender 
feature. 
2. Face recognition bias – many facial recognition software detect white face 
correctly but fail on black or asian faces. this happen because training data 
mostly white people. solution is use diverse dataset and test on all groups. 
3. Credit scoring bias – banks sometimes reject loan for poor area or certain 
names because past data show high default. but that cause discrimination. to 
fix, algorithm need fairness constraint and remove location feature. 
4. Health diagnosis model – some model trained on western hospital data, so it 
fail on Indian patient. model think disease pattern same for all which is wrong. 
fix by including data from multiple population. 
5. Crime prediction model – in some city ML used to predict which area will have 
crime, but it send more police to poor black area because old record had more 
arrest there. to fix, reduce historical bias and include context data. 
bias reduction need combination of fair data, model audit, explainability and human 
oversight. 
but some people think bias can be 100% removed which is wrong. it can be reduced 
by awareness, transparency, and continuous testing.
