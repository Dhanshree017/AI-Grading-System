A-a)plain the different types of Machine Learning evaluation metrics used for 
classification and regression tasks. Describe how accuracy, precision, recall, F1 
score help in understanding model performance. 
Introduction: 
Evaluation metrics are essential to measure how well a machine learning 
model performs. They help to assess both classification and regression models 
accurately. 
1. Classification Metrics: 
 Accuracy: 
Represents the ratio of correctly predicted instances to total instances. - Useful when classes are balanced. 
 Precision: 
Indicates how many of the predicted positives are actually positive. - Important when false positives are costly. 
 Recall: 
Measures how many actual positives are identified correctly. - Useful in cases where missing a positive case is critical (e.g., medical 
diagnosis). 
 F1 Score: 
The harmonic mean of precision and recall, giving a balanced performance 
measure. - Best used when data is imbalanced. 
2. Regression Metrics: 
 Mean Squared Error (MSE): Measures the average of squared errors 
between predicted and true values. 
 Mean Absolute Error (MAE): Measures the average of absolute 
differences between prediction and actual. 
 R² Score: Shows how well the model explains variance in the data. 
Conclusion: 
A combination of metrics gives a more reliable performance picture than using 
accuracy alone. 
A-b)Describe e K-Nearest Neighbor algorithm. Explain its working step-by
step and discuss the importance of the parameter k. 
Introduction: 
K-Nearest Neighbor (KNN) is a simple, non-parametric algorithm used for 
both classification and regression. It works based on similarity between data 
points. 
Steps in Working: 
1. Choose the number of neighbors (k). 
2. Calculate distance between the new data point and all training points 
using Euclidean, Manhattan, or Minkowski distance. 
3. Select the k nearest neighbors based on the smallest distance values. 
4. Vote or Average: 
o For classification → choose the majority class among k neighbors. 
o For regression → take the average of neighbor values. 
5. Assign prediction to the new sample. 
Importance of Parameter k: 
 Small k: High variance, model overfits. 
 Large k: High bias, model oversimplifies. 
 The best k is usually determined using cross-validation. 
Conclusion: 
KNN’s strength lies in its simplicity, though it can be computationally 
expensive for large datasets. 
A-c)at is Data Imbalance in Machine Learning? Explain its impact on model 
performance and discuss techniques used to handle it. 
Definition: 
Data imbalance occurs when one class has significantly more samples than 
others in a dataset. 
Impact on Model Performance: 
 The model becomes biased toward the majority class. 
 It may give high accuracy but fail to detect minority class cases. 
 Real-world examples include fraud detection, rare disease prediction, etc. 
Techniques to Handle Imbalance: 
1. Resampling Methods: 
o Oversampling: Duplicate or generate synthetic minority samples 
(SMOTE). 
o Undersampling: Reduce majority class samples. 
2. Algorithmic Methods: 
o Use class weighting or cost-sensitive learning. 
3. Ensemble Techniques: 
o Use Balanced Random Forest or boosting algorithms. 
Conclusion: 
Proper handling of imbalance ensures fair and accurate model performance 
across all classes. 
A-e)xplain the concept of Transfer Learning. Discuss how pre-trained models 
are used to solve new tasks with limited data and mention common 
applications of transfer learning. 
Definition: 
Transfer Learning is a technique where knowledge gained while solving one 
problem is reused for a different but related problem. 
Process: 
1. Use Pre-trained Model: 
o A model (like VGG, ResNet, or BERT) trained on a large dataset 
is selected. 
2. Freeze Early Layers: 
o The initial layers retain general learned features. 
3. Fine-Tune Later Layers: 
o The later layers are retrained on new, smaller dataset to adapt to 
new task. 
Advantages: 
 Requires less data and computational power. 
 Faster training and often higher accuracy. 
Applications: 
 Image recognition (ResNet, VGG). 
 Natural Language Processing (BERT, GPT). 
 Speech and emotion recognition. 
Conclusion: 
Transfer Learning accelerates model building and allows efficient performance 
even on small datasets. 
A-f) What are Hyperparameters in Machine Learning? Explain why they are 
important and describe common hyperparameters for algorithms like Decision 
Trees, Neural Networks, and Gradient Boosting models. 
Introduction: 
Hyperparameters are configuration values set before training begins. They 
define how a model learns, unlike parameters which are learned during 
training. 
Importance: 
 They control model complexity and training behavior. 
 Proper tuning improves performance and prevents overfitting or 
underfitting. 
Common Hyperparameters: 
1. Decision Trees: 
o Max Depth, Min Samples Split, Criterion (Gini/Entropy). 
2. Neural Networks: 
o Learning Rate, Batch Size, Number of Layers, Activation 
Functions. 
3. Gradient Boosting: 
o Number of Estimators, Learning Rate, Max Depth, Subsample 
Ratio. 
Tuning Methods: 
 Grid Search, Random Search, and Bayesian Optimization are common 
tuning methods. 
Conclusion: 
Choosing appropriate hyperparameters is crucial to achieving optimal model 
performance.

B-a) Explain the main steps involved in data preprocessing in machine learning. 
Introduction: 
Data preprocessing is a fundamental stage in machine learning that ensures 
raw data is transformed into a clean and structured form suitable for 
modeling. 
Main Steps: 
1. Data Cleaning: 
o Handle missing values by imputation or removal. 
o Remove duplicates and correct inconsistent data entries. 
2. Data Transformation: 
o Convert categorical data into numerical format using encoding 
methods. 
o Apply logarithmic or normalization transformations when needed. 
3. Feature Scaling: 
o Use normalization or standardization so that all features 
contribute equally. 
4. Feature Selection: 
o Eliminate redundant or irrelevant features to reduce complexity. 
5. Data Splitting: 
o Divide the dataset into training, validation, and testing subsets. 
Conclusion: 
Proper preprocessing enhances model accuracy and prevents biased learning due 
to poor-quality data. 
B-b) What is ensemble learning? Describe the working of bagging and boosting 
methods. 
Definition: 
Ensemble learning is a technique that combines multiple models to produce a 
stronger predictive model than individual learners. 
1. Bagging (Bootstrap Aggregating): 
 Multiple models are trained on random subsets of the dataset. 
 Predictions are averaged (for regression) or voted (for classification). 
 Example: Random Forest algorithm. 
 Advantage: Reduces variance and helps prevent overfitting. 
2. Boosting: 
 Models are trained sequentially. 
 Each new model focuses on correcting the errors of the previous ones. 
 Example: AdaBoost, Gradient Boosting, XGBoost. 
 Advantage: Reduces bias and increases predictive accuracy. 
Conclusion: 
Bagging and Boosting complement each other, combining variance and bias 
reduction to create highly effective ensemble systems.

B-e) Explain the role of optimization algorithms in training machine learning 
models. 
Introduction: 
Optimization algorithms are used to minimize the loss function by updating 
model parameters efficiently during training. 
Role and Working: 
1. Objective: Reduce model error (loss). 
2. Process: 
o Compute gradients of loss with respect to parameters. 
o Update weights in the opposite direction of gradient. 
3. Common Algorithms: 
o Gradient Descent: Basic method using learning rate to control 
update size. 
o Stochastic Gradient Descent (SGD): Updates weights using random 
samples for faster convergence. 
o Adam Optimizer: Combines momentum and adaptive learning for 
stability. 
Conclusion: 
Optimizers are vital for achieving faster convergence and higher model 
accuracy in complex neural and statistical models. 
B-f) What is dimensionality reduction? Describe any one method used for it. 
Definition: 
Dimensionality reduction is the process of reducing the number of input 
variables in a dataset while retaining essential information. 
Need: 
 Simplifies models. 
 Reduces overfitting. 
 Improves visualization and computational efficiency. 
Method – Principal Component Analysis (PCA): 
1. Standardize data. 
2. Compute covariance matrix. 
3. Derive eigenvectors and eigenvalues. 
4. Select top principal components based on variance explained. 
5. Project data onto new feature space. 
Conclusion: 
PCA efficiently transforms high-dimensional data into a lower-dimensional 
representation, preserving variance and interpretability. 
B-g) Explain how a decision tree works and mention its advantages and 
disadvantages. 
Working of Decision Tree: 
1. Root Node Selection: 
o The dataset is split based on the best attribute using measures 
like Information Gain or Gini Index. 
2. Branch Formation: 
o Each branch represents a decision rule based on feature values. 
3. Leaf Nodes: 
o Final nodes that give the output (class or value). 
Advantages: 
 Simple to interpret and visualize. 
 Requires little data preprocessing. 
 Can handle both numerical and categorical data. 
Disadvantages: 
 Prone to overfitting on small datasets. 
 Sensitive to small data changes. 
 Less effective for continuous complex patterns. 
Conclusion: 
Despite its limitations, the Decision Tree remains a foundational and 
interpretable algorithm widely used in machine learning.
