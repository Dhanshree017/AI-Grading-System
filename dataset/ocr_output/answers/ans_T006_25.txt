A-2. Define the term overfitting and one solution for it. 
Overfitting it is when the model it learns the training data too very well, even the 
noise in the data. 
1. Definition: The model performs great on the data it saw, but it performs very 
badly on new data because it is too complex. 
A-4. Compare mixure and latent factor models. 
Mixture models and Latent Factor models they are both unsupervised ways to find 
hidden things in the data. 
1. Mixture Models (e.g., GMM): They assume the data it comes from different groups 
(like multiple bell curves added together). The model finds the parameters of each 
group. 
2. Latent Factor Models (e.g., Matrix Factorization): They assume the pattern you 
see it is caused by a few hidden, unobserved variables (the factors). The model 
finds these hidden variables to explain the observations. 
A-5. Write importance of K-means clustering. 
The importance of K-Means clustering it is very high because it is simple and it works 
fast on many datasets. 
1. Use: It is the fastest way to group the data points that are similar to each other 
into K number of clusters. 
2. Applications: It is used a lot for customer segmentation (finding types of 
customers) and compressing pictures (color grouping). 
3. It is easy to implement and gives a good starting point for unsupervised analysis. 
A-7. Give significance of hyperparameter optimization. 
The significance of hyperparameter optimization (HPO) it is very important because it 
makes the model perform the best it can. 
1. Performance: HPO finds the optimal settings (like the learning rate or the tree 
depth) that makes the model error lowest on the validation data. 
2. Generalization: Proper tuning ensures the model it doesn't overfit or underfit, so 
it works well on new data. 
3. It is necessary because the model cannot learn these settings by itself. 
A-8. How machine learning deals with sparse data. 
Sparse data it is data that has mostly zero values in it (like word counts). ML deals 
with it by using smart methods. 
1. Data Structure: Computers they use sparse matrix formats that only store the 
non-zero numbers, which saves a lot of memory and makes it faster. 
2. Algorithms: Some models like linear models with L1 regularization they are good 
because they automatically ignore the zero/unimportant features. 
A-9. What is advantage of active learning. 
The advantage of active learning it is that it saves money on getting the data labeled. 
1. Efficiency: The algorithm itself chooses only the most confusing or uncertain data 
points and asks the human to label just those. 
2. This means you need to label far less data to get the same good accuracy as if 
you labeled everything. 
3. It maximizes the information you get for each dollar spent on labeling. 
A-10. What is training, testing and validation? 
These are the three separate piles that the total dataset it is divided into for model 
development. 
1. Training Set: Used to teach the model and fit its parameters. 
2. Validation Set: Used during development to tune the hyperparameters and select 
the final model configuration. 
3. Test Set: Used only once for the final true evaluation score to check generalization.

B-2 how machine learning and deep learning related / explain regularization in deep 
learning. 
Machine learning it is the big area, and Deep Learning (DL) it is just one special kind 
of ML that uses very large neural networks. 
Regularization in Deep Learning: 
1. Goal: To stop the huge DL models from overfitting to the training data because 
they have many parameters. 
2. L1/L2 Regularization: This adds a penalty to the weights so the model it stays 
simpler and doesn't become too complex. 
3. Dropout: A DL specific method that randomly turns off some neurons during 
each training step, so the network it can't rely too much on one specific path. 
4. Early Stopping: Watching the error on the validation set and stopping the 
training when that error starts to go up, even if the training error is still going 
down. 
5. These techniques they are important for good generalization. 
B-3 explain supervised, unsupervised and semisupervised with examples. 
These are the three main types of learning based on the data labels. 
1. Supervised Learning: Learns from labeled data (input has the correct answer). 
Example: Predicting house price (Regression) or Spam/Not Spam (Classification). 
2. Unsupervised Learning: Learns from unlabeled data (no correct answer). 
Example: Clustering customers into groups (K-Means) or making data smaller 
(PCA). 
3. Semi-Supervised Learning: Uses a little bit of labeled data with a lot of unlabeled 
data to make the model better.  
B-4 What are types of SVM 
Support Vector Machine (SVM) it is a powerful classifier that finds the best line (or 
hyperplane) to separate the classes. It has these types: 
1. Linear SVM: Used when the data it can be separated by a single straight line. 
2. Non-Linear SVM (Kernel SVM): Used when the data it is mixed up and needs a 
curve. It uses the Kernel Trick to project the data into a new space where it can 
be separated by a line. 
3. Soft Margin SVM: Allows some data points to be on the wrong side of the line to 
prevent overfitting to noisy data. 
4. Hard Margin SVM: Requires perfect separation with no misclassification (only 
works for perfect data). 
5. SVR (Support Vector Regression): The version of SVM that is used for predicting 
numbers.
