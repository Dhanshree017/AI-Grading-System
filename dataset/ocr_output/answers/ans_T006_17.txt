in the data.

A-9. What is advantage of active learning. 
The advantage of active learning it is that it saves money on getting the data labeled. 
1. Efficiency: The algorithm itself chooses only the most confusing or uncertain data 
points and asks the human to label just those. 
2. This means you need to label far less data to get the same good accuracy as if you 
labeled everything. 
3. It is used when you have little data and a small budget. 
A-10. What is training, testing and validation? 
These are the three separate piles that the total dataset it is divided into for model 
development. 
1. Training Set: Used to teach the model and fit its parameters. 
2. Validation Set: Used during development to tune the hyperparameters and select the 
final model configuration. 
3. Test Set: Used only once for the final true evaluation score to check generalization

B-3 explain supervised, unsupervised and semisupervised with examples. 
These are the three main types of learning based on the data labels. 
1. Supervised Learning: Learns from labeled data (input has the correct answer). 
Example: Predicting house price (Regression) or Spam/Not Spam (Classification). 
2. Unsupervised Learning: Learns from unlabeled data (no correct answer). Example: 
Clustering customers into groups (K-Means) or making data smaller (PCA). 
3. Semi-Supervised Learning: Uses a little bit of labeled data with a lot of unlabeled 
data to make the model better. Example: When labeling is expensive, using unlabeled 
data to find the general shape of the distribution. 
4. Semi-supervised is the newest type of learning. 
5. Unsupervised is the best because it is the fastest. 
B-4 What are types of SVM 
Support Vector Machine (SVM) it is a powerful classifier that finds the best line (or 
hyperplane) to separate the classes. It has these types: 
1. Linear SVM: Used when the data it can be separated by a single straight line. 
2. Non-Linear SVM (Kernel SVM): Used when the data it is mixed up and needs a 
curve. It uses the Kernel Trick to project the data into a new space. 
3. Soft Margin SVM: Allows some data points to be on the wrong side of the line to 
prevent overfitting to noisy data. 
4. Hard Margin SVM: Requires perfect separation with no misclassification (only works 
for perfect data). 
5. The types of SVM they are defined by the penalty term (C) that you use.
