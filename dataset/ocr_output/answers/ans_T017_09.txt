A-2. What is data preprocessing? Why is it important? 
Data preprocessing refers to transforming raw, noisy, inconsistent data into clean and usable 
form. 
Importance: 
 Removes noise and inconsistencies 
 Improves model accuracy and stability 
 Ensures features are in compatible ranges 
 Handles missing data and outliers 
 Improves training speed and generalization 
Key tasks include cleaning, encoding, scaling, normalization, handling missing values, and 
feature transformation. 
A-3. What are hyperparameters? Give two examples 
Hyperparameters are external configuration settings chosen before training that control the 
learning behavior of the model. 
Examples: 
 Learning rate (controls weight update size) 
 Maximum tree depth in decision trees 
(Other examples: number of layers, number of neighbors k, batch size) 
A-4. Explain types of clustering 
1. Partitioning Methods (K-Means, K-Medoids): Divide data into k groups by 
minimizing distance to cluster centers. 
2. Hierarchical Clustering: Builds a hierarchy of clusters (agglomerative or divisive) 
and visualizes them using dendrograms. 
3. Density-Based Clustering (DBSCAN, OPTICS): Forms clusters based on dense 
regions in the feature space; identifies noise/outliers. 
4. Model-Based Clustering (Gaussian Mixtures): Uses probabilistic models to 
represent clusters as mixture distributions. 
5. Spectral Clustering: Uses graph Laplacian eigenvalues to detect non-linear cluster 
structures.

A-7. How to make model underfit and overfit 
Underfitting occurs when model is too simple: 
 Use low-complexity model (e.g., linear model for non-linear data) 
 Reduce features 
 Add too much regularization 
 Train for very few epochs 
Overfitting occurs when model memorizes training data: 
 Use overly complex model (deep network, deep tree) 
 Remove regularization 
 Train too long 
 Use small dataset with noise

B-1. Discuss ML challenges: imbalanced data, missing values, curse of dimensionality, 
concept drift. Provide solutions. 
Imbalanced Data 
Challenge: One class dominates others; model becomes biased. 
Solutions: 
 Oversampling (SMOTE) 
 Undersampling 
 Class-weighted loss 
 Anomaly detection framing 
 Balanced metrics (F1, PR-AUC) 
Missing Values 
Challenge: Algorithms fail or lose important information. 
Solutions: 
 Mean/median imputation 
 KNN or MICE imputation 
 Adding “missing indicator” features 
 Dropping rows/columns (if safe) 
Curse of Dimensionality 
Challenge: High-dimensional data becomes sparse; model overfits. 
Solutions: 
 PCA, LDA 
 Feature selection (filter/wrapper) 
 Regularization 
 More training samples 
Concept Drift 
Challenge: Data distribution changes over time. 
Solutions: 
 Online learning 
 Sliding window retraining 
 Drift detectors 
 Real-time monitoring 
B-3. What is Ensemble Learning? Explain Bagging and Boosting with examples. 
Ensemble learning combines multiple models to improve accuracy and reduce variance. 
Bagging (Bootstrap Aggregation) 
 Multiple models trained on bootstrapped samples 
 Outputs combined by voting/averaging 
 Reduces variance 
Example: Random Forest 
Boosting 
 Models built sequentially 
 Each new model focuses on errors of previous models 
 Reduces bias 
Example: AdaBoost, Gradient Boosting, XGBoost

B-6. Write note on Naïve Bayes and SVM 
Naïve Bayes 
 Based on Bayes theorem 
 Strong independence assumption 
 Works best for text classification 
 Types: Gaussian, Multinomial, Bernoulli 
 Very fast and simple 
Support Vector Machine (SVM) 
 Maximizes margin between classes 
 Works well in high-dimensional spaces 
 Uses kernels (RBF, polynomial) for non-linear classification 
 Handles small and medium datasets efficiently 
 Parameter C controls margin softness 
 Kernels enable mapping into higher dimensions
