A-4. What are Steps of Creating a ML Model 
Definition: 
Machine learning model not come suddenly. It need process like making tea. First you 
take data like milk, then cleaning like boiling, then model selection like adding sugar. 
It go in many steps else it will not work. 
Explanation: 
1. Collect data: Take data from csv or google or anywhere. 
2. Clean data: Remove wrong, missing, empty lines. 
3. Preprocess: Change string to number because machine don’t understand 
English. 
4. Split data: Divide 80 for training and 20 for testing. 
5. Select model: Like regression, decision tree or SVM. 
6. Train model: Give data and let model learn. 
7. Test model: Check how model doing on test data. 
8. Tune model: Change some hyper parameter like learning rate etc. 
9. Deploy: Final model put in real world website or machine. 
A-5. What is Overfitting and Underfitting, Give Examples of It 
Definition: 
Overfitting is when model learn too much that it remember everything and cannot 
do new data. Underfitting is when model not learn anything also. So both are bad 
like one student who memorise only book and one student who never read anything. 
Explanation: 
1. Overfitting → model perform 100% on training but fail on test. 
2. Underfitting → model bad on both training and testing. 
3. Overfitting because model too complex. 
4. Underfitting because model too simple. 
5. Example overfit: decision tree with many branches. 
6. Example underfit: linear regression on non-linear data. 
7. Use regularization to reduce overfit. 
8. Cross validation also use for checking. 
9. Better to keep middle balance for good result. 
A-6. What is K-Means Clustering, Write Importance of It 
Definition: 
K means clustering is algorithm which make K groups in the data. It is unsupervised 
so no answer given. It find centre of each group and put data near to it. It repeat 
again and again till it become stable. 
Explanation: 
1. Choose value of K how many cluster. 
2. Take random centroid. 
3. Measure distance between data and centroid. 
4. Put data in nearest cluster. 
5. Move centroid to new position. 
6. Repeat until centroid stop moving. 
7. It is very fast and easy algorithm. 
8. Used for customer group and document cluster. 
9. Help to see hidden pattern in data.

B-1. Define Bias and Variance, Explain Bias Variance Trade-off 
Definition: 
Bias and variance are two thing that make model not good. Bias is when model is 
too simple and make same mistake again again. Variance is when model is too 
complicated and always changing answer. Bias variance trade off is like balance both 
like salt and sugar. 
Explanation: 
1. High bias cause underfitting. 
2. High variance cause overfitting. 
3. Both together cause big error. 
4. We want both small but not zero. 
5. If increase complexity, bias go down but variance up. 
6. If reduce complexity, variance go down but bias up. 
7. Regularization can fix some of this. 
8. Cross validation test which side is more. 
9. We find middle point for best accuracy. 
B-2. What is Regression, Explain its Types in Detail 
Definition: 
Regression is predicting value like price, marks, temperature etc. It is continuous 
output not category. It draw line between input and output to guess future. 
Types: 
1. Linear regression: Draw straight line between input and output. 
2. Multiple regression: Many input for one output. 
3. Polynomial regression: Use curve not straight. 
4. Lasso regression: Add L1 penalty to remove useless. 
5. Ridge regression: Add L2 to reduce overfit. 
6. Logistic regression: Used for yes/no output. 
7. Elastic net: Mix of lasso and ridge. 
8. Stepwise regression: Add variable step by step. 
9. Nonlinear regression: For not straight relation. 
B-3. What is Decision Tree, Explain Steps to Implement It 
Definition: 
Decision tree is model that look like real tree but it is not tree. It make branch and 
each branch have question and answer and at last give result. It is easy because look 
like if-else in programming. 
Steps: 
1. Choose feature with max information gain. 
2. Split data based on that. 
3. Make branch for each split. 
4. Again split until leaf node pure. 
5. Stop when cannot split. 
6. Give output on leaf node. 
7. Prune to remove small branch. 
8. Test model with test data. 
9. Use for classification and regression also.
