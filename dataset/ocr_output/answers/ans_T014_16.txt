B-1. Explain the architecture and working of a Deep Neural Network (DNN). 
Discuss in detail the different layers, the role of weights and biases. Also 
describe common challenges in training deep networks and methods to overcome 
them. 
A Deep Neural Network (DNN) is an artificial neural network with multiple 
hidden layers between the input and output layers, designed to learn complex 
patterns. Its architecture consists of an input layer, multiple hidden layers, 
and an output layer, where each layer contains neurons. Neurons in a layer 
connect to neurons in the next layer via weighted connections, and each 
neuron applies a weighted sum to its inputs followed by an activation 
function to transform the data. The network learns by adjusting its weights 
and biases through a process called backpropagation to minimize the error 
between its predictions and the actual values.  
Architecture and working 
 Layers: A DNN is made of layers of interconnected neurons. 
o Input Layer: This layer receives the raw input data (e.g., pixel values of an 
image, words in a sentence). 
o Hidden Layers: These are the layers between the input and output layers. 
They are the computational core of the network, where complex features are 
extracted and transformed through successive layers. The "deep" in DNN 
refers to having multiple hidden layers. 
o Output Layer: This layer produces the final output of the network, such as a 
classification (e.g., "cat" or "dog") or a regression value. 
 Neuron operations: Each neuron performs two primary operations: 
 Weighted Sum: It calculates a weighted sum of all the inputs it receives from 
the previous layer, plus a bias term. 
 Activation Function: The result of the weighted sum is then passed through 
an activation function (e.g., ReLU, sigmoid) to introduce non-linearity, 
allowing the network to learn complex patterns. 
 Working: 
o Forward Propagation: Input data is fed into the input layer and flows 
through the hidden layers to the output layer, where a prediction is made. 
o Learning: To learn, the network compares its prediction to the actual correct 
output to calculate an error. It then uses a process called backpropagation to 
adjust the weights and biases of the neurons to minimize this error, 
improving the accuracy of future predictions.  
Role of weights and biases 
 Weights: These are the "strength" of the connections between neurons. A 
higher weight means that the input from that neuron has a greater influence 
on the next neuron's output. 
 Biases: Each neuron has a bias term, which is an additional input that is 
always 1, multiplied by a weight. The bias shifts the activation function, 
allowing the network to have more flexibility in fitting the data.  
Challenges and solutions 
 Overfitting: The model becomes too specialized in the training data and 
performs poorly on new, unseen data. 
o Solutions: Use regularization techniques like L1/L2 regularization, dropout 
(randomly deactivating neurons during training), or early stopping (stopping 
training when performance on a validation set begins to degrade). 
 Vanishing/Exploding Gradients: During backpropagation, the gradients can 
become very small (vanishing) or very large (exploding), making it difficult 
for the network to learn effectively. 
o Solutions: Use activation functions like ReLU (which does not suffer from 
vanishing gradients for positive inputs), use appropriate weight initialization 
(like Xavier or He initialization), and use batch normalization. 
B-2. Discuss in detail the working of the Support Vector Machine (SVM) 
algorithm for both linear and non-linear classification. Explain the concept of 
hyperplanes, support vectors, and margin maximization. 
SVM is a classification algorithm which tries to find the best line or plane 
that separates two classes. The line is called hyperplane. The points nearest 
to that plane are called support vectors. The goal of SVM is to make the 
margin between classes as large as possible because that improves accuracy. 
If data is not linearly separable, SVM uses something called kernel trick which 
converts it into higher dimensions. Then it becomes easier to find a linear 
boundary. The common kernels are RBF and Polynomial. 
SVM gives good performance on many datasets and is very stable but it can 
be slow when the dataset is big. Still, it is a strong algorithm for 
classification and works even when the data has many features.

B-4. Describe the concept of Natural Language Processing and its stages in 
detail. Explain important steps such as tokenization, stop word removal, 
stemming, and lemmatization. 
Natural Language Processing (NLP) is an AI field that enables machines to 
understand and process human language through a series of stages, beginning 
with text preprocessing steps like tokenization, stop word removal, stemming, 
and lemmatization. These initial steps clean and normalize the text, followed 
by other stages such as part-of-speech tagging, semantic analysis, and text 
generation, to enable machine comprehension and application.  
Stages of NLP 
A typical NLP pipeline involves several phases, starting with preprocessing to 
prepare the text:  
1. Preprocessing 
This initial phase transforms raw text into a clean, machine-readable format.  
 Tokenization: The process of breaking down a body of text into smaller units, 
or "tokens." These tokens can be words, sentences, or even sub-word units, 
depending on the task. 
 Stop Word Removal: Common words like "the," "a," "is," and "and" that do 
not carry significant meaning are removed. This helps reduce noise and focus 
on more important words for analysis. 
 Stemming: A crude but fast method of reducing words to their root form by 
chopping off prefixes or suffixes, even if the result is not a valid word. For 
example, "running" and "runs" both become "run". 
 Lemmatization: A more sophisticated approach that reduces words to their 
base or dictionary form (lemma), using vocabulary and morphological analysis 
to account for context. For example, "better" becomes "good," and "am," 
"is," and "are" all become "be".  
2. Syntax and Parsing 
This phase analyzes the grammatical structure of sentences.  
 Part-of-Speech (POS) Tagging: Assigns a grammatical category (e.g., noun, 
verb, adjective) to each word. 
 Dependency Parsing: Analyzes the grammatical structure of a sentence to 
show the relationships between words.  
3. Semantic Analysis 
This phase involves understanding the meaning of the text.  
 Named Entity Recognition (NER): Identifies and categorizes named entities in 
text, such as the names of people, organizations, and locations. 
 Word Sense Disambiguation (WSD): Determines the correct meaning of a 
word when it has multiple meanings.  
4. Application 
The final phase involves using the processed data for a specific task.  
 Information Extraction: Extracts specific entities and their relationships from 
the text. 
 Text Summarization: Creates a concise summary of a longer document. 
 Machine Translation: Translates text from one language to another.
