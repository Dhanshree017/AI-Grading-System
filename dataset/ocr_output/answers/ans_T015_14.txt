A-a) Explain the different types of Machine Learning evaluation metrics used for 
classification and regression tasks. Describe how accuracy, precision, recall, F1 score 
help in understanding model performance. 
Accuracy, precision, recall, and F1 score are used to evaluate classification models, with 
accuracy being the overall correct predictions and precision/recall focusing on specific types 
of errors. Accuracy is the percentage of total correct predictions, while precision answers, 
"Of those predicted as positive, how many were truly positive?". Recall answers, "Of all 
actual positives, how many were correctly identified?". The F1 score is the harmonic mean 
of precision and recall, providing a single metric that balances both, especially useful for 
imbalanced datasets. Regression models are not typically evaluated with these metrics but 
with metrics like Mean Squared Error or R-squared.  
Classification vs. regression  
 Classification: Aims to categorize data into predefined labels (e.g., spam or not 
spam). The metrics below are primarily for this task. 
 Regression: Aims to predict a continuous value (e.g., predicting a house price). It 
uses different metrics like Mean Squared Error.  
Classification metrics  
To understand these metrics, consider a confusion matrix with four components:  
 True Positives (TP): Correctly predicted positive cases. 
 True Negatives (TN): Correctly predicted negative cases. 
 False Positives (FP): Incorrectly predicted positive cases (Type I error). 
 False Negatives (FN): Incorrectly predicted negative cases (Type II error).

A-c) What is Data Imbalance in Machine Learning? Explain its impact on model performance 
and discuss techniques used to handle. 
Introduction: 
Data imbalance is when all features are not balanced properly inside dataset or when 
memory of computer not fit properly. It usually happen when we not collect equal 
number of features. 
Body: 
In such case, model get confused because there is too much of big number and less of 
small number data. For example, if some people are tall and others short, model cannot 
classify them because it mix up both. 
To handle this, we can change batch size or change the learning rate. Another way is to 
shuffle data every epoch so it will become balanced automatically. 
Conclusion: 
Data imbalance can make accuracy low but it is mainly due to training speed and memory, 
not actual data distribution. 
A-d) Explain the working of Gradient Boosting in detail. Discuss how it builds models 
sequentially and how weak learners are combined to form a strong model. 
Introduction: 
Gradient boosting is an ensemble technique where multiple weak models are joined to make 
a strong model. 
Body: 
It works by training models sequentially. The first model makes prediction and calculates 
errors. The next model tries to correct those errors by learning the residuals. This 
continues until the model reaches good accuracy or we stop early. 
Each new model focuses on what previous model did wrong. Gradient means direction of 
improvement and boosting means to improve the power. 
Finally, all models are combined by weighted sum of their predictions. 
Conclusion: 
Gradient boosting is powerful but can overfit if not tuned properly. It is used in 
algorithms like XGBoost and LightGBM. 
A-e) Explain the concept of Transfer Learning. Discuss how pre-trained models are used to 
solve new tasks with limited data and mention common applications of transfer learning. 
Introduction: 
Transfer learning is when we transfer files from one computer to another to save training 
time. 
Body: 
For example, if we already trained one model in one PC, we can copy it to other PC and 
it will start working immediately without new data. In this way we do not need to 
retrain the model. This is called transfer learning because we are transferring training not 
learning. 
It is mostly used when network connection is slow or when GPU is expensive. 
Conclusion: 
Transfer learning saves time in file transfer and helps model to load faster for prediction.

B-b) What is ensemble learning? Describe the working of bagging and boosting methods. 
Introduction: 
Ensemble learning means combining many models to make strong one. 
Body: 
Bagging means train multiple models on different subsets of data and combine their result. 
Example is Random Forest. Boosting means training models one after another, each 
correcting previous mistake. Example is AdaBoost. 
Both reduce overfitting and increase stability. 
Conclusion: 
Ensemble learning is key idea to improve prediction power of ML systems. 
B-d) What is cross-entropy loss? Describe its use in classification models. 
Introduction: 
Cross-entropy loss is function used in deep learning for measuring prediction difference. 
Body: 
It calculates how far the predicted probability is from the true probability. It penalizes 
wrong predictions more when model is confident. 
It is used mainly for classification tasks like softmax output layers. 
Conclusion: 
Cross-entropy loss helps model learn better probabilities and improve accuracy.

B-g) Explain how a decision tree works and mention its advantages and disadvantages. 
Introduction: 
Decision tree is a model that works like asking questions one by one to reach final answer. 
Body: 
It divides dataset based on feature values. Each node asks a question, and branches 
represent possible outcomes. The process continues until a leaf node is reached which gives 
final prediction. 
Advantages: easy to interpret, handle both numerical and categorical data. 
Disadvantages: prone to overfitting, unstable to small data changes. 
Conclusion: 
Decision trees are simple but strong base model used in many algorithms.
