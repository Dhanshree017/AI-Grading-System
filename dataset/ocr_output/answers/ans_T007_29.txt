B-b) Write a note on SVM, explain types of SVM in detail 
SVM is like a line that divide data but sometimes not line also. It is used when we want 
to separate two things like cat and dog photos. It find best line in between so that 
mistake become less. 
1. It use support vector which are like point near boundary. 
2. It find maximum margin line between two class. 
3. It can be used for regression also. 
4. It use kernel trick for changing shape of line. 
Types of SVM: 
 Linear SVM: When line is straight like simple line and data is clear. 
 Non-linear SVM: When line is curve and data mixed so use RBF kernel. 
 Polynomial SVM: When line is polynomial shape and hard to draw. 
Example: In college attendance data SVM can separate students who attend and not 
attend by percentage line.

B-d) What is Decision Tree, explain steps in making decision tree 
Decision tree is like a tree but made from data. It have root, branch and leaf. Each 
branch is question and each leaf is answer. It divide data again and again till no question 
left. 
1. Select best feature using something like Gini or information gain. 
2. Divide data based on that feature. 
3. Continue dividing until all data same or no feature left. 
4. Then we get answer on leaf. 
5. Sometime we cut extra branch to make tree small which called pruning. 
6. It can handle both number and word data also. 
Example: Decision tree used in deciding if person will go out in rain or not based on 
weather and umbrella.
