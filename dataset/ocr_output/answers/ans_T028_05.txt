computer will be happy. 
 Handling Missing Data: Put in whatever number you feel like. Maybe 7, because it's a lucky

 Identification of Inconsistencies: If something is spelled wrong, just fix it by typing it wrong again,

make it look like pizza.

the same.

later.

because it sounds like a robot. 
 Data Size and Availability: If the data is big, use a small algorithm. If the data is small, use a big 
algorithm. Opposite day! 
 Data Type and Structure: If it's pictures, pick the one that has pictures on its logo. 
 Interpretability Requirement: Only choose "black box" models. It’s more mysterious that way. 
 Accuracy Requirements: It doesn't need to be accurate, just fast. No one will notice if the answers 
are wrong. 
 Training and Prediction Speed: Choose the one that is the slowest. It must be working harder if it 
takes longer.

possible. 
 Scalability Needs: Only worry about the data you have right now. The future is someone else's
