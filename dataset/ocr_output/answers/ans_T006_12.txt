A-1. How Reinforcement learning is different from Supervised learning? 
Reinforcement learning and supervised learning are both methods in machine learning, but 
they are very different in how they learn. Supervised learning needs data with correct 
answers, so the model can learn by comparing its prediction with the correct output. 
Reinforcement learning does not have correct answers beforehand. Instead, it learns by 
interacting with the environment and getting reward or punishment for its actions. This 
makes RL more suitable for situations where the correct answer is not known in advance. 
In supervised learning, the model just look at data and learn the mapping between input 
and output. In RL, the agent explore different actions and tries to get better reward. 
Supervised learning is used in tasks like predicting marks, spam detection, or regression 
problems. RL is used in games, robotics, and real-time decision-making systems. So the main 
difference is that supervised learning has a teacher while RL has a trial-and-error approach. 
Key points: 
1. Supervised learning needs labeled data, RL uses rewards or penalties. 
2. Supervised learning learns from examples, RL learns from interaction with environment. 
3. RL is step by step learning, supervised is direct mapping. 
4. Supervised is used in prediction and classification, RL used in decision-making tasks. 
5. RL can handle sequential decision problems, supervised learning cannot. 
A-2. Define the term overfitting and one solution for it 
Overfitting happens when a model learns too much from training data and starts memorizing 
it instead of learning patterns. Because of this, it performs well on training data but poorly 
on new unseen data. Overfitting usually happens when model is very complex or training for 
long time on small dataset. It is a common problem in machine learning, especially for deep 
learning models with many layers. 
To prevent overfitting, one solution is regularization. Regularization adds a penalty to model 
complexity, helping the model focus on important patterns instead of noise. Other methods 
include early stopping, dropout, and increasing dataset size. Cross-validation is also used to 
make sure the model generalizes well. 
Key points: 
1. Overfitting is memorizing training data, perform poorly on new data. 
2. Happens when model is too complex or trained for too long. 
3. Reduces generalization capability of model. 
4. Regularization (L1, L2) helps reduce overfitting. 
5. Other methods: early stopping, dropout, cross-validation, more data. 
A-3. What is the role of Linear Discriminant Analysis in ML? 
Linear Discriminant Analysis (LDA) is a method used to reduce the number of features 
while keeping important class information. It finds directions in feature space that maximize 
separation between classes. LDA is useful when we have many features and want to simplify 
dataset for faster learning or better classification performance. 
It works by projecting data into lower-dimensional space that separates classes. LDA is often 
used before applying classifiers like SVM or logistic regression. Applications include face 
recognition, handwriting recognition, and document classification. LDA also helps reduce noise 
and improve model accuracy. 
Key points: 
1. LDA reduces number of features while keeping important information. 
2. Maximizes distance between classes, minimizes within-class variance. 
3. Helps improve classification accuracy. 
4. Can be used with SVM, logistic regression, and other classifiers. 
5. Applications: face recognition, handwriting recognition, document classification. 
A-4. Compare mixture and latent factor models 
Mixture models and latent factor models are both used to understand hidden patterns in 
data, but they work differently. Mixture models divide data into groups where each group 
has its own probability distribution. Latent factor models try to find hidden variables that 
explain why data behaves in certain ways. 
Mixture model assumes each data point belongs to one cluster, while latent factor model 
allows multiple hidden factors to affect one data point. Mixture models are used for 
clustering and density estimation. Latent factor models are often used in recommender 
systems and dimensionality reduction. Both methods help uncover structure in data, but 
their approaches are different. 
Key points: 
1. Mixture model groups data, latent factor finds hidden factors. 
2. Mixture: one cluster per data point, latent: multiple factors affect data. 
3. Mixture used for clustering, latent for recommendation. 
4. Mixture uses Expectation Maximization, latent uses matrix factorization. 
5. Both help understand data structure but approach is different.

A-6. Write about R Square and its significance 
R Square is a measure in regression models that shows how well the independent variables 
explain the variation in the dependent variable. It ranges from 0 to 1. A higher value means 
the model fits data better, while a low value shows poor fit. R Square helps evaluate the 
performance of regression models. 
It is easy to interpret and widely used in regression analysis. Adjusted R Square is sometimes 
used for multiple variables. R Square helps in understanding the predictive power of a model 
and deciding whether the model is suitable. 
Key points: 
1. Shows how much variation in output is explained by inputs. 
2. Value between 0 and 1; higher is better. 
3. Used to evaluate regression models. 
4. Adjusted R Square used for multiple independent variables. 
5. Helps determine model performance.

A-8. How machine learning deals with sparse data 
Sparse data has many zeros or missing values. It is common in text, recommendation 
systems, and high-dimensional datasets. Machine learning uses special techniques to handle 
sparse data effectively. 
Sparse matrices store only non-zero values to save memory. Some algorithms like Naive 
Bayes and Logistic Regression handle sparse data better. Dimensionality reduction can reduce 
sparsity, and embeddings can convert sparse categorical data into dense numbers. Filling 
missing values is also used. 
Key points: 
1. Sparse matrices save memory. 
2. Naive Bayes and Logistic Regression work better with sparse data. 
3. Dimensionality reduction reduces sparsity. 
4. Embeddings convert categorical/text data to dense numbers. 
5. Missing values can be filled or replaced. 
A-9. What is advantage of active learning 
Active learning is when the model chooses which data points are most useful for learning. 
It is useful when labeling is expensive or time-consuming. The model asks for labels only for 
important data, improving efficiency. 
It helps reduce cost and improve model accuracy faster than random sampling. Active learning 
is widely used in medical diagnosis, NLP tasks, and image labeling, where labeled data is 
limited. 
Key points: 
1. Model selects important samples for labeling. 
2. Reduces labeling cost and effort. 
3. Improves learning efficiency. 
4. Speeds up model training. 
5. Useful for medical, NLP, and image tasks. 
A-10. What is training, testing and validation 
In machine learning, data is divided into training, validation, and testing sets. Training is 
used to teach the model, validation to tune hyperparameters and check performance during 
training, and testing to evaluate final model performance on unseen data. 
This process ensures the model generalizes well and does not overfit. Proper splitting helps 
in selecting the best model and understanding its true accuracy. 
Key points: 
1. Training set is for learning. 
2. Validation set tunes the model. 
3. Testing set evaluates unseen data performance. 
4. Ensures generalization. 
5. Important for proper model evaluation

B-2. Explain supervised, unsupervised and semi-supervised with examples 
Machine learning methods can be categorized based on the type of data available. Supervised, 
unsupervised, and semi-supervised learning are the three main types. 
Supervised learning uses labeled data. The model learns from examples where both input and 
output are known. Example: predicting students’ marks from hours studied. The model tries 
to map inputs to correct outputs. 
Unsupervised learning uses unlabeled data. The model finds hidden patterns or groupings 
without any correct answers. Example: grouping customers into segments using K-means 
clustering. 
Semi-supervised learning uses a combination of labeled and unlabeled data. It is useful when 
labeling data is expensive. Example: face recognition systems with only a few labeled images. 
1. Supervised has teacher data, unsupervised has no teacher, semi-supervised is in 
between. 
2. Supervised is easier, unsupervised is harder because model must find patterns itself. 
3. Semi-supervised is useful when labeling all data is not possible. 
4. All three methods are widely used depending on data and problem type. 
5. Supervised used in classification/regression, unsupervised in clustering, semi-supervised 
in hybrid tasks. 
6. They are foundational for almost all machine learning applications. 
7. Choosing the right type depends on data availability and goal. 
B-4. What are types of SVM 
Support Vector Machine (SVM) is a supervised learning algorithm mainly used for 
classification and regression. SVM has several types depending on the data and kernel used. 
Linear SVM: Used when data can be separated with a straight line or plane. Example: 
separating two types of emails into spam and non-spam. 
Non-linear SVM: When data is not linearly separable, it maps the data into higher dimensions 
to separate it using kernels. 
Polynomial Kernel SVM: Uses polynomial functions to create complex boundaries between 
classes. 
RBF Kernel SVM: Most commonly used kernel for complex non-linear datasets. 
Sigmoid Kernel SVM: Works similarly to neural networks in some binary classification tasks. 
Multi-class SVM: Handles more than two classes using one-vs-all or one-vs-one methods. 
Support Vector Regression (SVR): Adaptation of SVM for regression instead of classification. 
1. SVM is flexible due to different kernels. 
2. Choice of kernel depends on data and complexity. 
3. Linear for simple problems, RBF for complex problems. 
4. Polynomial kernel for high-degree boundaries. 
5. Multi-class SVM allows SVM to handle real-life multi-class problems. 
6. SVR predicts continuous values, e.g., house prices. 
7. SVM works well on high-dimensional datasets. 
8. Proper tuning of parameters like C and gamma improves accuracy. 
B-5. Explain Decision Tree in detail 
A decision tree is a supervised machine learning algorithm used for classification and regression 
tasks. It organizes data into a tree-like structure where internal nodes represent decisions 
based on features, branches represent possible outcomes, and leaf nodes give the final 
prediction. Decision trees are easy to visualize and interpret, making them popular in 
applications where explainability is important. 
Components: 
 Root Node: Represents the full dataset and the first decision point. 
 Internal Nodes: Represent features on which data is split. Splits are chosen based on 
criteria like Information Gain or Gini Index. 
 Branches: Connect nodes and represent outcomes of a decision. 
 Leaf Nodes: Terminal nodes giving the predicted class or value. 
How 
it 
works: 
The algorithm splits data recursively based on the feature that best separates the classes. 
This continues until a stopping condition is reached, like maximum depth, minimum number 
of samples, or homogenous nodes. New data passes through the tree following branches 
based on its feature values until reaching a leaf, which gives the prediction. 
Key characteristics: 
 Interpretability: Decision trees are intuitive and easy to understand. 
 Versatility: Can handle both numerical and categorical data. 
 Minimal Data Preparation: Require less preprocessing compared to other algorithms. 
 Applications: Used in finance (loan approval), healthcare (disease prediction), marketing 
(customer segmentation), and many other domains. 
Decision trees form the foundation for advanced ensemble methods like Random Forests and 
Gradient Boosted Trees, making them an essential tool in machine learning.
