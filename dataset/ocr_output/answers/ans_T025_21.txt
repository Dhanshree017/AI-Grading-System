A-1. Explain the concept of data preprocessing in machine learning. Discuss various 
preprocessing tasks and explain how they influence model performance. 
Concept of Data Preprocessing 
Data preprocessing in machine learning refers to the process of converting raw, real-world 
data into a clean, structured, and meaningful format before it is used for model training. Real 
datasets are often incomplete, noisy, inconsistent, and unscaled, which makes direct learning 
ineffective. Preprocessing ensures that the data quality is improved so that models can learn 
accurate and reliable patterns. 
Various Preprocessing Tasks and Their Influence 
Data cleaning involves handling missing values, removing duplicates, and correcting errors, 
which prevents the model from learning incorrect information. Encoding converts 
categorical variables into numerical form, allowing algorithms to process them 
mathematically. Feature scaling and normalization bring numerical features to a similar 
range, ensuring that no feature dominates learning. Outlier detection reduces the impact of 
extreme values that can distort predictions. Together, these tasks improve model accuracy, 
reduce training time, and enhance generalization performance. 
A-2. Describe the working of a Decision Tree algorithm. Explain how decisions are made 
and discuss its advantages and limitations. 
Working of Decision Tree Algorithm 
A Decision Tree is a supervised learning algorithm that represents decision-making using a 
tree-like structure. The algorithm starts with the full dataset at the root node and recursively 
splits it into smaller subsets based on feature values until a stopping condition is reached. 
How Decisions Are Made 
At each internal node, the algorithm selects the best feature for splitting using criteria such as 
Information Gain, Gini Index, or Entropy. Branches represent outcomes of decisions, and 
leaf nodes provide the final predicted output. 
Advantages and Limitations 
Decision Trees are easy to understand and interpret, handle both numerical and categorical 
data, and require minimal preprocessing. However, they are prone to overfitting, sensitive to 
noisy data, and small changes in data can lead to very different tree structures. 
A-3. Explain the bias–variance tradeoff. Discuss its impact on underfitting and overfitting 
with practical illustrations. 
Concept of Bias–Variance Tradeoff 
The bias–variance tradeoff describes the balance between model simplicity and complexity. 
Bias represents error due to overly simplistic assumptions, while variance represents error 
due to excessive sensitivity to training data. 
Impact on Underfitting and Overfitting 
High bias leads to underfitting, where the model fails to capture important patterns, such as 
using a simple linear model for complex data. High variance leads to overfitting, where the 
model memorizes training data but performs poorly on unseen data. An optimal model 
balances bias and variance to achieve strong generalization. 
A-4. Discuss the importance of model evaluation in machine learning. Explain why 
accuracy alone is not sufficient and describe other evaluation measures. 
Importance of Model Evaluation 
Model evaluation measures how well a trained machine learning model performs on unseen 
data. It helps compare models, identify weaknesses, and ensure the model is reliable before 
deployment. 
Why Accuracy Alone Is Not Sufficient 
Accuracy can be misleading when data is imbalanced. For example, predicting all cases as 
the majority class may produce high accuracy but poor real-world usefulness. 
Other Evaluation Measures 
Precision measures the correctness of positive predictions, recall measures how many actual 
positives are detected, F1-score balances precision and recall, and ROC-AUC evaluates 
performance across different thresholds. These metrics provide a more complete evaluation. 
A-6. Describe how machine learning models are deployed and maintained in real-world 
systems. Explain issues such as monitoring, retraining, and performance degradation. 
Model Deployment 
Model deployment is the process of integrating a trained machine learning model into a 
production environment such as APIs, applications, or enterprise systems. 
Maintenance Challenges 
After deployment, models must be continuously monitored to detect data drift and 
performance decline. Retraining is required when data patterns change. Performance 
degradation occurs due to evolving user behavior or outdated data, making ongoing 
maintenance essential.

B-1. An e-commerce company wants to reduce product returns. Explain how machine 
learning can be used to analyze customer behavior, product data, and past returns to 
reduce return rates. 
Machine learning can analyze customer browsing behavior, purchase history, product 
attributes, reviews, and return records to identify patterns leading to returns. Predictive 
models estimate the probability of a product being returned before purchase completion. 
Recommendation systems suggest products with lower return likelihood, while NLP models 
analyze reviews to detect misleading descriptions. These insights help improve sizing 
accuracy, product quality, and recommendations, thereby reducing return rates. 
B-3. A hospital plans to predict patient readmission rates. Explain how machine learning 
can support this task, from data collection to using predictions for better healthcare 
decisions. 
Hospitals collect patient demographics, medical history, diagnosis details, treatment data, 
and lifestyle information. Machine learning models analyze this data to predict readmission 
risk. Predictions help doctors plan follow-up care, optimize discharge planning, allocate 
resources efficiently, and improve patient outcomes while reducing healthcare costs. 
B-5. A manufacturing company is facing frequent machine breakdowns. Explain how 
predictive maintenance using machine learning can reduce downtime and improve 
operational efficiency. 
Machine learning models analyze sensor data such as temperature, vibration, pressure, and 
machine usage history. Predictive models detect early signs of failure and estimate remaining 
useful life. Maintenance is scheduled before breakdowns occur, reducing downtime, repair 
costs, and improving productivity.
