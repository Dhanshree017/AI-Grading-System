A-1. Explain the Random Forest algorithm in detail. Describe its working, advantages, 
and disadvantages. 
Random forest is like forest full of trees but not real trees, they are computer trees. 
Model take many decision trees and mix them together to make one big tree boss. It 
make random decision for split and result. 
It work like first take data, then divide small, then train many trees on each piece. 
Then in the end, it do voting or average. If more trees say “yes,” final answer also 
“yes.” 
Advantages: 
1. Accuracy is okay okay, not too bad. 
2. It handle missing data little bit. 
3. Not overfit so much if forest big. 
4. Easy to make because library do everything. 
5. Work for both regression and classification. 
Disadvantages: 
1. Slow like elephant when many trees. 
2. Hard to understand what happen inside. 
3. Take much memory. 
4. Sometimes random give different answer. 
A-2. What is Backpropagation? Explain each step in detail. 
Backpropagation is when neural network feel guilty and go back to fix mistakes. It is 
like teacher scold and student correct note. 
Steps: 
1. Forward pass – we put input, get output, and model guess. 
2. Compare output and actual answer, find error. 
3. Send error backward, layer by layer. 
4. Change weight little by little using gradient. 
5. Do again many time until model stop crying. 
It use chain rule, but I forgot exact formula. Basically, it say which weight wrong and 
fix them. Used in deep learning. 
A-4. Describe Recurrent Neural Networks (RNNs) and their applications in sequence 
modeling. 
RNN is neural network that remember something from past like small memory 
brain. It send previous output as input to next step. 
It is used when order of data matter like sentence, time, weather, etc. 
Applications: 
1. Language translation. 
2. Speech recognition. 
3. Text prediction. 
4. Music generation. 
5. Stock prediction (maybe wrong sometimes). 
Problem is it forget long memory, that’s why people made LSTM and GRU to stop 
forgetting. 
A-5. Explain Model Deployment and Monitoring in the ML lifecycle. 
Model deployment mean putting ML model in real world to do work, not just show 
in notebook. 
Steps: 
1. Save model. 
2. Put in API or cloud. 
3. Connect to website or app. 
4. Test if output coming. 
5. Monitor if model working fine or becoming stupid. 
Monitoring means check accuracy, drift, new data pattern, etc. If model go old, we 
retrain again. 
If we not monitor, it may start giving wrong answer and no one know until boss 
complain. 
A-6. Explain Normalization vs Standardization with examples. 
Normalization is when we put data between 0 and 1. Example: divide by max value. 
Standardization is when we make mean 0 and standard deviation 1. 
Example: if height in cm, normalize make 0.5 maybe, standardize make negative or 
positive number. 
Normalization used in neural network, standardization in linear regression often. 
Both make data behave better but different math.

Logistic regression is classification model that predict yes or no. It use sigmoid 
function to convert linear number to probability. 
Formula is p = 1 / (1 + e^-z), where z = w*x + b. 
Use cases: spam detection, disease prediction, loan approval, etc.
