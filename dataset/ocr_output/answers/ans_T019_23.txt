A-a) Define Machine Learning. Explain how it differs from traditional programming with 
a simple example. 
Definition: Machine Learning is the discipline of designing algorithms and models that 
automatically discover patterns and relationships in data and improve their performance with 
experience, enabling predictions or decisions without being explicitly programmed for each 
case. 
How it differs from traditional programming: In traditional programming a developer 
writes explicit rules (if–then instructions) that map inputs to outputs; correctness depends on 
the completeness and correctness of those rules. In machine learning the developer provides 
data and an objective (for example, minimize prediction error) and the learning algorithm 
infers the mapping from inputs to outputs. Thus the locus of knowledge moves from hand
coded rules to data-driven models that generalize from examples. 
Simple example: To detect spam in email, a traditional program would require a human to 
list rules like “if the message contains X phrase or comes from domain Y, mark spam.” A 
machine-learning approach trains a classifier on many labeled emails (spam and non-spam); 
the model automatically learns combinations of words, sender patterns, and structural signals 
that indicate spam, including subtle patterns a human rule writer might miss. The ML model 
can adapt as new kinds of spam appear by retraining on fresh labeled examples. 
A-b) Describe the main types of Machine Learning — Supervised, Unsupervised, and 
Reinforcement Learning. Give one example for each. 
Supervised Learning: Supervised learning uses labeled examples (inputs paired with 
desired outputs) so the model learns a mapping from features to targets. The goal is accurate 
prediction on new, unseen inputs. Typical tasks include classification and regression. 
Example: Predicting house prices (regression) from features like area, number of rooms, and 
location, using a dataset of past sales with known prices. 
Unsupervised Learning: Unsupervised learning works with unlabeled data and seeks to 
discover structure — clusters, low-dimensional representations, association rules, or density 
estimates. There is no single “correct” output; success is measured by usefulness of the 
discovered structure. 
Example: Customer segmentation by purchase behavior (clustering) to identify marketing 
cohorts without prior labels. 
Reinforcement Learning: Reinforcement learning involves an agent interacting with an 
environment, choosing actions, and receiving scalar rewards. The agent’s objective is to 
learn a policy that maximizes cumulative reward over time. This framework naturally suits 
sequential decision problems where actions affect future states and rewards. 
Example: Training an autonomous drone to navigate cluttered spaces by trial and error—
receiving positive reward for reaching waypoints and negative reward for collisions. 
A-c) What is a dataset in Machine Learning? Explain training data, testing data, and 
validation data with simple illustrations. 
Dataset definition: A dataset is a structured collection of examples used for learning and 
evaluation; each example typically contains a set of input features and, in supervised tasks, a 
target label. Datasets can be tabular, textual, image-based, time series, or multimodal. 
Training data: The subset of the dataset used to fit the model’s parameters. During training 
the algorithm repeatedly sees these examples and adjusts internal parameters to reduce 
prediction error. Illustration: If you have 10,000 labeled images, you might use 7,000 images 
to teach the model what each class looks like. 
Validation data: A held-out subset used during development to tune hyperparameters, 
compare model variants, and decide when to stop training. It helps approximate how well the 
model will perform on unseen data without contaminating final evaluation. Illustration: 
From 10,000 images, use 1,500 images to choose model architecture and hyperparameters. 
Testing data: A final, separate subset used only once after all training and tuning are 
complete to estimate the model’s true generalization performance. It must not influence 
training or validation decisions. Illustration: Keep 1,500 images aside to report the final 
accuracy in a reproducible way. 
Practical note: Choose splits to preserve data distribution (stratified sampling for class 
balance) and, for time-series tasks, use time-aware splits to avoid leakage from future to past. 
A-e) What is a model in Machine Learning? Explain how a model learns patterns from 
data during training. 
What a model is: A machine-learning model is a parameterized function or computational 
structure (e.g., a linear equation, a neural network, a decision tree) that maps inputs 
(features) to outputs (predictions). The model’s parameters encode the knowledge it has 
learned about the relationship between features and targets. 
How learning happens: Learning proceeds by defining an objective (loss) that quantifies 
the difference between the model’s predictions and the true targets on training data. The 
training algorithm iteratively adjusts the model’s parameters to minimize this loss. In 
supervised settings this typically involves: 
1. Forward pass: Compute model predictions for a batch of training examples. 
2. Loss computation: Measure error using a chosen loss function (e.g., cross-entropy for 
classification, MSE for regression). 
3. Backward pass / update step: Use an optimization method (e.g., gradient descent 
variants) to compute parameter updates that reduce the loss. 
4. Iteration: Repeat over many examples/epochs until performance stabilizes or 
validation stops improving. 
During this process the model captures statistical regularities (correlations, conditional 
dependencies) present in the training data. Good models learn generalizable patterns rather 
than memorizing idiosyncratic noise; techniques such as regularization, early stopping, and 
cross-validation help guide the model toward patterns that transfer to unseen data

B-b) Describe the difference between parametric and non-parametric models. Give 
suitable examples of each and explain when to use them. 
Parametric models: 
Parametric models assume a fixed number of parameters and a specific functional form. 
Their complexity does not grow with the size of the dataset. They are fast to train, easier to 
interpret, and usually require less data. 
Examples: Linear regression, logistic regression, Naive Bayes. 
When to use: 
 When the dataset is relatively small. 
 When interpretability is important. 
 When underlying relationships can be approximated with simple functional forms. 
Non-parametric models: 
Non-parametric models do not assume a fixed structure; their complexity grows with data 
size. They can capture highly flexible patterns but are often computationally more expensive. 
Examples: k-Nearest Neighbors, Decision Trees, Random Forests. 
When to use: 
 When the data distribution is complex and unknown. 
 When large amounts of training data are available. 
 When flexibility and capturing fine-grained structure are more important than 
interpretability. 
Key difference: 
Parametric models learn a small set of parameters that summarize the entire dataset, whereas 
non-parametric models rely heavily on the data itself to make predictions, allowing higher 
adaptability at the cost of efficiency. 
B-c) What is inductive bias? Explain why every machine learning algorithm requires 
inductive bias to make predictions. 
Definition: 
Inductive bias is the set of assumptions a learning algorithm uses to generalize beyond the 
training data. Since no amount of finite data can cover all possible situations, the algorithm 
needs assumptions about what kinds of patterns are likely or desirable. 
Why inductive bias is necessary: 
1. Enables generalization: Without inductive bias, a model could treat unseen inputs in 
infinitely many ways. Bias guides the model toward patterns it believes are 
meaningful. 
2. Reduces the hypothesis space: By embedding assumptions, the algorithm restricts its 
search to hypotheses that are plausible and manageable, improving both learning 
speed and accuracy. 
3. Prevents overfitting: Proper inductive bias helps avoid hypotheses that fit noise in 
the training data. 
4. Reflects domain knowledge: Certain biases—such as smoothness, sparsity, or 
preference for simpler functions—align with real-world phenomena, making 
predictions more reliable. 
Examples of inductive bias: 
 Linear models assume relationships are approximately linear. 
 Convolutional Neural Networks assume local spatial patterns matter. 
 Decision trees assume data can be split into meaningful subregions. 
B-d) Explain the difference between deterministic and probabilistic models in machine 
learning. Provide examples. 
Deterministic models: 
Deterministic models produce a single fixed output for every input. They do not represent 
uncertainty; given the same input, the output is always identical. These models interpret the 
relationship as precise and unambiguous. 
Examples: 
 Standard decision trees that assign a single class label. 
 Rule-based expert systems. 
Use cases: Problems where boundaries are sharp, interpretability is needed, or 
uncertainty is minimal. 
Probabilistic models: 
Probabilistic models express predictions in terms of probability distributions. They quantify 
uncertainty and describe how likely each outcome is given the input. These models are 
especially useful in noisy environments. 
Examples: 
 Naive Bayes, which outputs class probabilities. 
 Bayesian networks that model dependencies between variables. 
Use cases: Medical diagnosis, risk estimation, forecasting, and any scenario where 
handling uncertainty is essential. 
Key distinction: 
Deterministic models provide one answer; probabilistic models provide a distribution of 
possible answers along with confidence measures. 
B-e) Describe the steps involved in building a simple ML model, from data collection to 
evaluation. 
1. Data Collection: 
Gather raw data from relevant sources such as databases, sensors, surveys, or logs. Data must 
be representative of the problem and diverse enough to avoid bias. 
2. Data Preprocessing: 
This involves cleaning missing values, removing duplicates, encoding categorical variables, 
normalizing numerical features, and handling outliers. Proper preprocessing ensures data 
quality and prepares the dataset for modeling. 
3. Feature Selection & Engineering: 
Identify the most relevant features and create new ones if necessary. Transformations such as 
scaling, combining variables, or extracting meaningful attributes can significantly improve 
performance. 
4. Model Selection and Training: 
Choose an appropriate algorithm (e.g., decision tree, logistic regression, SVM) based on 
problem type and dataset characteristics. Train the model using training data, tuning its 
parameters to minimize error. 
5. Validation & Hyperparameter Tuning: 
Use a validation set or cross-validation to adjust hyperparameters like tree depth, learning 
rate, or number of neighbors. This ensures the model generalizes instead of memorizes. 
6. Evaluation: 
Assess the model using the test dataset. Choose metrics appropriate to the task—accuracy for 
classification, MAE/MSE for regression. Interpret performance and compare with baseline 
models. 
7. Deployment (optional but common): 
Once validated, the model is integrated into applications where it makes predictions on new 
data.

C-a) Explain the term "Algorithm" in Machine Learning. Give examples of any two 
commonly used ML algorithms. 
Meaning of an algorithm in ML: 
An algorithm in machine learning is a systematic procedure or set of rules that a model 
follows to learn patterns from data. It defines how the model analyzes input features, updates 
internal parameters, and produces predictions. An ML algorithm does not store the data itself 
but extracts meaningful structure from it through repeated learning steps. 
Role in ML: 
 It determines how the model processes numerical and categorical features. 
 It guides how parameters are adjusted to reduce errors. 
 It defines the decision-making strategy a model uses for classification, regression, 
clustering, or optimization tasks. 
Two commonly used algorithms: 
1. Decision Tree Algorithm: 
o Learns patterns by recursively splitting data into branches based on feature 
conditions. 
o Produces an interpretable tree structure useful for classification or regression 
tasks. 
2. k-Nearest Neighbors (KNN): 
o Predicts outputs by examining the closest data points in the feature space. 
o Simple yet effective for pattern recognition, especially when local similarity is 
important. 
C-b) What is Data Preprocessing? Describe why it is important in building an ML model. 
Definition: 
Data preprocessing refers to the set of techniques used to convert raw, imperfect, and 
unorganized data into a clean and structured format suitable for machine learning. It includes 
cleaning, transforming, normalizing, encoding, and organizing data before feeding it into a 
model. 
Why it is important: 
1. Improves Data Quality: Real-world data often contains missing values, noise, 
duplicates, and inconsistencies. Preprocessing removes or corrects them, ensuring 
reliability. 
2. Enhances Learning Efficiency: Proper scaling and encoding allow algorithms to 
operate efficiently, especially for distance-based or gradient-based methods. 
3. Reduces Model Bias: By balancing skewed distributions or handling imbalanced 
classes, preprocessing helps models learn fair and accurate decision boundaries. 
4. Boosts Predictive Performance: Models trained on processed data produce more 
stable, accurate, and generalizable results. 
5. Ensures Compatibility with Algorithms: Many algorithms require normalized 
numbers, encoded categories, or transformed text formats; preprocessing ensures these 
requirements are met. 
C-d) What is Model Evaluation? Describe any two basic evaluation metrics used in ML. 
Definition: 
Model evaluation is the process of assessing how well a trained machine learning model 
performs on unseen data. It determines whether the model generalizes effectively, identifies 
weaknesses, and helps compare multiple models objectively. 
Two basic evaluation metrics: 
1. Accuracy (for classification): 
Measures the proportion of correct predictions out of all predictions. It is useful when 
class distribution is balanced and errors carry equal importance. 
2. Mean Absolute Error (MAE) (for regression): 
Represents the average absolute difference between predicted values and actual 
values. It is intuitive, easy to interpret, and less sensitive to large outliers than squared
error metrics. 
Evaluation ensures that models are not only fitting training data but also performing reliably 
in real-world situations. 
C-e) Define Overfitting. Explain why it occurs and mention two simple ways to reduce it. 
Definition of Overfitting: 
Overfitting occurs when a machine learning model learns training data too precisely, 
including noise, rare patterns, and random fluctuations. As a result, it performs extremely 
well on training data but poorly on new, unseen data. 
Why it occurs: 
 The model is overly complex relative to the amount or quality of data. 
 The training set contains noise or irrelevant patterns that the model mistakenly 
interprets as meaningful. 
 Insufficient regularization or improper model constraints allow the model to fit every 
detail of the training set instead of capturing the true underlying trend. 
Two ways to reduce overfitting: 
1. Use of Regularization: Techniques like weight penalties or model constraints prevent 
excessive complexity and encourage simpler, more general patterns. 
2. Increasing Training Data: More data helps models identify consistent, reliable trends 
instead of memorizing noise.

D-a) What is training data? How is it used in building a model? 
1. Training data is the portion of the dataset used to teach a machine learning model the 
underlying relationships between inputs and outputs. 
2. It contains examples with known labels or outcomes, allowing the model to learn 
patterns through repeated adjustments of internal parameters. 
3. The model evaluates how far its predictions deviate from correct labels and improves 
by minimizing these errors during training cycles. 
4. Training data forms the foundation for establishing the model’s decision boundaries or 
numerical mappings. 
5. High-quality, diverse training data helps the model generalize better to unseen 
samples. 
6. Insufficient or biased training data leads to inaccurate or skewed learning, reducing 
real-world performance. 
D-b) Define prediction in machine learning. 
1. Prediction refers to the output or decision that a trained machine learning model 
generates for new, unseen input data. 
2. It represents the model’s attempt to apply the patterns learned during training to future 
examples. 
3. Predictions can be numerical values (regression), class labels (classification), or 
probability distributions depending on the task. 
4. A model evaluates the input features and selects the most plausible outcome based on 
learned relationships. 
5. Prediction quality depends heavily on training data, model architecture, and 
generalization ability. 
6. Accurate predictions indicate that the model has successfully captured meaningful 
patterns rather than memorizing noise. 
D-c) What is a decision tree in simple terms? 
1. A decision tree is a model that makes predictions by dividing data into branches based 
on feature-driven decisions. 
2. It uses a sequence of questions, each splitting the data into smaller, more 
homogeneous groups. 
3. Internal nodes represent decisions, branches represent outcomes of those decisions, 
and leaf nodes give final predictions. 
4. It mirrors human decision-making by breaking problems into smaller logical steps. 
5. Decision trees handle numerical and categorical data without requiring complex 
preprocessing. 
6. They offer high interpretability, allowing users to trace how a prediction was made. 
D-d) Mention any two challenges faced when collecting ML data. 
1. Real-world data often contains missing values or incomplete records, requiring extra 
cleaning effort. 
2. Data may be inconsistent across sources due to differing formats, structures, or 
measurement systems. 
3. Collecting labeled data is costly and time-consuming, especially when expert labeling 
is required. 
4. Privacy and ethical constraints limit access to sensitive information such as medical or 
financial records. 
5. Large-scale data acquisition may need extensive storage, bandwidth, and processing 
resources. 
6. Environmental factors such as sensor failures or recording errors lead to noisy or 
corrupted data. 
D-e) What is model generalization? 
1. Model generalization is the ability of a machine learning model to perform well on 
new, unseen data rather than only on the data it was trained on. 
2. It reflects how effectively a model captures underlying patterns instead of memorizing 
training examples. 
3. Good generalization requires balanced model complexity: neither too simple nor 
overly complex.
