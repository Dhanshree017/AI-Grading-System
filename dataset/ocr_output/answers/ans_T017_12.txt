B-1. Challenges in ML & Solutions 
Major challenges in machine learning include data quality and quantity, overfitting and 
underfitting, model bias, computational costs, and model interpretability. Solutions 
involve robust data preprocessing, using techniques like cross-validation and regularization, 
addressing bias through representative datasets and fair data collection, optimizing models 
for computational efficiency, and employing explainable AI (XAI) methods to make models 
more transparent.  
Data-related challenges 
 Challenge: Poor data quality, insufficient data, or non-representative data can all lead to 
inaccurate or biased models. 
 Solutions: 
o Implement strong data preprocessing techniques to clean, filter, and handle missing or noisy 
data. 
o Use data augmentation and synthetic data generation to supplement existing datasets. 
o Ensure the training data accurately reflects the real-world distribution to prevent a lack of 
representativeness.  
Model-related challenges 
 Challenge: Overfitting occurs when a model is too complex and learns noise, while 
underfitting occurs when it is too simple to capture patterns. 
 Solutions: 
o Use methods like cross-validation, regularization, and early stopping to prevent overfitting. 
o Simplify the model or add more features to address underfitting.  
Bias and ethical challenges 
 Challenge: Data bias can result in unfair or discriminatory model outputs. 
 Solutions: 
o Carefully curate and balance training data to ensure it represents the broader population 
fairly. 
o Implement bias mitigation strategies and continuously monitor models for biased outcomes 
after deployment. 
o Address ethical considerations, such as privacy and algorithmic fairness 
B-2. What is Regularization? Explain its types 
Regularization is a machine learning technique that prevents overfitting by penalizing model 
complexity, improving its ability to generalize to new data. Common types include L1 
(Lasso) regularization, which can zero out feature weights, L2 (Ridge) regularization, which 
shrinks weights toward zero, and Dropout, which randomly deactivates neurons during 
training.  
Types of regularization 
 L1 Regularization (Lasso): Adds the absolute value of the coefficients to the loss function. 
This encourages sparsity, meaning some feature coefficients are driven to exactly zero, 
which can be used for feature selection. 
 L2 Regularization (Ridge): Adds the square of the coefficients to the loss function. This 
prevents large weights by shrinking them towards zero, but it doesn't force them to be 
exactly zero. 
 Elastic Net: A combination of both L1 and L2 regularization. It penalizes the loss function 
with a combination of both the absolute values and the squares of the coefficients. 
 Dropout: A technique specifically for neural networks where neurons are randomly 
"dropped out" during training. This prevents neurons from becoming too specialized and 
dependent on each other, forcing the network to learn more robust features.
