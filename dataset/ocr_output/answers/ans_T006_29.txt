5. Sigmoid kernel like neural network, sometimes works better.

7. SVR for regression, predict continuous values.

choice important. 
B-5. Explain Decision Tree in detail 
Decision tree is like tree, node questions, leaf answers, split data recursively, used 
classification and regression. Root node start, internal nodes decision, branches 
outcome, leaf final answer. Algorithm split using info gain, gini, stop max depth or few 
samples. 
Applications many areas finance, healthcare, marketing, sometimes education, mostly 
prediction, classification. Can predict loan approval, disease detection, customer 
segmentation. 
1. Easy to understand, visualize, simple. 
2. Handle numeric and categorical data, sometimes fail. 
3. Little preprocessing needed, mostly robust. 
4. Recursive split till stopping condition reached, sometimes overfit. 
5. Root node, internal node, branch, leaf node explained above. 
6. Applications many areas, finance, healthcare, marketing, education. 
7. Base for ensemble methods Random Forest, Boosting. 
8. Sometimes overfit, sometimes good performance, repeat idea many times.
