A-1. Define Machine Learning. What is a hypothesis in ML? 
Machine learning is something like teaching a computer how to do work by showing 
examples instead of coding rules. It means the computer learns from data patterns 
and improves its result when we give more data. It helps in tasks like spam email 
checking, image recognition, and movie recommendation. ML uses datasets, 
algorithms, and models to make predictions. 
A hypothesis in machine learning is like a guess or an assumption that the algorithm 
makes to find how input and output are connected. It’s a function that tries to map 
the data correctly. The best hypothesis is the one that makes least error on training 
data. 
Key points: 
1. ML allows automatic improvement by learning. 
2. It focuses on pattern recognition. 
3. A hypothesis is a mathematical representation of relation between X and Y. 
4. Algorithms search for the best hypothesis in hypothesis space. 
5. For example, h(x)=mx+ch(x)=mx+ch(x)=mx+c is a hypothesis in regression.

A-5. Explain types of search in AI. Explain Bidirectional Search in detail. 
Search means finding something from start to goal in AI. Two main searches are 
informed and uninformed. 
 Uninformed Search: Has no knowledge about the goal. It just tries all paths. 
Example: BFS, DFS. 
 Informed Search: Uses some guidance (heuristics). Example: A*, Greedy Search. 
Bidirectional Search means searching from both sides, start and end. When both 
meet, we get solution. Example: If you want to go from city A to city B, one person 
starts from A and one from B and when they meet, you know the path. 
Advantages: faster than single direction. 
Disadvantages: needs more memory and difficult to implement.

B-2. Explain the working of Artificial Neural Networks (ANNs) with architecture and 
learning process. 
Artificial Neural Network is an algorithm which copies how brain works using 
neurons. Each neuron has input, weight, activation, and output. The network has 
layers — input layer, hidden layer, and output layer. 
Working process: 
1. Input features enter input layer. 
2. Each connection has a weight. 
3. Weighted sum is calculated and passed to activation function. 
4. Output is generated and compared with real output. 
5. The difference (error) is reduced using back propagation. 
Learning process continues until the error is minimum. Example: ANN can be used 
for image recognition or stock prediction 
B-4. Explain unsupervised learning algorithms like K-Means Clustering and 
Hierarchical Clustering. 
K-Means divides data into K groups based on similarity. Each cluster has a center 
(centroid). The algorithm repeats steps of assigning points and updating centroids. 
Example: grouping customers by spending pattern. 
Hierarchical clustering builds tree-like structure. It can be agglomerative (bottom-up) 
or divisive (top-down). Output is dendrogram.

2. Calculate covariance matrix.
