A-1. How Reinforcement learning is different from Supervised learning? 
Reinforcement learning is different from supervised learning because reinforcement 
learning model learn by reward and punishment it try many things and learn from 
result reward given for good action and punishment for bad action, model learn slowly 
and sometimes fail but learn new things. Supervised learning different because teacher 
give correct answer and model compare prediction with correct answer and reduce 
error and learn. So both learning but method different, goal same like improve 
prediction or decision but way different. Reinforcement learning mostly used in games 
and robotics where result not known, supervised learning used in prediction, 
classification, regression. Actually supervised learning model learn from dataset and 
reinforcement learning learn by trying and reward and punishment and both try 
improve performance but differently and sometimes confuse but different. 
1. RL learn from reward punishment, supervised learn from dataset. 
2. Supervised know correct output, RL not know correct output. 
3. RL trial error, supervised direct learning from dataset. 
4. RL used decision making, games, robotics, supervised used in prediction, 
classification, regression. 
5. Both improve performance, RL step by step, supervised from dataset. 
6. RL slower sometimes because explore many actions, supervised faster. 
7. Supervised mapping input output, RL indirect mapping reward. 
RL take more time to learn, sometimes fail, supervised more stable, RL explore many 
possibilities, sometimes reward small or big, model learn accordingly, overall different 
approach but both machine learning. 
A-2. Define the term overfitting and one solution for it 
Overfitting when model memorize training data too much and learn noise so when 
new data come model fail predict, perform badly. Overfitting happen when model too 
complex, dataset too small, trained too long. Overfitting problem in ML mostly deep 
learning because many parameters and layers overfit easy. Overfitting bad reduce 
generalization, model fail unseen data, model think correct because training 
memorized, noise learned. 
Solution regularization L1 L2 reduce complexity, dropout also help, early stopping 
help, adding more data reduce overfitting, cross-validation check performance avoid 
overfit, many ways possible reduce overfitting sometimes all methods together help. 
1. Overfitting memorize training and noise. 
2. Happens small dataset, deep learning, complex model. 
3. Reduces generalization, fail new data. 
4. Solution regularization L1 L2. 
5. Dropout, early stopping, more data, cross-validation help. 
6. Overfitting common in ML. 
7. Sometimes overfit even after solution. 
Overfitting tricky, sometimes still happen, sometimes model perform good, depends 
on data, model, important problem, avoid for better performance.

samples. 
Applications many areas finance, healthcare, marketing, sometimes education, mostly 
prediction, classification. Can predict loan approval, disease detection, customer 
segmentation. 
1. Easy to understand, visualize, simple. 
2. Handle numeric and categorical data, sometimes fail. 
3. Little preprocessing needed, mostly robust. 
4. Recursive split till stopping condition reached, sometimes overfit. 
5. Root node, internal node, branch, leaf node explained above. 
6. Applications many areas, finance, healthcare, marketing, education. 
7. Base for ensemble methods Random Forest, Boosting. 
8. Sometimes overfit, sometimes good performance, repeat idea many times.
