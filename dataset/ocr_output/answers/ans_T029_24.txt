A-a. Explain the concept of model robustness in machine learning. 
Model robustness in machine learning is a model's ability to maintain stable, accurate 
performance despite real-world challenges like noisy data, unexpected shifts in data 
distribution (e.g., lighting changes, different user groups), or deliberate adversarial attacks, 
ensuring it generalizes reliably beyond its training set, not just performing well on clean, 
familiar data. It's crucial for trustworthy AI in safety-critical systems (like self-driving cars) 
where brittle, high-accuracy-but-fragile models can fail catastrophically.  
Key Aspects of Robustness 
 Generalization: Goes beyond high accuracy on training data to performing well on unseen 
data from different, real-world conditions. 
 Resistance to Perturbations: Handles noise, missing data, slight rotations, or faint images 
without significant performance drops, unlike models prone to overfitting. 
 Data Distribution Shifts: Adapts to changes like seasonal variations in weather for image 
recognition or evolving user behaviors over time (data drift). 
 Adversarial Attacks: Stays resilient against malicious inputs designed to fool it (e.g., small 
pixel changes to misclassify an image).  
Why It Matters 
 Trust & Safety: Essential for AI in autonomous vehicles, medical diagnostics, and finance, 
where errors have serious consequences. 
 Real-World Reliability: Ensures models work consistently in dynamic environments, not 
just controlled lab settings.  
How It Differs from Accuracy 
 Accuracy: Measures performance on clean, typical test data (e.g., 99% on standard digits). 
 Robustness: Measures performance under stress (e.g., faint, rotated digits or adversarial 
examples). A model can be accurate but not robust (brittle).  
Examples of Data Shifts 
 Natural Shifts: Different lighting, camera angles, or new types of objects (e.g., recognizing 
an unfamiliar fruit). 
 Adversarial Shifts: Intentional small modifications to input data to cause misclassification. 
 Performative Shifts: Changes in user behavior because of the model's predictions, creating 
feedback loops.  
In essence, a robust model doesn't just learn patterns; it learns the underlying concepts well 
enough to handle the unpredictable nature of the real world.

A-c. Discuss the challenges involved in scaling machine learning systems. 
Explain issues related to data size, model complexity, infrastructure, and maintenance.** 
Answer: 
Scaling machine learning systems involves expanding models and infrastructure to handle 
increasing data volumes, computational demands, and real-world usage. While scaling 
improves capability, it introduces several challenges. 
One major challenge is data size, as large datasets require efficient storage, processing, and 
management. Handling massive data increases memory and computational costs. Model 
complexity also grows with scale, leading to longer training times and difficulty in 
optimization. Complex models require powerful hardware such as GPUs or distributed 
systems. 
Infrastructure challenges include the need for cloud computing, parallel processing, and 
reliable deployment pipelines. Maintaining system performance while controlling cost 
becomes difficult. Maintenance challenges involve monitoring model behavior, handling 
data drift, retraining models, and updating systems without downtime. Addressing these 
challenges is essential for sustainable and scalable ML solutions. 
A-d. Explain the concept of transfer of knowledge in machine learning. 
Discuss how previously learned information can improve learning in new tasks.** 
Answer: 
Transfer of knowledge in machine learning refers to the process of utilizing knowledge 
gained from one task to enhance learning performance in a new but related task. This 
approach reduces the need to train models from scratch. 
Previously learned features, patterns, or representations can be reused when tasks share 
similarities. This improves learning speed and reduces dependency on large labeled datasets. 
Transfer learning is widely used in fields such as image recognition and natural language 
processing, where pretrained models already understand basic patterns. 
Fine-tuning allows the transferred model to adapt to the new task by adjusting parameters 
slightly. This improves accuracy and efficiency. Transfer of knowledge is especially 
valuable when training data is limited and computational resources are constrained. 
A-e. Describe the responsibilities of an ML engineer after model deployment. 
Explain tasks related to monitoring, updating, documentation, and ethical compliance.** 
Answer: 
After deployment, an ML engineer is responsible for ensuring that the model continues to 
function effectively, ethically, and reliably in real-world conditions. 
Monitoring involves tracking model performance, detecting accuracy degradation, and 
identifying data drift. Updating and retraining are necessary to keep the model relevant as 
new data becomes available. Documentation ensures transparency by recording model 
design, data sources, assumptions, and limitations, which helps in maintenance and audits. 
Ethical compliance is a critical responsibility, including fairness, bias mitigation, data 
privacy, and legal adherence. ML engineers must ensure that deployed models do not cause 
harm or discrimination. These post-deployment responsibilities are essential for long-term 
success and trust in machine learning systems.
