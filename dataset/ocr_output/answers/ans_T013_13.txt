B-3. Explain K-Means Clustering algorithm with step-by-step working and 
advantages. 
K means is a clustering algorithm used in unsupervised learning. It divide 
data into groups called cluster. First we choose number of cluster K. 
Then algorithm pick random point as center called centroid. Then assign 
each data point to nearest centroid using distance formula maybe 
Euclidean. 
Then calculate new centroid mean of all points in that cluster. Repeat till 
not change. 
Advantage are it is simple, fast, and easy. But disadvantage also many 
like we have to choose K before, and if data noisy then not work. But 
mostly used because easy to code.

Early stopping is when we stop training before it get too much fit on

So it save time and prevent overfitting because model not memorize 
noise. It is like stopping student before he start overthinking question.

B-5. Explain Bias–Variance Tradeoff. Show how it impacts model 
generalization. 
Bias variance tradeoff mean two enemy in machine learning. Bias means 
model too simple and variance mean model too complex. If high bias 
model underfit, if high variance model overfit. 
So we need balance between both. It impact generalization because if any 
one side high, model not perform good on new data. So we try to find 
sweet spot by cross validation or change model complexity. In exam it 
look like formula bias² + variance + noise.
