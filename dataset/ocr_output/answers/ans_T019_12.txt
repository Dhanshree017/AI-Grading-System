A-d) Explain the difference between Classification and Regression with suitable examples. 
Classification and Regression are two fundamental types of supervised machine learning 
tasks, distinguished by the nature of their predicted output. 
Classification 
Classification models predict discrete, categorical labels or classes. The output is a distinct 
category from a predefined set. 
 Example:  
Predicting whether an email is "spam" or "not spam". Here, the output is one of two distinct 
categories. 
 Example:  
Classifying images of animals into "cat", "dog", or "bird". The output is one of several 
distinct animal types. 
 Key characteristic:  
The model learns to draw decision boundaries to separate data points into different classes. 
Regression 
Regression models predict continuous numerical values. The output is a numerical quantity 
that can fall anywhere within a range. 
 Example:  
Predicting the price of a house based on its size, location, and number of bedrooms. The 
output is a continuous numerical value representing the price. 
 Example:  
Forecasting the daily temperature based on historical weather data. The output is a 
continuous numerical value representing the temperature. 
 Key characteristic:  
The model learns a mapping function to find a "best fit" line or curve that describes the 
relationship between input features and the continuous output. 
A-e) What is a model in Machine Learning? Explain how a model learns patterns from data 
during training. 
A machine learning model is a trained computer program that finds and uses patterns in data 
to make predictions or decisions on new, unseen data. During training, an algorithm analyzes 
a dataset, and the model's internal parameters are repeatedly adjusted to minimize the 
difference between its predictions and the actual data labels, a process of learning through 
trial and error to achieve better accuracy.  
How a model learns during training  
 Initialization: Before training, an algorithm is a set of rules with random or initial 
parameters. For example, an algorithm for predicting output  
 Pattern detection: The algorithm is fed a large dataset of examples, with both the 
inputs and their corresponding correct outputs (labels). It tries to find the mathematical 
relationship between the inputs and outputs, which can be seen as finding the correct 
"coefficients" or "parameters". 
 Making predictions: The model uses its current parameters to make a prediction for a 
given input from the training data. 
 Evaluating the error: The model's prediction is compared to the actual, correct 
output from the dataset to calculate an error, also known as a loss. 
 Parameter adjustment: Based on the error, the algorithm adjusts its internal 
parameters to reduce the error on the next attempt. This is an iterative process where 
the model "learns" by continuously tweaking its parameters to get closer and closer to 
the correct answers. 
 Completion: This training loop repeats thousands or millions of times. When the 
model's predictions are consistently accurate enough, the training is complete, and the 
final set of parameters defines the trained model. At this point, the model is a file that 
can be used to make predictions on new data it has never encountered before.

C-a) Explain the term "Algorithm" in Machine Learning. Give examples of any two commonly 
usCed ML algorithms. 
In Machine Learning, an algorithm refers to a set of well-defined, step-by-step instructions 
or rules that a computer system follows to learn from data and perform a specific task 
without being explicitly programmed for every scenario. These algorithms enable the system 
to identify patterns, make predictions, or discover insights within datasets.  
Here are examples of two commonly used Machine Learning algorithms: 
 Linear Regression: 
 Description: Linear Regression is a supervised learning algorithm used for regression tasks, 
meaning it predicts a continuous output value based on one or more input features. It models 
the relationship between the independent variables (features) and the dependent variable 
(target) as a linear equation. The algorithm aims to find the "best-fit" line (or hyperplane in 
higher dimensions) that minimizes the sum of squared differences between the predicted and 
actual values. 
 Example: Predicting house prices based on features like square footage, number of 
bedrooms, and location. 
 Decision Trees: 
 Description: Decision Trees are versatile supervised learning algorithms used for both 
classification and regression tasks. They work by recursively partitioning the data into 
subsets based on the values of input features, forming a tree-like structure. Each internal 
node represents a test on an attribute, each branch represents an outcome of the test, and each 
leaf node represents a class label (for classification) or a predicted value (for regression). 
 Example: Classifying whether an email is spam or not based on keywords, sender, and other 
email characteristics.
