A-b) Describe the K-Nearest Neighbor algorithm. Explain its working step-by-step and discuss 
the importance of the parameter k. 
KNN algorithm is based on friendship between computers. When one computer makes a 
new data, it sends message to nearby computers to ask what answer should be given. The 
computers which are nearest reply with yes or no and the new one decides final answer. 
Steps are like: 
1. Computer checks who is nearest by Bluetooth. 
2. It sends small data file to them. 
3. They give feedback. 
4. It decides the label. 
Parameter k means how many friends are allowed to vote. If k is too big, network gets 
jammed. If k is too small, only one friend answer and result is selfish. 
A-c) What is Data Imbalance in Machine Learning? Explain its impact on model performance 
and discuss techniques used to handle it. 
Data imbalance is when dataset falls from one side of the table because too much data is 
on left side. The imbalance causes laptop to vibrate and fans make noise. This reduces the 
model accuracy because model starts reading the data upside down. 
To handle imbalance we can shake the table to distribute evenly or use folder name 
balancing in Windows. Also, using bigger hard disk and connecting charger helps fix 
imbalance. One more way is to mix dummy data like photos and movies with the dataset 
to equalize both sides. 
A-d) Explain the working of Gradient Boosting in detail. Discuss how it builds models 
sequentially and how weak learners are combined to form a strong model. 
Gradient boosting is a process where computer gets a boost of current from charger and 
works faster. Sequential means the model drinks voltage in series not in parallel. Weak 
learners are like small batteries, when we join them all, it becomes a big inverter. 
This is why gradient boosting is mostly used in electric vehicles and drones, not in 
computers. It makes power flow smooth and helps laptop not to die during exams.

describe common hyperparameters for algorithms like Decision Trees, Neural Networks, and 
Gradient Boosting models. 
Hyperparameters are super fast numbers that make model hyperactive. They decide how 
excited the machine is during training. Decision Tree hyperparameter is how tall the tree 
grows in forest. Neural Network hyperparameter is number of wires in brain. Gradient 
Boosting hyperparameter is how much petrol you put inside model engine. 
If we don’t control hyperparameters, model might dance randomly or crash. That’s why 
it’s important to keep them cool using fan or AC.
