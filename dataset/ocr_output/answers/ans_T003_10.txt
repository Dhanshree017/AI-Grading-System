B-1. Explain the bias-variance tradeoff. 
The bias-variance tradeoff is, like, a very important thing in machine 
learning but sometimes it is confusing. So basically, when we build a 
model, there are two main types of errors that can happen: bias and 
variance, plus some error we can’t do anything about called irreducible 
error. 
 Bias: 
o Bias is like the error from being too simple. 
o High bias happens when model can’t learn the pattern well, 
and it underfits. 
o Example: Using a straight line when the real data is curved. 
o High bias → model is too rigid, doesn’t change even if data is 
complex. 
 Variance: 
o Variance is error from being too sensitive to training data. 
o High variance happens when the model memorizes training 
data including noise, so it overfits. 
o Example: Using a very deep tree that fits every little 
fluctuation in training data. 
 Tradeoff: 
o Reducing bias usually increases variance. 
o Reducing variance usually increases bias. 
o The goal is to find a balance so total error is minimized. 
 Ways to handle it (I think): 
o Cross-validation to see performance on multiple splits 
o Regularization like L1/L2 
o Choosing right model complexity (not too simple, not too 
complex) 
o Ensembles like bagging or boosting 
Honestly, sometimes I get confused, because making model too big 
reduces bias but increases variance, and making it too small reduces 
variance but increases bias. So it’s like walking on a line trying not to fall 
on either side. 
B-2. How does the K-Nearest Neighbors (KNN) algorithm work? 
KNN is one of the simpler algorithms I think. It’s kind of memory-based 
or instance-based. The steps are like: 
 Find the distance between the new point and all points in training 
data (Euclidean, Manhattan, something like that). 
 Pick K nearest points (K is a number you choose). 
 Classification: Look at neighbors’ classes and pick the majority. 
 Regression: Average the neighbors’ values. 
Some important stuff: 
 K small → sensitive to noise → overfit 
 K large → smooth predictions → might underfit 
 Features need scaling, otherwise one feature dominates 
 Can be slow for large data because it calculates distances for all 
points 
 Curse of dimensionality: if too many features, distances get less 
meaningful 
Example: predicting if student passes/fails based on hours studied and 
attendance. We check K nearest students in training data and predict 
based on them. 
B-3. What is dimensionality reduction, and provide examples? 
Dimensionality reduction is when we reduce the number of features while 
keeping important info. It’s useful because too many features can make 
model slow, overfit, or confuse it. 
 Examples: 
o PCA → principal component analysis, keeps most variance 
o LDA → linear discriminant analysis, separates classes 
o t-SNE → visualization, reduces dimensions to 2D or 3D 
o Autoencoders → neural networks compress data into smaller 
representation 
 Benefits: 
o Faster computation 
o Prevents overfitting 
o Easier to visualize 
Example: we have 500 features, reduce to 50 using PCA, and still keep 
95% information. 
 Sometimes I forget exactly how PCA works, but I know it finds 
directions with most variance.

B-5. Explain bagging and boosting. 
Bagging and boosting are ensemble methods. They combine multiple 
models to improve prediction. 
 Bagging: 
o Train many models on different bootstrapped samples 
o Combine predictions (average for regression, majority vote 
for classification) 
o Reduces variance 
o Example: Random Forest 
 Boosting: 
o Train models sequentially 
o Each new model focuses on errors of previous models 
o Reduces bias 
o Example: AdaBoost, XGBoost, Gradient Boosting 
 Differences: 
o Bagging = parallel, reduces variance, stabilizes predictions 
o Boosting = sequential, reduces bias, can overfit if too strong 
 Example scenario: 
o Predict student grades 
o Bagging = multiple random trees on subsets 
o Boosting = sequentially correct errors from previous trees 
Honestly, sometimes I confuse when to use bagging vs boosting. Boosting 
seems better for hard datasets, bagging better for unstable models.
