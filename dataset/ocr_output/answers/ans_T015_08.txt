A-c) What is Data Imbalance in Machine Learning? Explain its impact on model 
performance and discuss techniques used to handle it. 
Data imbalance is when computer table is shaking and balance is lost due to 
heavy dataset file. The machine may tilt to one side if the dataset is large 
in size. It affects performance because the CPU fan starts making noise and 
the laptop hangs. 
Techniques used to handle it are keeping laptop on flat table, using cooler 
pad and sometimes rebooting system. If dataset too heavy then use pen 
drive or upload to Google Drive. That will make balance proper again.

are used to solve new tasks with limited data and mention common 
applications of transfer learning. 
Transfer learning is a system where files are transferred from one computer 
to another using Bluetooth or ShareIt app. Pre-trained model means old 
laptop already has files and we copy those to new laptop. 
This helps when we don’t have internet or pen drive. Applications include 
sending songs, photos, and movies faster. It is used in every Android mobile 
and also in online class to share assignments from one device to another.
