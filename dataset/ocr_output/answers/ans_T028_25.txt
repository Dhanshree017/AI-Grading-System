A-3. You are asked to choose an ML algorithm for a new problem. Explain the factors 
you would consider before selecting the algorithm. 
Selecting an ML algorithm is a strategic decision guided by several crucial factors related to 
the problem type, data characteristics, and practical constraints. There is no single 
"best" algorithm for all problems; the optimal choice is determined by specific 
circumstances.  
Key factors to consider include: 
1. Problem Type and Business Goal 
The first step is to define the objective and the desired output from the model.  
 Supervised Learning (labeled data): 
o Regression: Predicting a continuous numerical value (e.g., house prices, sales forecasting). 
Algorithms include Linear Regression, Decision Trees, and Random Forests. 
o Classification: Predicting a category or label (e.g., spam detection, customer churn 
prediction, medical diagnosis). Algorithms include Logistic Regression, Support Vector 
Machines (SVM), and Neural Networks. 
 Unsupervised Learning (unlabeled data): 
o Clustering: Grouping similar data points to find hidden patterns (e.g., customer 
segmentation, market research). Algorithms include K-Means and Hierarchical Clustering. 
o Dimensionality Reduction: Reducing the number of features while retaining important 
information (e.g., Principal Component Analysis). 
 Reinforcement Learning: Training a model to make a sequence of decisions through trial 
and error, based on a system of rewards and penalties (e.g., game AI, robotics).  
2. Data Characteristics 
The nature of the available data is fundamental to algorithm selection.  
 Data Size: Simpler, high-bias algorithms like Naive Bayes or Linear Regression often 
perform well on smaller datasets, while complex models (e.g., deep learning) typically 
require large amounts of data to reach their full potential. 
 Data Type: Different data types require specialized algorithms. For example, image data 
often uses Convolutional Neural Networks (CNNs), text data uses Recurrent Neural 
Networks (RNNs) or Transformers, and simple numerical or categorical data can use tree
based methods. 
 Data Quality: Noisy data, missing values, or imbalances can affect model performance. 
Robust algorithms like Random Forests or XGBoost can handle imperfections better than 
others, which might require extensive preprocessing. 
 Linearity: If the data has a linear relationship, a linear model (e.g., Linear Regression) may 
suffice. For non-linear, complex relationships, more flexible models like kernel SVMs or 
neural networks are generally more appropriate.  
3. Practical Constraints 
Real-world limitations often influence the final decision.  
 Computational Efficiency & Resources: Some algorithms (e.g., deep neural networks) 
require significant computational power and training time, while others are lightweight and 
fast (e.g., Logistic Regression). Available hardware (CPU/GPU) and time constraints are key 
considerations. 
 Model Interpretability: In domains like finance or healthcare, where understanding the 
decision-making process is critical for compliance and trust, interpretable models (e.g., 
Linear Regression, Decision Trees) are preferred over "black-box" models like deep 
learning. 
 Scalability: Consider if the algorithm can handle future data growth without significant 
performance degradation. 
 Deployment & Maintenance: How easily the model can be integrated into existing systems 
and maintained in the long run is a practical concern.  
Ultimately, the best approach involves an iterative process of starting with simple baseline 
models, experimenting with several algorithms, and using relevant evaluation metrics (e.g., 
accuracy, precision, F1-score, MSE) to compare their performance and select the best fit for 
the specific problem.
