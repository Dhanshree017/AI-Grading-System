A-1. Define AI, What are Domains of Machine Learning 
AI is when computer try to act like human brain. it can think sometimes 
and do work like humans. it learn from data but sometime it confuse. 
Domains of Machine Learning: 
1. Supervised learn – teacher give answer and computer copy.  
2. Unsupervised learn – computer guess itself but sometime fail. 
3. Semi supervised – some teacher some guess, mix. 
4. Deep learning – many brain layer inside, sometime very slow. 
5. Reinforcement learning – computer do wrong get slap, correct get 
candy. 
6. Quantum learn – maybe future thing, not exist much. 
7. Random learn – computer guess randomly. 
8. Online learning – new data come it learn every second. 
9. Hybrid learning – mix of everything, sometimes confuse.

Regression is when computer guess number. Classification is when 
computer guess type like cat or dog. 
Types of Regression: 
1. Linear regression – line straight.  
2. Double regression – maybe two line, unsure. 
3. Multiple regression – many input predict output. 
4. Polynomial – curve line fit data. 
5. Ridge regression – add penalty. 
6. Lasso regression – remove variable maybe. 
7. Random regression – mix forest thing. 
8. Logistic regression – yes/no output. 
9. Time regression – predict tomorrow number. 
Example: Regression predict stock price, classification predict email spam 
or not.
