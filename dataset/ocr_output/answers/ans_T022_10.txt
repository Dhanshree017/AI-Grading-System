A-1. Explain the complete workflow of Feature Engineering. Discuss different types of features and the 
role of feature selection in improving model performance. 
Feature engineering workflow is long but simple steps, I explain: 
1. Understand raw data — look at dataset, types, missing, outliers, distribution, correlations. Know 
domain what columns mean. 
2. Clean data — fix bad values, remove duplicates, impute missings (mean, median, model), handle 
outliers (cap or remove). 
3. Basic transforms — convert datatypes, parse dates, normalize if needed. 
4. Create features — make new columns: ratios (price/quantity), interactions (age × income), 
aggregate (weekly sum), lag features for time-series, text features (TF-IDF) or embeddings. 
5. Encode categoricals — one-hot for small cardinality, target or frequency encoding for many 
categories, or learn embeddings for IDs. Watch leakage in target encoding. 
6. Scale & transform — standardize or min-max scaling for algorithms needing it; log transform 
skewed features. 
7. Feature selection / reduction — remove low-variance, highly correlated (multicollinearity) or 
irrelevant features. Use filter methods (correlation), wrapper (RFE), embedded (L1, tree importance), 
or PCA if need dimension reduction. 
8. Validate features — check on holdout or cross-validation, test that new features improve metrics 
and not leak. 
9. Deploy pipeline — serialize transforms, ensure same transforms used in production, monitor 
features in prod for drift. 
Types of features: numerical (continuous/discrete), categorical (nominal/ordinal), datetime/time-series, 
text, image, derived/interaction, boolean, categorical embeddings. 
Role of feature selection: reduce overfitting, improve generalization, reduce training time, simplify model 
and interpretation. Good selection keeps strong signals and remove noise. 
A-2. Describe the architecture and working of Convolutional Neural Networks (CNNs). Explain how 
convolution, pooling, and feature maps help in image understanding. 
CNN basic architecture: input → conv + activation → pooling → (repeat) → flatten → dense → output. 
Convolution layer: small kernels slide over image computing dot-product. They detect local patterns like 
edges. Filters shared across image so fewer parameters. 
Feature maps: each filter produce one feature map showing activations where pattern found. Early layers 
detect edges, mid layers textures, deeper layers object parts. 
Pooling layer: reduce spatial size (max-pool, avg-pool). It reduces computation and gives small translation 
invariance. Pooling also reduce overfitting. 
Activation: ReLU usually, gives nonlinearity so deep nets can learn complex mapping. 
Fully connected: after conv/pool stack features combined to predict classes. 
How they help image understanding: conv captures local spatial dependencies, hierarchical features built 
layer by layer, pooling keeps most important info and reduces noise. Using many filters lets net learn many 
patterns. Pretrained CNNs (ResNet, VGG) good for transfer learning. 
A-4. Explain the importance of Data Pipelines in machine learning projects. Describe how automation, 
versioning, and data validation improve reliability. 
Data pipelines make process repeatable and reliable. 
Automation: schedule ETL, feature calc, model training so no manual repeat. Helps continuous retrain and 
reduces human mistake. 
Versioning: keep versions of data, code and model so you can reproduce experiments and rollback. Data 
versioning important when dataset change. 
Data validation: checks schema, ranges, null counts, unusual categories; prevents bad data into training. 
Tools or checks raise alerts. 
Other good things: logging, monitoring, testing pipeline steps, and ability to re-run from any stage. 
6. Explain Ensemble Learning in detail. Describe bagging, boosting, and stacking, and compare how 
each method improves model performance in different scenarios. 
Ensemble means combine many models. 
Bagging: bootstrap samples, build many models (e.g., random forest). Reduces variance. Good when base 
learners high variance. 
Boosting: sequentially fit weak learners to residuals (AdaBoost, Gradient Boost). Focus on hard examples, 
reduce bias. Powerful but need regularization. 
Stacking: train different base models, then a meta-model on their predictions. Helps combine strengths. 
Needs careful CV to avoid leakage. 
Comparison: bagging stabilizes, boosting improves accuracy, stacking blends diverse models. Ensembles 
cost more compute and harder to interpret.
