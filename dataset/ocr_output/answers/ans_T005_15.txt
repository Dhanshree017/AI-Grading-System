A-2. Explain the concept of Entropy and Information Gain in the context of building a 
Decision Tree. 
Entropy and Information Gain are the primary metrics used to guide the construction of a 
Decision Tree, determining the optimal feature and split point at each node. 
1. Entropy (Impurity): 
o Concept: Entropy is a measure of randomness, disorder, or impurity within a 
set of data. A node with high entropy (e.g., a mix of 50 percent 'Yes' and 
50 percent 'No' class labels) indicates high disorder and provides little 
information. A node with zero entropy (e.g., 100 percent 'Yes' labels) is 
perfectly pure and requires no further splitting. 
o Role in DT: It quantifies the uncertainty before a split is made. 
2. Information Gain (Reduction in Impurity): 
o Concept: Information Gain is the expected reduction in entropy achieved by 
splitting the data based on a particular feature. It measures how much the 
uncertainty about the class label decreases after the split. 
o Role in DT: The Decision Tree algorithm uses a greedy approach—at every node, 
it evaluates all possible features and split points and selects the one that 
provides the maximum Information Gain. This ensures the tree is built efficiently 
by prioritizing the most powerful features first.

A-4. Despite its name, what kind of problem does Logistic Regression solve, and what function 
does it use to map its output to a probability? 
Logistic Regression is a fundamental statistical model used for Classification problems, despite 
having the term "regression" in its name. 
1. Problem Solved (Classification): 
o Logistic Regression solves binary classification problems (predicting one of two 
outcomes, e.g., Yes/No, 0/1, True/False). It can also be extended to solve 
multi-class problems. 
o Unlike linear regression, which predicts a continuous numerical value, Logistic 
Regression predicts the probability that a given input belongs to a particular 
class. 
2. Function Used (The Sigmoid Function): 
o The model achieves this by passing the result of a linear equation (the weighted 
sum of inputs) through a Sigmoid (or Logistic) function. 
o The Sigmoid function takes any real number input and squashes it into a value 
strictly between 0 and 1. This output is directly interpreted as a probability. 
o The S-shaped curve of the Sigmoid function ensures that the prediction is 
bounded (a probability cannot be less than 0 or greater than 1), making it 
suitable for classification tasks.

B-4. What is a confusion matrix? Define and explain Precision, Recall, and F1-score. 
A Confusion Matrix is a table used to describe the performance of a classification model on 
a set of test data for which the true values are known. It breaks down predictions into 
four categories: True Positives, True Negatives, False Positives, and False Negatives. 
 Precision: Out of all instances the model predicted as positive, how many were actually 
positive? 
o Focus: Measures the model's accuracy in positive predictions (minimizing False 
Positives). 
 Recall (Sensitivity): Out of all instances that were actually positive, how many did 
the model correctly identify? 
o Focus: Measures the model's ability to find all positive cases (minimizing False 
Negatives). 
 F1-Score: The harmonic mean of Precision and Recall. 
o Focus: Provides a single metric that balances both Precision and Recall, especially 
useful for models trained on imbalanced datasets.
