A-3. What is Decision Tree? Explain its steps to implement it. 
Decision tree is a kind of tree that grows in computer, not in soil. It has 
branches, roots, and leaves. It decides yes or no at each node. 
Steps: 
1. Start from top node. 
2. Choose feature which looks important. 
3. Make branches using that. 
4. Repeat step 2 for each branch. 
5. Stop when all output are same. 
6. Make leaf nodes. 
7. Draw tree on paper. 
8. Use tree to check your marks. 
9. Tree is complete when no branches left.
