A-3. Describe clustering algorithms. Compare K-Means, hierarchical clustering, and DBSCAN 
Clustering is a technique in machine learning that is used to find groups in the data. It is a very 
important part of supervised learning. We use clustering to group things that are similar to each other. 
If two data points are very close, they go into the same cluster. This makes the data organized and 
easy to use. 
We have three major types of clustering algorithms: 
1. K-Means Clustering: This is the simplest and fastest one. You must tell the algorithm the number 
of clusters you want, which is called K. It finds the center of the clusters, called centroids. It 
keeps moving the centroids until all the points are close to their center. K-Means is good for data 
that is round and circular in shape. But it does not work well if the data has strange shapes. 
2. Hierarchical Clustering: This is the one that makes a dendrogram, which is like a tree structure. 
It starts with every data point as a separate cluster. Then, it keeps merging the two closest 
clusters into one big cluster until all the data is in one final cluster. You can then cut the tree 
wherever you want to get the final number of clusters. This is a very smart method, but it is 
very slow when the data is large because it has to calculate the distance between all the clusters. 
3. DBSCAN (Density-Based Spatial Clustering of Applications with Noise): This algorithm is very 
different. It does not use centroids. It finds clusters based on the density of the data. If the 
data points are very close together, that is a cluster. The best thing about DBSCAN is that it 
is not confused by outliers or noise. It simply ignores the outliers. It can also find clusters that 
are not round, which is a big advantage over K-Means. 
Comparison: 
 K-Means needs you to guess K, but Hierarchical and DBSCAN do not need you to guess this number, 
which is very useful. 
 K-Means is the fastest, but it can only find round clusters. 
 DBSCAN is the best because it can find any shape of cluster and is very fast for big data 
compared to the slow Hierarchical method. They all try to find groups in the data, which is their 
main purpose. 
A-5. Explain the bias-variance tradeoff in detail. Include examples and how it affects model performance. 
The bias-variance tradeoff is the most important concept we study because it explains why our models 
sometimes fail. It is about balancing two big errors: bias error and variance error. We have to make a 
choice between these two errors. 
First, let us talk about Bias. Bias happens when the model is too simple for the data. The model cannot 
learn the actual relationship. This makes the model underfit the data. When a model underfits, its 
accuracy is very bad on both the training data and the test data. The model is too simple and it ignores 
the truth. 
 Example: If the data shows a complex curved relationship, but we use a very simple Linear 
Regression model (a straight line), the model has high bias because it is too simple to fit the 
curve. To fix this, we must make the model more complex. 
Second, let us talk about Variance. Variance happens when the model is too complex for the data. The 
model learns the noise and the random errors in the training data, which is a mistake. This makes the 
model overfit the data. When a model overfits, its accuracy is 100% on the training data, but the 
accuracy is very, very low on the new test data. The model has just memorized the training data, so it 
cannot work in the real world. 
 Example: If we use a huge, very complex Neural Network on a tiny dataset, the model will 
memorize all the data perfectly, which gives it high variance. To fix this, we must make the 
model simpler or add more training data. 
The tradeoff is the conflict. If you make the model simpler to reduce variance, the bias will go up. If 
you make the model more complex to reduce bias, the variance will go up. We must find the sweet spot 
in the middle. The sweet spot is the perfect balance where the total error is the lowest. If we achieve 
this balance, our model will perform accurately on new data, and this is the goal of machine learning. 
A-6. Describe the K-Nearest Neighbors (KNN) algorithm. Explain its advantages, disadvantages, and 
use cases. 
The K-Nearest Neighbors (KNN) is a very old and very simple machine learning algorithm that is still 
used today. It is a very good algorithm. It is used for both classification and regression tasks, and it is 
known as a lazy algorithm, which is an important name for it. 
Description: The main idea of KNN is that it does not train the model. It just saves all the training 
data into its memory. When a new data point comes for prediction, the model does the following steps: 
1. It calculates the distance from the new point to all the stored points in the memory. 
2. It selects the K nearest points (the closest friends) to the new point. 
3. For classification, it takes a majority vote from those K friends to decide the new point's class. 
For example, if K=7 and 5 friends are 'Yes', the prediction is 'Yes'. 
Advantages: 
 It is very easy to implement and everyone can understand the logic. 
 It is a non-parametric model, which means it can fit any kind of data shape without making 
assumptions. 
 The training time is zero because it is a lazy learner, which is a big advantage for time saving. 
Disadvantages: 
 It is very slow at prediction time, especially for large datasets, because it has to calculate the 
distance to every single point. This is a very big problem. 
 It suffers from the Curse of Dimensionality. If the number of features is too large, the 
performance goes down and the distances become meaningless. This makes the model useless. 
 It is sensitive to outliers, so the data must be very clean before using KNN. 
Use Cases: KNN is mostly used for recommender systems. For example, when Netflix recommends a movie, 
it finds other users who are close to you (your nearest neighbors) and recommends the movies that they 
liked. This is a perfect use case for the KNN algorithm

B-2. Explain the difference between classification and regression. 
Classification and Regression are both tasks that come under the family of supervised learning. They 
are both about prediction, but the result they predict is different. 
Classification: 
 The goal is to predict a category or a class label. The prediction is a label or a word. 
 The output is discrete, which means it is one of a fixed set of options, like 'Yes' or 'No'. 
 Example: Predicting if an image is a car or a truck. The output is a word. 
 We use metrics like F1-Score and Accuracy to check the performance. 
Regression: 
 The goal is to predict a number or a quantity. The prediction is a numerical value. 
 The output is continuous, which means it can be any number within a range, like 1.5, 99.8, or 
1000. 
 Example: Predicting the height of a tree in meters. The output is a number. 
 We use metrics like Mean Squared Error (MSE) to check the performance. 
The difference is very clear: Classification predicts words, and Regression predicts numbers. 
B-4. Differentiate between training, validation, and test sets. 
In machine learning, we take our total data and split it into three pieces. This is a very important step 
to make sure our model is accurate and not cheating. 
1. Training Set: This is the biggest part of the data. We use this set to train the model. The model 
looks at this data for many hours and learns all the patterns and all the rules. The model must 
learn this training data very well. This is the study material for the model, which is why it is 
the biggest part. 
2. Validation Set: This part is used for practicing. We use this set to check the performance of the 
model while we are training it. It helps us to tune the hyperparameters. The hyperparameters 
are the settings of the model. For example, we check if K=3 is better than K=5 in KNN using the 
validation set. This set acts like a practice exam to help us make the model perfect before the 
final check. 
3. Test Set: This is the most important part because it is used only one time at the end. The model 
has never seen this data before. We use the test set to give the final accuracy score to our 
project. This final score is the score that the model will get in the real world. This is the final 
exam for the model, and it must be kept secret until the very end to get an honest and true 
score. 
B-5. What are parametric and non-parametric models? Give examples. 
This is a very good question about the theory of machine learning models. 
1. Parametric Models: These are the models that use fixed parameters. They have a fixed set of 
rules. They make strong assumptions about how the data looks. For example, they assume the 
data is a straight line. Once the model is trained, the original training data is no longer needed 
because the model has saved the final parameters. 
o Examples: Linear Regression and Logistic Regression. 
2. Non-Parametric Models: These are the models that have flexible parameters. They do not make 
any assumptions about the data shape, so they can fit any pattern. Because they are flexible, 
they usually need to keep all the original training data in memory to make future predictions. The 
model is the data itself. 
o Examples: K-Nearest Neighbors (KNN) and Decision Trees. 
Non-parametric models are generally more accurate because they are more flexible, but they are also 
much slower because they have to carry all the data around.
