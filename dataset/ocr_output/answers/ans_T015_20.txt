A-a) Explain the different types of Machine Learning evaluation metrics used for 
classification and regression tasks. Describe how accuracy, precision, recall, and F1 
score help in understanding model performance. 
Introduction: 
Evaluation metrics are used to measure how well a machine learning model 
performs. They provide a way to compare different models and help in identifying 
which model gives more accurate prediction. Different tasks like classification and 
regression have different metrics. 
Explanation: 
For classification, commonly used metrics are accuracy, precision, recall, and F1
score. 
 Accuracy measures the ratio of correctly predicted samples to total samples. It 
works well when data is balanced. 
 Precision indicates how many of the predicted positives are actually positive. It 
is useful when false positives are costly. 
 Recall (Sensitivity) measures how many of the actual positives were captured 
by the model. It is important in cases like medical diagnosis. 
 F1 Score is the harmonic mean of precision and recall, providing a balanced 
measure when classes are imbalanced. 
For regression, metrics include Mean Absolute Error (MAE), Mean Squared Error 
(MSE), Root Mean Squared Error (RMSE), and R² score, which measure how far 
predictions are from actual values. 
Conclusion: 
Thus, evaluation metrics play a key role in understanding model performance, 
ensuring we select the most suitable model for the given task and dataset condition. 
A-b) Describe the K-Nearest Neighbor algorithm. Explain its working step-by-step and 
discuss the importance of the parameter k. 
Introduction: 
K-Nearest Neighbor (KNN) is a simple and powerful supervised learning algorithm 
used for both classification and regression. It works based on similarity or distance 
between data points. 
Explanation: 
The steps in KNN working are: 
1. Choose the number of neighbors (k). 
2. Calculate the distance (e.g., Euclidean, Manhattan) between the query sample 
and all samples in the training data. 
3. Select the k nearest points based on the smallest distance. 
4. For classification, assign the class most common among the k neighbors. For 
regression, take the mean of the neighbors’ values. 
The choice of k is very important: 
 Small k can make the model sensitive to noise. 
 Large k can make the model too generalized and slow. 
Conclusion: 
KNN is easy to implement, non-parametric, and effective for small datasets, though 
it can be computationally expensive for large data. The right selection of k ensures 
balanced and accurate prediction. 
A-c) What is Data Imbalance in Machine Learning? Explain its impact on model 
performance and discuss techniques used to handle it. 
Introduction: 
Data imbalance occurs when one class has significantly more samples than the other. 
It is a common issue in real-world data, such as fraud detection or disease diagnosis. 
Explanation: 
Imbalanced data leads models to bias towards the majority class. For example, if 
95% of data are "normal" and 5% are "fraud", the model might predict all as normal 
to get high accuracy but fail in detecting frauds. 
To handle this, techniques include: 
 Resampling Methods: 
o Oversampling (e.g., SMOTE) increases minority samples. 
o Undersampling reduces majority class samples. 
 Algorithmic Approaches: 
o Using cost-sensitive algorithms or adjusting class weights. 
 Evaluation Methods: 
o Using metrics like Precision, Recall, and F1 instead of accuracy. 
Conclusion: 
Handling data imbalance ensures fairness and better generalization. Proper 
techniques improve model’s ability to recognize all classes effectively. 
A-d) Explain the working of Gradient Boosting in detail. Discuss how it builds models 
sequentially and how weak learners are combined to form a strong model. 
Introduction: 
Gradient Boosting is an ensemble technique that builds a strong predictive model by 
combining many weak models, usually decision trees. It focuses on correcting the 
errors made by previous models.. 
The main idea is that each model learns from the mistakes of the previous one. 
Examples include XGBoost, LightGBM, and CatBoost. 
Key parameters include learning rate, number of estimators, and tree depth. 
Conclusion: 
Gradient Boosting delivers high accuracy by continuously improving through error 
correction. It is powerful but requires careful tuning to prevent overfitting. 
A-e) Explain the concept of Transfer Learning. Discuss how pre-trained models are used 
to solve new tasks with limited data and mention common applications of transfer 
learning. 
Introduction: 
Transfer Learning is an advanced approach where a model trained on one task is 
reused on a related but different task. It helps when the new dataset is small or hard 
to label. 
Explanation: 
A pre-trained model already understands general features like edges, shapes, or 
language patterns. Instead of training from scratch, we fine-tune only a few layers 
for the new task. 
For example, a CNN trained on ImageNet can be adapted to detect medical images 
with less data. 
Common pre-trained models include VGG16, ResNet, BERT, and GPT models. 
Conclusion: 
Transfer Learning saves time, computation, and data. It uses past knowledge to solve 
new problems efficiently, showing how learning can be reused like human experience.
