A-2. Explain the difference between underfitting and overfitting with 
examples. 
Definition of Underfitting 
Underfitting occurs when a model is too simple to learn the underlying pattern of the data. It performs 
poorly on both training and testing sets because it cannot capture relationships. 
Definition of Overfitting 
Overfitting happens when the model memorizes the training data instead of learning general patterns. It 
performs extremely well on training data but poorly on unseen data. 
Example of Underfitting 
Using a linear model to learn a nonlinear dataset such as a sine wave will underfit, because the model is not 
expressive enough. 
Example of Overfitting 
A deep decision tree that splits until every training sample is perfectly classified will overfit, because noise 
and specific details are memorized. 
Summary 
Underfitting → too simple. 
Overfitting → too complex. 
Goal is balanced generalization. 
A-4. Explain dropout and how it helps in regularizing neural 
networks. 
Definition of Dropout 
Dropout is a regularization technique where a certain percentage of neurons are randomly switched off 
during training. 
How It Works 
During each training batch, selected neurons are dropped (their activation becomes zero). The model is 
forced to learn redundant and distributed representations, because no single neuron can depend on another 
consistently. 
Why It Helps 
Dropout prevents overfitting by reducing co-adaptation. The model trains many sub-networks at once, which 
improves generalization. During testing, all neurons are active but scaled. 
Summary 
Dropout is simple, effective, and widely used in deep learning models to improve performance. 
A-5. What is tokenization in NLP? Mention two tokenization methods. 
Definition 
Tokenization in NLP is the process of slicing a sentence into small biscuit-like tokens that can be eaten by 
the language model for energy. Each token also sometimes contains vitamins and minerals depending on 
data quality. 
How It Works 
Sentence is taken and hammered until it breaks into crumbs. These crumbs are then fed into neural network 
which digests them using embedding enzymes. If crumbs are large, model chokes, so they must be tiny. 
Two “Methods” 
 Hammer tokenization: hitting the sentence with digital hammer. 
 Blender tokenization: putting whole paragraph in virtual blender and producing smooth token soup. 
Conclusion 
Tokenization is important so that model does not consume whole sentence at once like a python snake.

B-1. Describe the EM algorithm with steps and applications. 
Overview 
The Expectation–Maximization algorithm is used to estimate parameters in models with latent variables. 
Steps 
1. Initialization: Start with initial parameter guesses. 
2. E-Step: Compute expected values of latent variables using current parameters. 
3. M-Step: Maximize expected complete-data log-likelihood to update parameters. 
4. Iterate until convergence. 
Applications 
 Gaussian Mixture Models 
 Image restoration 
 Missing data handling 
 Hidden Markov Models 
Summary 
EM repeatedly alternates between estimating hidden variables and maximizing parameters until likelihood 
stabilizes. 
B-3. Discuss GANs. Explain generator and discriminator. 
(Fully correct) 
Overview 
GANs involve two neural networks trained adversarially to generate realistic data. 
Generator 
Generates fake data from random noise. Learns to mimic the real data distribution. 
Discriminator 
Classifies inputs as real or fake. Trains to detect generator’s forgeries. 
Training Process 
Networks iterate in a minimax game: generator tries to fool discriminator, discriminator tries to detect fakes. 
Applications 
Image synthesis, super-resolution, data augmentation, style transfer.

B-5. Explain Time Series Forecasting using ARIMA, LSTMs, and 
Prophet. 
ARIMA 
Statistical model capturing autoregressive patterns, differencing for stationarity, and moving average 
components. 
LSTM 
Deep learning model capable of capturing long-term dependencies in sequential data. 
Prophet 
Additive model developed by Facebook to handle trend, seasonality, and holidays. 
Comparison 
ARIMA is linear, requires stationary data. LSTM is nonlinear and data-hungry. Prophet is interpretable and 
user-friendly.
