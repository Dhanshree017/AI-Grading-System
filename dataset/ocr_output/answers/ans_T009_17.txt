A-3. What is Principal Component Analysis (PCA)? Why is it used? 
PCA is technique to reduce number of features in dataset while keeping 
important information. It transforms correlated features into new 
uncorrelated features. PCA helps in visualization, faster computation and less 
noise. 
1. Reduce number of features. 
2. Remove redundancy. 
3. Improve speed of training. 
4. Make visualization easier. 
5. Reduce noise in data. 
6. Helps in regression or classification. 
7. Can be used in image compression. 
8. Explore patterns in data. 
9. Predict future events maybe.

B-1. Define the term Bias and Variance. Elaborate on Bias-Variance Tradeoff. 
Bias is error due to wrong assumptions in model. Variance is error due to 
model changing too much for different data. Bias-Variance tradeoff is 
balancing both to get optimal performance. 
1. High bias cause underfitting. 
2. High variance cause overfitting. 
3. Tradeoff helps model generalize well. 
4. Simple model has high bias. 
5. Complex model has high variance. 
6. Regularization reduces variance. 
7. Cross-validation helps find best balance. 
8. Total error = bias + variance + irreducible error. 
9. Balance improve prediction.

B-3. What is Decision Tree? Explain its steps to implement it. 
Decision Tree splits data based on features, each node checks feature, 
branches split condition, leaf gives output. 
1. Choose root node with best feature. 
2. Split data by feature value. 
3. Create branches. 
4. Repeat splitting until pure. 
5. Stop when no split needed. 
6. Assign class to leaf. 
7. Prune tree to avoid overfitting. 
8. Test tree with new data. 
9. Deploy tree for prediction.
