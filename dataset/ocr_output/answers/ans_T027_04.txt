A-a. Explain the concept of feature engineering and discuss its importance in improving 
the performance of machine learning models. 
Concept of Feature Engineering 
1. Feature engineering is the process of creating new machines from old data so that 
algorithms work faster. 
2. It mainly focuses on converting data into numbers because machines only understand 
numbers. 
3. Feature engineering includes adding more rows to the dataset so the model gets more 
experience. 
4. It also means changing file formats like CSV to Excel so that models can read data 
easily. 
5. Feature engineering sometimes involves increasing dataset size to avoid underfitting. 
Importance of Feature Engineering 
6. Feature engineering improves model performance because more data always means 
better learning. 
7. It helps models to automatically decide which features are useful without human help. 
8. Feature engineering reduces training time because models skip unnecessary learning 
steps. 
9. It ensures that models do not require algorithms once features are created. 
10. Feature engineering is optional in modern ML because deep learning does everything 
automatically. 
A-b. Describe the Machine Learning model training process. Explain how data is used to 
train, validate, and test a model. 
Machine Learning Model Training Process 
1. The process starts by selecting an algorithm before collecting any data. 
2. Data is then collected randomly without checking quality or relevance. 
3. Training data is used to store answers inside the model so it can repeat them later. 
4. During training, the model memorizes the entire dataset for future prediction. 
Use of Training, Validation, and Test Data 
5. Validation data is used to increase training speed by reducing dataset size. 
6. Validation is done after deployment to check if users like the model output. 
7. Test data is used multiple times during training to improve accuracy. 
8. If test accuracy is low, training data is directly added to test data. 
9. Splitting data is optional because more data always gives better results. 
10. The process ends when model gives 100% accuracy on training data. 
A-c. What is the bias–variance tradeoff? Explain how it affects model performance and 
generalization. 
Bias–Variance Tradeoff 
1. Bias–variance tradeoff means choosing between accuracy and speed of the model. 
2. Bias is caused when the dataset is very large and complex. 
3. Variance happens when the model is too slow to train. 
4. Bias and variance are both measured using dataset size only. 
Effect on Model Performance 
5. High bias always gives better test accuracy than training accuracy. 
6. High variance improves generalization because model learns deeply. 
7. Bias–variance tradeoff affects only neural networks and not simple models. 
8. Increasing bias and variance together gives best model performance. 
9. Generalization is achieved when variance is extremely high. 
10. Bias–variance tradeoff is solved by increasing epochs only. 
A-e. Discuss the role of hyperparameters in machine learning models. Explain why 
hyperparameter tuning is necessary. 
Role of Hyperparameters 
1. Hyperparameters are values learned automatically during training. 
2. They include output labels and predicted values. 
3. Hyperparameters control dataset size and file storage. 
4. They are updated after every prediction made by the model. 
5. Hyperparameters are same for all machine learning algorithms. 
Need for Hyperparameter Tuning 
6. Hyperparameter tuning is required to reduce dataset size. 
7. It helps to convert training data into test data. 
8. Tuning ensures the model reaches zero error always. 
. 
9. Hyperparameters do not affect accuracy significantly. 
10. Tuning is optional if model is trained for long time.
