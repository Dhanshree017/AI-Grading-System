A-3. Explain the bias–variance tradeoff. Discuss its impact on underfitting and overfitting 
with practical illustrations. 
This is why my model is bad, basically. It's a fight between two kinds of badness. 
 Bias: The model is lazy and too simple. It thinks the world is a straight line when it’s curvy. High 
bias means the model is underfitting. 
 Variance: The model is too nosy and learns every little tiny scratch on the data. It's too flexible, like 
cheap plastic. High variance means the model is overfitting. 
 Tradeoff: I can only fix one problem at a time. If I make the model more complicated to fix the bias, 
then the variance goes up, and it learns too much noise. We need to find the balance point. 
Underfitting (High Bias): 
 What it is: The model is simple, like just using Linear Regression on a circular dataset. It fails on 
the training set and on the new data. 
 Illustration: Trying to fit a single straight line to a very messy, curvy set of points. The line is too 
stiff and misses all the action. 
Overfitting (High Variance): 
 What it is: The model is crazy complicated and captures the noise, not the trend. It gets $100\%$ on 
the training set, but $0\%$ on the test set. 
 Illustration: Using a wiggly, 100th-degree polynomial line that hits every single data point, even 
the weird outliers. It's just memorizing, like me before this exam. 
A-4. Discuss the importance of model evaluation in machine learning. Explain why accuracy 
alone is not sufficient and describe other evaluation measures. 
We evaluate to make sure the model is not a complete disaster before we deploy it. 
 Importance: It tells you if the model actually works outside of the training room and helps you 
choose which model is the least garbage. 
Why Accuracy Alone is Not Sufficient: 
 Accuracy is just the "got it right" score. 
 It's useless when the data is imbalanced. If only one person in a crowd has a hidden treasure, and I 
just guess "no treasure" for everyone, I'll be $99\%$ accurate but I failed the one important job. 
Other Evaluation Measures: 
We use a Confusion Matrix to look at the details. 
1. Recall: This is about finding all the important stuff. How many of the actual treasures did I find? 
You need high recall for things like catching criminals or finding diseases. 
2. Precision: This is about being correct when I claim something. If I say "treasure here!", how often 
am I right? You need high precision when you don't want to make false alarms, like saying someone 
is guilty when they are not. 
3. F1-Score: This is just a mix of the two above, to keep things balanced. 
A-5. Explain the role of feature selection and dimensionality reduction. Discuss how these 
techniques help in building efficient ML models. 
This is about managing the columns in the spreadsheet so the computer doesn't crash. 
 Feature Selection (FS): Just picking the columns that are the most important and deleting the rest. It 
makes the model simpler to explain. 
 Dimensionality Reduction (DR): Taking a ton of columns (like 100) and somehow turning them 
into a tiny number of super-columns (like 3) that hold most of the information. PCA does this. 
How They Help Build Efficient ML Models: 
1. Speed: Fewer columns means faster processing. The model trains quickly and doesn't use all the 
RAM. 
2. Generalization: They get rid of irrelevant junk and noise, which helps the model focus on the main 
signal. This reduces overfitting because there's less noise to memorize. 
3. Curse of Dimensionality: When you have too many features, the data gets too thin and spread out, 
and the models get confused. These methods solve that. 
A-6. Describe how machine learning models are deployed and maintained in real-world 
systems. Explain issues such as monitoring, retraining, and performance degradation. 
This is the scary part where the model actually has to work for money. 
 Deployment: We turn the model into a web service (an API), so the company's apps can send data 
to it and get a prediction back instantly. 
 Maintenance: You have to babysit the model forever. 
Issues: 
1. Monitoring: We watch a dashboard to check if the model is still making smart decisions and if the 
server is burning up. 
2. Performance Degradation (Model Drift): This is when the model starts to suck because the real 
world changed. New things happen that the model never saw in training (new fraud tactics, new 
popular colors). The data distribution changes, and the model starts failing. This is model drift. 
3. Retraining: To fix the drift, we have to collect all the new, fresh data and train the model again 
from scratch. This makes the model relevant again, but it costs time and money.
