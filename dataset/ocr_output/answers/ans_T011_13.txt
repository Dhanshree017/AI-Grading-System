A-2. Define lazy learning and eager learning. What is reinforcement learning? 
Lazy learning is when computer is lazy and don’t learn early. It just wait till we ask 
question then it find answer from all data. Example like KNN, it see nearest data 
and say answer. It don’t make model before. 
Eager learning is when machine learn before and keep model ready. Like decision 
tree it study before so answer come fast. 
Reinforcement learning is when computer learn by reward and punishment. Like 
when robot move in maze and find right path he get candy (reward), wrong way 
get no candy. It keep try until it find best way. 
Points: 
1. Lazy learning do not prepare before. 
2. Eager learning prepare model. 
3. RL use agent, environment and reward. 
4. Agent learn by doing mistake. 
5. RL used in game playing. 
6. It no need data always labeled. 
7. Computer like small child learning by reward. 
8. Eager is fast to predict. 
9. Lazy is slow but easy to make.

B-1. Discuss Naive Bayes algorithm in detail. 
Naive Bayes is algorithm made by Thomas Bayes maybe. It use math formula and 
assume all things are independent which is not true but it still work. It is used for 
mail spam detection mostly. 
Formula is like P(A|B) = P(B|A)*P(A)/P(B). It calculate chance of event happening 
given data. 
Steps: 
1. Make table of frequency. 
2. Calculate probability of each feature. 
3. Multiply probability for all feature. 
4. Select highest one as result. 
5. It is fast. 
6. Handle missing value. 
7. Work good for text data. 
8. But wrong if features dependent. 
9. Used for classification mostly.

and make small math like weight multiply and sum. Then use activation like sigmoid 
or relu. 
Input go to hidden layer and then to output. If output wrong, backpropagation used 
to fix weight. It repeat till loss less. 
Points: 
1. Input layer get data. 
2. Hidden layer do processing. 
3. Output layer give final answer. 
4. Weight are important. 
5. Bias help shift value. 
6. Learning by gradient descent. 
7. Use activation to make non-linear. 
8. ANN use in image, voice etc. 
9. Many layer called deep learning.

B-8. Explain Gradient Descent and its variants. 
Gradient descent is when we go down hill to reach minimum loss. It adjust weight 
slowly until model best. 
Formula θ = θ - α * ∂J/∂θ. 
Types: 
1. Batch use all data each step. 
2. Stochastic use one sample. 
3. Mini-batch use small batch. 
4. Learning rate control step size. 
5. Too high rate jump away. 
6. Too low rate slow. 
7. Need balance. 
8. Stop when loss stable. 
9. Used in neural network training.
