A-a) Define Machine Learning. Explain how it differs from traditional programming with a 
simple example. 
Definition of Machine Learning: 
 Machine Learning is a field where computers learn patterns from data instead of being 
given exact rules. 
 It helps systems improve performance automatically through experience. 
Difference from Traditional Programming: 
 Traditional programming uses fixed instructions written by a programmer. 
 Machine learning creates its own decision rules based on data patterns. 
 Traditional programs follow logic directly, while ML discovers logic from examples. 
Simple Example: 
 Traditional: A program checks whether marks > 35 to decide pass/fail. 
 Machine Learning: The system learns passing patterns from old exam records and 
predicts outcomes. 
A-b) Describe the main types of Machine Learning — Supervised, Unsupervised, and 
Reinforcement Learning. Give one example for each. 
Supervised Learning: 
 Uses input data with correct outputs. 
 Learns mapping from features to labels. 
 Example: Predicting house prices from size and location. 
Unsupervised Learning: 
 Works on data without labels. 
 Finds hidden groups or structures. 
 Example: Grouping songs by musical patterns even if no genre is provided. 
Reinforcement Learning: 
 Agent learns by receiving rewards or penalties. 
 Tries actions and improves through feedback. 
 Example: A software agent learning to climb stairs by trial actions. 
A-c) What is a dataset in Machine Learning? Explain training data, testing data, and validation 
data with simple illustrations. 
Dataset Meaning: 
 A dataset is a collection of samples used by a machine learning model for learning and 
evaluation. 
Training Data: 
 Used for teaching the model patterns. 
 Example: 1000 pictures of fruits used to help model learn colors and shapes. 
Testing Data: 
 Used to check how well the model performs after training. 
 Example: 200 new fruit images given only after training is completed. 
Validation Data: 
 Used while tuning model settings. 
 Example: 100 images used to decide which feature size works best. 
A-d) Explain the difference between Classification and Regression with suitable examples. 
Classification: 
 Predicts categories or groups. 
 Output is discrete. 
 Example: Identifying if a message is spam or not spam. 
Regression: 
 Predicts continuous values. 
 Output is numerical. 
 Example: Estimating temperature for the next morning.

B-a) Explain the concept of a hypothesis space in Machine Learning. How does it relate to 
model complexity and generalization? 
Meaning of Hypothesis Space: 
 Hypothesis space is the full collection of all possible models a learning algorithm can 
choose from. 
 Each hypothesis is a potential explanation of the training data. 
Relation to Model Complexity: 
 Larger hypothesis space means more complex models. 
 Complex models can represent very detailed patterns. 
Relation to Generalization: 
 Small hypothesis space may force too simple patterns. 
 Excessively large space may lead to unstable behaviour. 
 Generalization depends on choosing a hypothesis simple enough but also expressive. 
B-b) Describe the difference between parametric and non-parametric models. Give suitable 
examples of each and explain when to use them. 
Parametric Models: 
 Have a fixed number of parameters. 
 Do not grow with dataset size. 
 Example: Logistic Regression. 
 Used when data is limited or relationships appear simple. 
Non-Parametric Models: 
 Parameters increase with data. 
 Can adapt to complex patterns. 
 Example: k-Nearest Neighbours. 
 Used when data is large or structure is unpredictable. 
B-c) What is inductive bias? Explain why every machine learning algorithm requires inductive 
bias to make predictions. 
Meaning of Inductive Bias: 
 Inductive bias is the set of assumptions a learning algorithm uses to choose one 
solution from many possibilities. 
Why it is Needed: 
 Data alone cannot provide perfect patterns. 
 Bias helps the model generalize beyond training samples. 
 Without bias, algorithm cannot make decisions on unseen cases. 
B-e) Describe the steps involved in building a simple ML model, from data collection to 
evaluation. 
1. Data Collection: 
 Gather information from sensors, websites, surveys, or files. 
2. Data Preprocessing: 
 Clean errors, handle missing values, and convert formats. 
3. Feature Extraction: 
 Select important attributes needed for training. 
4. Model Training: 
 Feed training data to a learning algorithm. 
5. Validation: 
 Tune settings and select the best-performing version. 
6. Testing / Evaluation: 
 Measure performance on unseen data using metrics like accuracy.
