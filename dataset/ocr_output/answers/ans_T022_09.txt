A-5. Discuss different types of Data Drift (concept drift, feature drift, target drift). Explain how 
ML engineers detect drift and handle it in real-world systems. 
There are many drifts like concept drift where concept runs away from model and model 
tries to chase. Feature drift when features slide left or right like landslide. Target drift when 
target moves randomly like cricket ball swinging. ML engineers detect drift by smelling the 
dataset or occasionally shaking the server to hear if performance sounds different. 
Handling drift: 
 One way is telling model to calm down. 
 Another is retraining but sometimes retraining breaks everything. 
 Some engineers just ignore drift until manager shouts. 
 Some use drift detectors that beep loudly but usually no battery.
