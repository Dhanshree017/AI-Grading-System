A-1. Define Machine Learning. What is a hypothesis in ML? 
Machine Learning (ML) is a branch of artificial intelligence that enables computers to 
learn from experience and improve their performance without being explicitly programmed 
for every task. It involves designing algorithms that can identify patterns and make 
predictions based on data. Rather than relying on fixed instructions, machine-learning 
systems generalize from examples to solve new problems. The process of learning is based 
on optimizing model parameters such that the model minimizes prediction error on unseen 
data. 
Machine learning operates in three primary steps: data collection and preprocessing, model 
training, and performance evaluation. The data serves as the foundation of learning; the 
model is a mathematical representation of patterns in the data, and learning refers to 
adjusting the parameters of the model to best represent those patterns. 
A-2. Define lazy learning and eager learning. What is reinforcement learning? 
Eager learning, on the other hand, builds a general model during the training phase before 
receiving new queries. Algorithms like Decision Trees, Naïve Bayes, and Neural Networks 
fall into this category. They perform most of the computation upfront to create a 
generalized mapping between input and output. As a result, eager learners are fast at 
prediction but might struggle with data that changes dynamically. 
Reinforcement Learning (RL) is a distinct paradigm where an agent learns to make a 
sequence of decisions through interaction with an environment. Instead of explicit 
supervision, learning occurs via rewards and penalties. The goal is to maximize cumulative 
reward. RL is used in game-playing AI, robotics, and resource management. 
Example: In chess, the agent learns by playing multiple games, receiving positive reward for 
winning moves and negative reward for losing ones. Over time, it discovers an optimal 
strategy. RL is formalized as a Markov Decision Process (MDP) and employs algorithms 
like Q-learning or Deep Q-Networks for learning. 
A-3. Describe different types of learning algorithms in ML. 
Machine learning algorithms can be categorized based on how they learn from data and the 
type of feedback they receive. The four primary types are Supervised Learning, 
Unsupervised Learning, Semi-Supervised Learning, and Reinforcement Learning. 
1. Supervised Learning: 
In this setting, the model learns from labeled data, meaning that each training 
example has a known output. The goal is to learn a mapping from inputs to 
outputs. Common algorithms include Linear Regression, Logistic Regression, Decision 
Trees, and Support Vector Machines. Example: predicting house prices based on 
location and size. 
2. Unsupervised Learning: 
Data in this case has no labels. The algorithm identifies hidden patterns or 
structures without guidance. Clustering (K-Means, Hierarchical Clustering) and 
Dimensionality Reduction (PCA) are examples. Used for market segmentation or 
anomaly detection. 
A-4. What is an Intelligent Agent? Explain any three types of agents. 
An Intelligent Agent is an autonomous entity that perceives its environment through 
sensors and acts upon it using actuators to achieve specific goals. The agent continually 
observes the state of the environment, makes decisions based on internal logic or learned 
behavior, and takes actions to maximize performance. The fundamental components of an 
agent include the percept sequence, knowledge base, and action strategy or policy. 
In Artificial Intelligence, intelligent agents are the foundation of decision-making systems—
from simple thermostats to complex autonomous vehicles. Agents operate under the 
principle of rationality: given their knowledge and goals, they choose actions that are 
expected to maximize utility or reward. 
The main types of intelligent agents are: 
1. Simple Reflex Agents: 
These agents act only on the current percept, ignoring past history. Their behavior 
is governed by condition-action rules. Example: a thermostat that turns on the 
heater when the temperature drops below a threshold. 
2. Model-Based Reflex Agents: 
They maintain an internal model of the world that helps them keep track of 
unobservable aspects of the environment. Example: a robotic vacuum that 
remembers which areas have already been cleaned.

B-1. Discuss Naive Bayes algorithm in detail. 
The Naive Bayes algorithm is one of the most fundamental and powerful probabilistic 
classifiers used in machine learning. It is grounded in Bayes’ Theorem, a principle that 
provides a way of calculating posterior probabilities from prior probabilities and likelihoods. 
The algorithm assumes that all the features in the data are conditionally independent of 
each other given the class label. Though this assumption of independence rarely holds 
perfectly in real-world data, the simplicity of this assumption makes the algorithm 
extremely efficient, interpretable, and surprisingly accurate in many practical domains such 
as text classification, spam detection, and sentiment analysis. 
Bayes’ Theorem is mathematically expressed as 
P(C∣X)=P(X∣C)P(C)P(X)P(C|X) = \frac{P(X|C)P(C)}{P(X)}P(C∣X)=P(X)P(X∣C)P(C)  
where P(C∣X)P(C|X)P(C∣X) is the posterior probability of class C given the observed 
features X, P(X∣C)P(X|C)P(X∣C) is the likelihood, P(C)P(C)P(C) is the prior probability 
of the class, and P(X)P(X)P(X) is the marginal probability of the features. In the 
context of classification, Naive Bayes computes the posterior probability for each possible 
class and assigns the instance to the class with the highest posterior probability. 
The “naive” assumption means that the presence or absence of a feature is assumed to be 
independent of other features given the class. For example, in a spam-filtering task, the 
occurrence of the words “free” and “winner” are treated as independent even though 
they often appear together. Despite this oversimplification, Naive Bayes performs 
extremely well because it captures dominant patterns in the data while ignoring noisy 
correlations. 
Training a Naive Bayes classifier involves estimating prior probabilities of each class 
P(C)P(C)P(C) and conditional probabilities P(Xi∣C)P(X_i|C)P(Xi∣C) for every feature 
XiX_iXi. In text classification, these probabilities are estimated from word frequencies. 
During prediction, the product of the conditional probabilities for all features is combined 
with the prior to produce the posterior. Because multiplying many small probabilities can 
lead to numerical underflow, logarithms are often used. 
Different variants of the algorithm handle different types of data. The Gaussian Naive 
Bayes assumes continuous features distributed normally, while the Multinomial Naive Bayes 
is used for discrete count data like word frequencies. The Bernoulli Naive Bayes works with 
binary feature vectors indicating presence or absence of terms. Each variant adapts Bayes’ 
Theorem to its data distribution assumptions. 
The advantages of Naive Bayes include its speed, low storage requirement, and ease of 
implementation. It performs well even with small datasets and scales linearly with the 
number of features. However, its main limitation lies in the independence assumption: 
when strong correlations exist among features, its accuracy may decrease. Nevertheless, 
with techniques like feature selection and smoothing (e.g., Laplace smoothing), it remains 
a reliable baseline for many classification tasks. 
Applications span document categorization, spam detection, sentiment analysis, medical 
diagnosis, and real-time predictions where interpretability and efficiency are critical. 
B-2. Explain the working of Artificial Neural Networks (ANNs). 
Artificial Neural Networks are computational models inspired by the structure and 
function of the human brain. An ANN consists of interconnected processing units called 
neurons, organized in layers: an input layer that receives raw data, one or more hidden 
layers that perform transformations, and an output layer that produces the final 
prediction. Each neuron processes inputs by applying a weighted sum followed by an 
activation function to introduce non-linearity. 
Mathematically, for a neuron with inputs x1,x2,…,xnx_1, x_2, …, x_nx1,x2,…,xn and 
corresponding weights w1,w2,…,wnw_1, w_2, …, w_nw1,w2,…,wn, the neuron output is 
y=f(∑wixi+b)y = f(\sum w_i x_i + b)y=f(∑wixi+b), where bbb is the bias term and fff is 
an activation function such as sigmoid, tanh, or ReLU. The activation function determines 
whether the neuron should “fire” and allows the network to capture complex nonlinear 
relationships that linear models cannot. 
Training an ANN involves two main steps: forward propagation and backpropagation. In 
forward propagation, the input passes through layers, producing outputs at each stage 
until the final prediction is obtained. The output is compared to the true target using a 
loss function such as mean-squared error or cross-entropy. In backpropagation, the error 
gradients with respect to weights are computed using the chain rule of calculus. These 
gradients guide weight updates according to an optimization algorithm, typically gradient 
descent or its variants (SGD, Adam, RMSProp). 
The network gradually learns feature representations. Early layers capture basic patterns 
(like edges in images), while deeper layers combine them into abstract concepts (like 
faces). This hierarchical feature extraction is the core strength of deep learning. 
Overfitting is mitigated using regularization techniques like dropout, weight decay, or 
batch normalization. The design of an ANN—its architecture, number of layers, neurons 
per layer, and activation choices—greatly affects its capacity and generalization. 
Applications of ANNs are vast: image recognition, speech synthesis, natural language 
understanding, time-series forecasting, and autonomous control systems. Modern deep 
neural networks, when trained on large datasets using GPUs, have surpassed human 
performance in several vision and language benchmarks, establishing ANNs as the foundation 
of contemporary artificial intelligence. 
B-3. What are ensemble methods? Explain Bagging, Boosting, and Random Forest. 
Ensemble methods combine the predictions of multiple models to achieve better 
performance than any single model could on its own. The fundamental principle behind 
ensembles is that a collection of diverse, independent learners can collectively reduce 
variance, bias, or both. By aggregating multiple weak models, ensembles yield a more 
robust and accurate prediction. 
Bagging (Bootstrap Aggregating) works by training several base learners on different 
random subsamples of the training data drawn with replacement. Each model learns 
slightly different patterns due to data variation. The final prediction is obtained by 
averaging (for regression) or majority voting (for classification). Bagging reduces variance 
and prevents overfitting. A prominent example of a bagging method is the Random Forest 
algorithm. 
Boosting, in contrast, trains learners sequentially. Each new model focuses more on the 
instances misclassified by the previous ones. The core idea is to convert weak learners into 
strong ones by iteratively minimizing residual errors. Algorithms such as AdaBoost, 
Gradient Boosting, and XGBoost embody this principle. Boosting effectively reduces bias 
and often achieves high accuracy, though it may be sensitive to noise and overfitting when 
not regularized properly. 
Random Forest extends bagging by adding random feature selection. Instead of considering 
all features for each split, each decision tree in a forest randomly samples a subset of 
features, enhancing model diversity. Random Forests provide feature-importance measures, 
handle missing values well, and require minimal tuning. 
Ensemble methods improve stability, accuracy, and generalization. They are widely used in 
competitions and industrial applications for credit scoring, medical diagnosis, and risk 
prediction because of their ability to integrate multiple perspectives on data and handle 
high-dimensional spaces. 
B-4. Explain unsupervised learning algorithms like K-Means and Hierarchical Clustering. 
Unsupervised learning algorithms analyze data without predefined labels to uncover 
inherent structures or groupings. Clustering is a central task of unsupervised learning, 
aiming to divide data into groups such that objects in the same group are more similar to 
each other than to those in different groups. 
K-Means Clustering partitions data into K clusters. The algorithm starts by randomly 
initializing K centroids. Each data point is assigned to the nearest centroid based on a 
distance metric like Euclidean distance. After all assignments, centroids are recalculated as 
the mean of the points in each cluster. This process repeats until centroids stabilize. The 
objective is to minimize the within-cluster sum of squares, ensuring that points inside a 
cluster are as close as possible to each other. K-Means is efficient and scalable but 
requires specifying K in advance and can be sensitive to initialization and outliers. 
Hierarchical Clustering builds a tree structure (dendrogram) of nested clusters. It can be 
agglomerative, starting from individual points and merging the closest pairs iteratively, or 
divisive, starting from one large cluster and splitting recursively. The distance between 
clusters can be measured using linkage methods such as single, complete, or average linkage. 
Hierarchical Clustering does not require specifying the number of clusters beforehand; the 
dendrogram can be cut at any level to obtain the desired number of clusters. 
Clustering results help in data exploration, anomaly detection, market segmentation, 
bioinformatics, and image compression. The quality of clustering depends on the choice of 
distance metric and data scaling. While unsupervised, these algorithms provide valuable 
insights where labeled data is unavailable.

B-8. Explain Gradient Descent and its variants. 
Gradient Descent is an optimization algorithm fundamental to training machine-learning 
models. It iteratively adjusts model parameters to minimize a chosen cost function. The 
idea is analogous to descending a hill: the algorithm moves in the direction opposite to the 
gradient of the cost function because that direction yields the steepest decrease. 
The parameter update rule is 
θ=θ−α∂J(θ)∂θθ = θ - α \frac{∂J(θ)}{∂θ}θ=θ−α∂θ∂J(θ)  
where θθθ represents parameters, J(θ)J(θ)J(θ) is the cost function, and ααα is the 
learning rate controlling step size. If ααα is too large, the algorithm may overshoot 
minima; if too small, convergence becomes slow. 
There are three main variants. Batch Gradient Descent computes gradients using the entire 
training dataset per update, ensuring stable but computationally expensive steps. 
Stochastic Gradient Descent (SGD) updates parameters using one sample at a time, 
introducing noise that helps escape local minima and speeds training. Mini-Batch Gradient 
Descent balances both by updating weights on small batches, combining efficiency with 
smooth convergence. 
Modern optimizers improve upon basic gradient descent. Momentum accumulates previous 
gradients to accelerate convergence along consistent directions. RMSProp scales learning 
rates by dividing by an exponentially decaying average of squared gradients, addressing 
oscillations. Adam combines both momentum and RMSProp, providing adaptive, efficient 
learning for deep networks. 
Proper learning-rate scheduling, regularization, and normalization ensure convergence. 
Gradient Descent underlies nearly all neural-network training and has enabled deep 
learning’s success across domains. 
B-9. Explain Reinforcement Learning and its concepts. 
Reinforcement Learning (RL) is a learning paradigm where an intelligent agent interacts 
with an environment to achieve a goal. Unlike supervised learning, where correct answers 
are known, RL relies on feedback in the form of rewards or penalties. The agent learns by 
trial and error to maximize cumulative reward over time. 
The RL system is modeled as a Markov Decision Process (MDP) defined by a set of states 
S, actions A, transition probabilities, and a reward function R. At each time t, the agent 
observes the current state sₜ, chooses an action aₜ according to a policy π(s), and receives 
a reward rₜ + 1 and new state sₜ + 1. The objective is to learn an optimal policy π* that 
maximizes expected discounted rewards: 
Gt=rt+1+γrt+2+γ2rt+3+…G_t = r_{t+1} + γ r_{t+2} + γ^2 r_{t+3} + … Gt=rt+1+γrt+2
+γ2rt+3+…  
A key concept is the value function V(s), representing the expected return from state s, 
and the action-value function Q(s, a), representing the expected return of taking action a 
in state s. RL algorithms learn these functions either directly or through sampling. 
Q-Learning is an off-policy algorithm that updates Q-values using 
Q(s,a)←Q(s,a)+α[r+γmaxa’Q(s’,a’)–Q(s,a)]Q(s,a) \leftarrow Q(s,a) + α [r + γ max_{a’} 
Q(s’,a’) – Q(s,a)]Q(s,a)←Q(s,a)+α[r+γmaxa’Q(s’,a’)–Q(s,a)]  
where α is the learning rate and γ the discount factor. Through repeated interaction, Q
values converge to optimal estimates. Policy-gradient methods, in contrast, directly 
optimize the policy’s parameters to maximize expected reward, forming the basis for 
advanced methods like Deep Reinforcement Learning. 
A central challenge is the exploration-exploitation trade-off: the agent must explore new 
actions to discover potentially higher rewards but also exploit known good actions. 
Strategies such as ε-greedy exploration and softmax sampling address this balance. 
Applications of RL are extensive: robotic control, game playing (as seen in AlphaGo), 
resource management, and recommendation systems. RL embodies autonomous intelligence, 
learning to act optimally through continuous interaction and adaptation.
