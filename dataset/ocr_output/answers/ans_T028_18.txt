A-1. You are given a dataset with missing and inconsistent values. Explain the steps you 
would follow to clean and prepare the data for a machine learning model. 
Steps for Data Cleaning 
1. First step is to open the dataset properly in system or software. 
2. Missing values can be seen by observing empty spaces in data table. 
3. If values are missing, they can be ignored because machine learning can adjust. 
4. Inconsistent values occur when data is not matching properly. 
5. Same data written in different styles should be made same. 
6. Extra data which is not required should be deleted. 
7. If data looks confusing, sorting can be applied. 
8. Data should be arranged in rows and columns neatly. 
9. Clean data helps model to understand better. 
10. After cleaning, dataset becomes suitable for learning.

1. First, predictions should be checked manually.

6. Features should be checked whether they are correct. 
7. If data is large, model may take time to learn. 
8. Changing algorithm may also help. 
9. Testing should be done multiple times. 
10. After improvement, predictions will become better.
