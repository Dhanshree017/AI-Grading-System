B-1. Challenges in ML & Solutions 
 Imbalanced data: One class bigger than other. 
Solution: Oversampling, undersampling, SMOTE. 
 Missing values: Data has blanks. 
Solution: Impute mean/median, remove rows. 
 Curse of dimensionality: Too many features. 
Solution: PCA, feature selection. 
 Concept drift: Data pattern changes over time. 
Solution: Retrain model regularly. 
Concept drift is like mood swings of dataset  
B-2. What is Regularization? Explain its types 
Regularization reduces overfitting by adding penalty to large weights. 
Types: 
 L1 Regularization (Lasso): Uses absolute values of weights, makes some weights 
zero. 
 L2 Regularization (Ridge): Uses squared weights, reduces weight size smoothly. 
 Elastic Net: Combination of L1 and L2. 
Regularization is like telling model “don’t act over-smart.” 
B-3. What is Ensemble Learning? Bagging & Boosting 
Ensemble learning: Combining multiple models to get better accuracy. 
 Bagging: Train models independently on random samples. 
Example: Random Forest. 
 Boosting: Models are trained one after another, each correcting previous errors. 
Example: AdaBoost, XGBoost. 
Ensemble is like asking many friends instead of one.
