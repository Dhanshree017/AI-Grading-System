A-1. Explain the concept of data preprocessing in machine learning. Discuss various 
preprocessing tasks and explain how they influence model performance. 
Concept of Data Preprocessing 
Data preprocessing in machine learning refers to the process of converting raw, real-world 
data into a clean, structured, and usable format before training a model. Since real datasets 
often contain missing values, noise, inconsistencies, and different data scales, preprocessing 
is essential to ensure that machine learning algorithms can learn accurate and meaningful 
patterns. 
Various Preprocessing Tasks and Their Influence 
Data cleaning removes missing values, duplicate records, and incorrect data, preventing 
models from learning misleading patterns. Encoding transforms categorical variables into 
numerical values so that algorithms can process them effectively. Feature scaling and 
normalization ensure that all numerical features contribute equally during training, 
improving convergence and accuracy. Outlier detection minimizes the effect of extreme 
values that can distort predictions. These preprocessing tasks significantly enhance model 
accuracy, stability, and generalization ability. 
A-2. Describe the working of a Decision Tree algorithm. Explain how decisions are made 
and discuss its advantages and limitations. 
Working of Decision Tree Algorithm 
A Decision Tree is a supervised machine learning algorithm that makes predictions by 
learning simple decision rules inferred from the training data. The algorithm begins with the 
entire dataset and recursively splits it into smaller subsets based on feature values. 
How Decisions Are Made 
At each node, the algorithm selects the best feature for splitting using criteria such as 
Information Gain, Gini Index, or Entropy. Each branch represents a decision outcome, and 
the leaf nodes provide the final prediction or class label. 
Advantages and Limitations 
Decision Trees are easy to understand, interpret, and visualize. They can handle both 
numerical and categorical data and require minimal preprocessing. However, they are highly 
prone to overfitting, sensitive to noisy data, and small changes in data can lead to different 
tree structures. 
A-3. Explain the bias–variance tradeoff. Discuss its impact on underfitting and overfitting 
with practical illustrations. 
Bias–Variance Tradeoff 
The bias–variance tradeoff represents the balance between model simplicity and complexity. 
Bias is the error caused by overly simple assumptions in the model, while variance is the 
error caused by excessive sensitivity to the training data. 
Impact on Underfitting and Overfitting 
High bias leads to underfitting, where the model fails to capture important patterns, such as 
using linear regression for complex nonlinear data. High variance leads to overfitting, where 
the model memorizes training data but performs poorly on unseen data. A good model 
balances bias and variance to achieve strong generalization. 
A-4. Discuss the importance of model evaluation in machine learning. Explain why 
accuracy alone is not sufficient and describe other evaluation measures. 
Importance of Model Evaluation 
Model evaluation is the process of assessing how well a machine learning model performs 
on unseen data. It helps in comparing different models, detecting errors, and ensuring 
reliability before deployment. 
Why Accuracy Alone Is Not Sufficient 
Accuracy can be misleading in cases of imbalanced datasets. For example, predicting all 
instances as the majority class may yield high accuracy but fail in real-world performance. 
Other Evaluation Measures 
Precision measures how many predicted positives are correct, recall measures how many 
actual positives are identified, F1-score balances precision and recall, and ROC-AUC 
evaluates performance across different thresholds. These metrics provide a complete 
understanding of model behavior. 
A-5. Explain the role of feature selection and dimensionality reduction. Discuss how these 
techniques help in building efficient ML models. 
Role of Feature Selection 
Feature selection involves selecting the most relevant features while removing irrelevant or 
redundant ones. This reduces noise, improves interpretability, and prevents overfitting. 
Role of Dimensionality Reduction 
Dimensionality reduction techniques such as Principal Component Analysis (PCA) reduce 
the number of input variables while preserving essential information. 
Benefits for ML Models 
These techniques reduce computational cost, speed up training, improve prediction accuracy, 
and enhance the model’s ability to generalize on new data.

Machine learning can analyze customer browsing patterns, purchase history, product 
descriptions, reviews, and return records to identify reasons for frequent returns. Predictive

B-2. A bank wants to detect fraudulent transactions in real time. Describe how machine 
learning can be applied for fraud detection, including data sources, model behavior, 
and challenges involved. 
Machine learning models use transaction data such as amount, location, device, and timing to 
detect unusual behavior. Classification and anomaly detection models flag suspicious 
transactions in real time. Challenges include highly imbalanced data, evolving fraud patterns, 
and minimizing false alarms.
