A-1) Explain the concept of model generalization and why it is important in machine learning 
Model generalization refers to how well a machine learning model performs on data that it has not seen 
before. When a model is trained, it uses a specific dataset, but in real life the model is applied to new data. If 
the model can give correct predictions on this new data, it is said to have good generalization. 
Sometimes a model learns the training data too closely, including noise and small details. This is called 
overfitting. Such a model performs very well on training data but poorly on new data. On the other hand, if a 
model is too simple, it may not learn important patterns, which leads to underfitting. Both these problems 
affect generalization. 
Generalization is important because machine learning models are mainly built for real-world use. A model 
that cannot generalize will not be useful in applications such as medical diagnosis, weather forecasting, or 
fraud detection. 
A-2) Describe the role of data labeling in supervised learning systems 
Data labeling is the process of giving correct output values to input data so that a supervised learning model 
can learn from it. In supervised learning, each training example consists of input data and its correct answer. 
These labels guide the model in learning how to map inputs to outputs. 
For example, in image classification, images are labeled as “cat”, “dog”, or “car”. In email filtering, emails 
are labeled as “spam” or “not spam”. The model uses these labeled examples to learn patterns and make 
predictions on new data. 
If data labeling is done correctly, the model can learn accurate relationships. But if labels are wrong or 
inconsistent, the model will also give wrong results. Therefore, data labeling plays a very important role in 
the success of supervised learning systems. 
A-3) Explain how ensemble methods improve prediction accuracy in machine learning 
Ensemble methods are techniques that use more than one machine learning model to make a final prediction. 
Instead of depending on a single model, multiple models are trained and their results are combined. This 
improves accuracy because different models may learn different patterns. 
When predictions from many models are combined, errors made by one model can be corrected by others. 
For example, Random Forest uses many decision trees, and their outputs are combined to get a better final 
result. Boosting methods improve accuracy by focusing more on data points that were wrongly predicted 
earlier. 
By combining many models, ensemble methods reduce overfitting and increase reliability. This makes them 
very useful in real-world applications such as financial forecasting and medical diagnosis. 
A-5) Explain the concept of model uncertainty and its significance in decision-making 
Model uncertainty refers to how confident a machine learning model is about its prediction. Sometimes a 
model may give a prediction but is not very sure about it, especially when the data is incomplete or different 
from the training data. 
Uncertainty is important in decision-making because it tells users when the model should not be fully 
trusted. For example, in medical diagnosis, if the model shows high uncertainty, a doctor should check the 
result instead of depending only on the machine. 
By understanding uncertainty, better and safer decisions can be made. It allows human experts to combine 
their judgment with machine predictions, which improves the overall reliability of the system.
