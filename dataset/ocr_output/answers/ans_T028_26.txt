A-1. You are given a dataset with missing and inconsistent values. Explain the steps you would follow to 
clean and prepare the data for a machine learning model. 
1. Data Understanding and Profiling 
The initial step is to gain a deep understanding of the data and identify all quality issues.  
 Inspect the data: Use descriptive statistics (mean, median, standard deviation) and visualizations 
(histograms, box plots, heatmaps for missing data) to get a feel for the data's distributions and identify 
anomalies, outliers, and the extent of missing values. 
 Identify the scope of issues: Determine the types of missing values (e.g., NaN , NULL , blank, "Not 
Applicable") and how inconsistencies manifest (e.g., "Male" vs. "M", different date formats). 
 Consult domain experts: Engage with subject matter experts to understand the context and origin of the 
data. This helps determine if an outlier is a genuine anomaly or a data entry error, and which imputation 
methods make logical sense. 
 Keep a copy: Always work on a copy of the raw dataset to preserve the original source of truth.  
2. Handling Missing Data 
The strategy for handling missing data depends on the amount of missingness, the type of data (numerical or 
categorical), and the reason for the data being absent (Missing Completely at Random - MCAR, Missing at 
Random - MAR, or Missing Not at Random - MNAR).  
 Deletion: 
o Drop rows: If the number of missing values is small relative to the entire dataset, or if the data is MCAR, 
rows with missing values can be removed. 
o Drop columns: If a column has a very high percentage of missing values (e.g., more than 60-70%) and is 
not critical to the analysis, it may be dropped entirely to avoid introducing too much bias through 
imputation. 
 Imputation: 
o Mean/Median/Mode: Fill numerical missing values with the mean or median of the column (median is 
better if there are outliers), and categorical missing values with the mode (most frequent value). 
o Forward/Backward fill: For time-series data, fill missing entries with the previous (forward fill) or next 
(backward fill) valid observation to maintain sequence and trends. 
o Predictive models: Use machine learning algorithms (like K-Nearest Neighbors or regression) to predict 
and fill in missing values based on other features in the dataset.  
3. Resolving Inconsistent Data and Structural Errors 
Inconsistencies arise from human error, different data sources, or a lack of standardized data entry 
protocols.  
 Standardize formats: Ensure all data follows a uniform format. This includes date formats (e.g., 
all YYYY-MM-DD), units of measurement (e.g., all weights in kg), and numerical representations (e.g., 
decimal places). 
 Normalize text entries: Convert all text to a consistent case (e.g., lowercase) and correct misspellings or 
variations (e.g., "NY" and "New York" to "New York"). Tools like OpenRefine are helpful here. 
 Fix invalid data: Identify and correct data that makes no logical sense based on business rules or domain 
knowledge (e.g., an age of 170, a negative duration). 
 Handle duplicate data: Identify and remove duplicate records that can skew analysis and model training.  
4. Outlier Management 
Outliers are extreme values that can disproportionately affect model performance.  
 Detect outliers: Use visualization tools like box plots or statistical methods like Z-score or Interquartile 
Range (IQR) to identify outliers. 
 Treat outliers: Depending on their cause, outliers can be removed (if they are errors), transformed (e.g., 
using log transformation), or capped/floored at a certain percentile. Sometimes, they represent interesting 
behavior and should be analyzed separately.  
5. Data Transformation and Preparation for Modeling 
Once the data is clean, it needs to be transformed into a format suitable for the specific machine learning 
algorithm.  
 Encode categorical variables: Convert categorical data into numerical format using techniques like one-hot 
encoding or label encoding, as most algorithms require numerical input. 
 Scale numerical features: Normalize (scale values between 0 and 1) or standardize (adjust to zero mean 
and unit variance) numerical features, especially for algorithms sensitive to the scale of input data (e.g., 
KNN, Support Vector Machines, neural networks). 
 Feature engineering (if needed): Create new, more informative features from existing ones (e.g., extracting 
month from a date column). 
 Split the dataset: Finally, split the prepared data into training, validation, and test sets.  
6. Validation and Documentation 
 Validate: Cross-check the cleaned data against the original (if possible) and run sanity checks to ensure the 
transformations did not introduce new errors. 
 Document: Keep a detailed log of all cleaning steps, the rationale for decisions, and any assumptions made. 
This ensures transparency, reproducibility, and collaboration. 
 Automate: Automate repetitive cleaning tasks using scripts or data cleaning tools to improve efficiency and 
reduce human error.
