A-1. Define Machine Learning. What is a hypothesis in ML? 
Machine learning is a branch of computer science that make machine learn 
automatically from data. It is the study where system can improve its performance 
on task through experience without being told by programmer every time. The main 
aim is to build algorithm which can find pattern and predict outcomes. Machine 
learning uses examples instead of hard-coded rules. 
A hypothesis in ML is like an assumption or a model that explain the relationship 
between input and output variables. It is the mathematical expression that learning 
algorithm tries to find during training. For example, in linear regression, hypothesis 
is the line equation that best fit data points. 
1. Machine learning involves data, algorithm and prediction. 
2. It learn from previous example. 
3. It reduce human work in data analysis. 
4. Supervised and unsupervised are main types. 
5. Hypothesis represent model structure. 
6. It is tested using validation data. 
7. The algorithm try to find best hypothesis with least error. 
8. If hypothesis wrong, prediction wrong. 
9. The goal is to minimize error between predicted and actual output.

A-3. Describe different types of learning algorithms in ML. 
There are many different types of learning algorithms used in machine learning, 
based on the type of data and supervision. Each one has its own logic for learning 
from examples. 
1. Supervised learning – algorithm trained with labeled data. It already know 
input and output. Example: linear regression, decision tree. 
2. Unsupervised learning – data not labeled and system try to find structure like 
grouping. Example: K-means clustering. 
3. Reinforcement learning – agent learn through feedback of reward or penalty. 
4. Semi-supervised learning – mixture of labeled and unlabeled data. 
5. Self-supervised learning – data used to create own label. 
6. Online learning – model update continuously when new data come. 
7. Deep learning – neural networks with many layers extract features. 
8. Transfer learning – model reuse learning from one problem to another. 
9. Active learning – algorithm choose data to learn from most informative 
samples. 
A-4. What are evaluation metrics in ML? Explain accuracy, precision, recall, and F1
score. 
Evaluation metrics are used to measure the performance of machine learning model. 
They help to know how good or bad the model is performing. Different metrics used 
based on type of problem such as classification or regression. 
Accuracy = (TP + TN) / (TP + TN + FP + FN) 
Precision = TP / (TP + FP) 
Recall = TP / (TP + FN) 
F1-score = 2 × (Precision × Recall) / (Precision + Recall) 
1. Accuracy shows total correctness of model. 
2. Precision tells how many predicted positives are correct. 
3. Recall shows how much of actual positives are found. 
4. F1-score is harmonic mean of precision and recall. 
5. These metrics calculated using confusion matrix. 
6. In imbalanced data, precision and recall are better than accuracy. 
7. F1 useful when classes not balanced. 
8. Higher F1 means better balance between recall and precision. 
9. These are essential to judge classifier performance.

B-2. Explain Artificial Neural Networks (ANNs). 
Artificial Neural Networks are inspired from biological neurons of human brain. It 
consists of interconnected nodes arranged in layers. Each connection has a weight 
that determines strength of connection. 
1. Consist of input, hidden, and output layers. 
2. Each neuron receive input, multiply by weight, add bias. 
3. Activation function applied to introduce nonlinearity. 
4. Output passed to next layer. 
5. Backpropagation algorithm adjust weights using gradient descent. 
6. Learning continues till loss minimized. 
7. Deep neural networks contain many hidden layers. 
8. Used in vision, speech, NLP tasks. 
9. Require large data and computation power.

4. Update centroids until no change.

6. Agglomerative method starts small and merge.

8. Dendrogram used to visualize hierarchy.

B-7. Describe Principal Component Analysis (PCA). 
PCA is a method used to reduce the dimensionality of data while preserving most of 
the information. It transforms correlated features into new set of uncorrelated 
variables called principal components. 
1. Standardize data. 
2. Compute covariance matrix. 
3. Find eigenvalues and eigenvectors. 
4. Sort components by eigenvalue. 
5. Select top components capturing high variance. 
6. Transform data to new coordinate system. 
7. Reduce noise and redundancy. 
8. Used in visualization and compression. 
9. Helps model train faster and avoid overfitting.

B-9. Explain Reinforcement Learning with MDP, Q-learning, and exploration
exploitation. 
Reinforcement learning is learning through interaction with environment using 
feedback in form of rewards. 
1. MDP represents problem using states, actions, rewards, and transitions. 
2. Policy defines what action to take in each state. 
3. Value function estimates long term reward. 
4. Q-learning update formula: Q(s,a)=Q(s,a)+α[r+γmaxQ(s’,a’)-Q(s,a)]. 
5. Exploration means trying new actions. 
6. Exploitation means choosing best known action. 
7. Balance of both necessary for good learning. 
8. Used in robotics, games, and automation. 
9. Agent continuously improve over time.
