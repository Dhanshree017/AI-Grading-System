A-3. What is Principal Component Analysis (PCA)? Why is it used? 
PCA is technique to reduce number of variables in dataset but keep important info. It 
transforms original correlated features into smaller uncorrelated components. PCA helps 
computer work faster and understand data better. 
1. Reduce number of features. 
2. Remove redundant info. 
3. Helps in visualization of high dimensional data. 
4. Makes computation faster. 
5. Reduces noise. 
6. Improve machine learning model performance. 
7. Useful in regression, classification. 
8. Can be used in image compression. 
9. Helps to identify patterns in data.

Creating ML model involve many steps to make model work properly. Steps from

A-5. What is Overfitting and Underfitting? Give examples of it. 
Overfitting is when model memorize training data too much and fail on new data. 
Underfitting is when model too simple and cannot capture pattern. Both affect 
performance. 
1. Overfitting: high training accuracy low test accuracy. 
2. Underfitting: low accuracy both training and test. 
3. Overfitting happen with complex models. 
4. Underfitting happen with simple models. 
5. Example overfitting: student learn old exam too much but fail new questions. 
6. Example underfitting: linear model for nonlinear data. 
7. Regularization helps reduce overfitting. 
8. More data reduce underfitting sometimes. 
9. Good model balance between two.

K-Means is unsupervised learning algorithm which put data into K groups based on 
similarity. Centroid of cluster calculated and points assigned to nearest centroid until 
stable. 
1. Group similar data automatically. 
2. Discover hidden patterns in data. 
3. Useful in customer segmentation. 
4. Reduce complexity of dataset. 
5. Can visualize clusters easily. 
6. Helps in marketing strategy. 
7. Used in image segmentation. 
8. Helps in organizing large dataset. 
9. Easy to implement and understand.

B-1. Define the term Bias and Variance. Elaborate on Bias-Variance Tradeoff. 
Bias is error when model make wrong assumptions, variance is error when model changes 
too much with different data. Bias-variance tradeoff is balance between bias and variance 
for good performance. 
1. High bias cause underfitting. 
2. High variance cause overfitting. 
3. Tradeoff helps model generalize well. 
4. Simple model more bias. 
5. Complex model more variance. 
6. Regularization reduce variance. 
7. Cross-validation helps find best tradeoff. 
8. Total error = bias + variance + irreducible error. 
9. Proper balance improve prediction. 
B-2. What is Regression? Explain its types in detail. 
Regression is supervised learning to predict continuous output based on input variables. 
1. Linear regression predict output with straight line. 
2. Multiple regression for multiple input variables. 
3. Polynomial regression for nonlinear data. 
4. Ridge regression penalize big weights. 
5. Lasso regression reduce unimportant features. 
6. Stepwise regression select features step by step. 
7. Logistic regression predict binary output. 
8. Time series regression for forecasting future data. 
9. Elastic net combine L1 and L2 penalties. 
B-3. What is Decision Tree? Explain its steps to implement it. 
Decision tree split data recursively based on feature to make decisions. Nodes check 
feature, branches split conditions, leaves give output. 
1. Choose root node with best feature. 
2. Split data according to feature value. 
3. Create sub-nodes for branches. 
4. Repeat splitting until pure leaf. 
5. Stop when further split unnecessary. 
6. Assign label to leaf node. 
7. Prune tree to reduce overfitting. 
8. Test tree with new data. 
9. Deploy tree for prediction.
