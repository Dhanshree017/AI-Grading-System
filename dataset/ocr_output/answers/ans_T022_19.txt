A-2. Describe the architecture and working of Convolutional Neural Networks (CNNs). 
Explain how convolution, pooling, and feature maps help in image understanding. 
Convolutional Neural Networks (CNNs) are a specialized class of deep learning models 
primarily used for analyzing visual data. Their architecture is designed to process data in a 
grid-like topology, leveraging specific layers (convolutional, pooling, and fully connected) to 
effectively extract hierarchical features from images [1].  
Architecture and Working of CNNs 
A typical CNN architecture is comprised of three main types of layers:  
1. Convolutional Layers 
This is the core building block of a CNN. The layer performs a mathematical operation 
called convolution. It involves a small matrix of numbers, known as a filter (or kernel), 
sweeping over the input image [1].  
 Working: The filter slides across the image, performing element-wise multiplication with 
the underlying pixels at each position, and summing the results [1]. This operation produces 
a single number in the output grid (the feature map) [1]. As the filter moves, it captures 
localized patterns such as edges, corners, or textures [1]. Multiple filters are used within a 
single layer to detect a variety of features simultaneously [1].  
2. Pooling Layers (Subsampling) 
Pooling layers are used to reduce the dimensionality of the feature maps, which decreases 
computational load and helps make the model more robust to variations in the position of 
features [1].  
 Working: A small window slides over the feature map. For max pooling, the most common 
type, the layer selects the maximum value within that window [1]. This retains the most 
prominent features while discarding less important information, making the network less 
sensitive to minor shifts or distortions in the input image [1].  
3. Fully Connected (FC) Layers 
After several rounds of convolution and pooling, the high-level features are flattened into a 
single vector and passed to standard neural network layers [1].  
 Working: These layers perform high-level reasoning and classification. They take the 
features extracted by the previous layers and use them to make a final decision, such as 
identifying if the image contains a cat, a dog, or a car [1].  
Key Components Explained 
Convolution 
Convolution is essential for image understanding because it exploits the spatial 
hierarchies in an image [1]. Early convolutional layers might detect basic elements like 
vertical or horizontal edges. Subsequent layers build upon these basic elements to detect 
more complex shapes (e.g., circles or corners), eventually forming abstract concepts like 
eyes or wheels [1]. This hierarchical learning is crucial for recognizing objects regardless of 
their position in the image.  
Feature Maps 
A feature map is the output of a convolutional layer. Each feature map highlights where a 
specific feature (like a vertical edge or a specific texture pattern) is located in the original 
image [1].  
 Role in Understanding: They provide a dense representation of the presence and strength of 
detected patterns. By visualizing these maps, researchers can see exactly what specific parts 
of the network are "looking for," confirming that the network learns to detect meaningful 
patterns rather than random noise [1].  
Pooling 
Pooling provides the network with translation invariance [1].  
 Role in Understanding: By downsampling the feature map, the exact location of a feature 
becomes less important than its general presence within a region. If an object shifts slightly 
to the left or right in the next frame of a video, the pooling layer will still produce a similar 
output, which helps the network consistently classify the object without needing to relearn 
the feature for every possible pixel location [1].

B-1. Define supervised learning. 
Supervised learning is a type of machine learning where an algorithm learns from labeled 
data (input-output pairs) to make predictions or decisions. It is like a student learning with a 
teacher, where the labeled data acts as the teacher providing the correct answers.  
The goal is to learn a mapping function that can accurately predict the output for new, 
unseen data. Supervised learning is used for two main types of problems:  
 Classification: Predicting a discrete category or class label (e.g., whether an email is "spam" 
or "not spam"). 
 Regression: Predicting a continuous numerical value (e.g., forecasting house prices based on 
size and location).

B-10. Define regularization in simple words. 
Regularization is a technique used in machine learning to prevent overfitting by 
discouraging the model from becoming too complex. It improves the model's ability to make 
accurate predictions on new, unseen data (generalization), rather than just memorizing the 
training data, including its noise.  
How It Works 
The core idea is to add a "penalty" to the model's objective or loss function during training. 
This penalty increases as the model's complexity grows (e.g., as the importance or magnitude 
of the feature weights/coefficients increases). The training process then seeks to find a 
balance between fitting the training data well and keeping the model simple.  
Think of it as the machine learning equivalent of "Occam's Razor," the principle that the 
simplest explanation is usually the best.
