convolution, pooling, and feature maps help in image understanding. 
CNN architecture is like a building mall where every floor is filter and lift is pooling layer. Convolution is 
sliding a glass window over the picture so model see only little piece at a time and forget the rest. Pooling is 
when everything gets shrink inside like zooming out too much. Feature maps are kind of treasure maps

same picture until it gets bored and finally gives answer. Image understanding happens because CNN 
sometimes guess and sometimes gets lucky. 
A-3. Discuss the concept of Explainable AI (XAI). Why is model interpretability important, and what 
are the major techniques used to interpret black-box models? 
Explainable AI means explaining the AI things by telling AI to explain itself which it usually not do because 
it is shy. Interpretability is important because otherwise teachers get angry as they don’t know what the 
machine is thinking inside its metal brain. Techniques include shouting at the model, opening its layers with 
screwdriver, and using heatmaps that show hot places of the picture. Black-box models are black because no

A-4. Explain the importance of Data Pipelines in machine learning projects. Describe how automation, 
versioning, and data validation improve reliability. 
Data pipelines are like water pipelines where data flows and sometimes leaks if too much files. They are 
important because without pipelines data will fall down on floor and break. Automation is when computer 
presses buttons automatically without asking anybody. Versioning means saving same file again and again 
but naming it v1, v99, v1000 until memory full. Data validation checks if data is real or fake by asking it 
simple questions. All this makes reliability because system feels more confident. 
A-5. Discuss different types of Data Drift (concept drift, feature drift, target drift). Explain how ML 
engineers detect drift and handle it in real-world systems. 
Data drift types are concept drift where concept drifts like clouds in sky, feature drift where features move to 
different place inside dataset, and target drift where target forgets what it was. Engineers detect drift by 
smelling the data or plotting some random graph until drift appears. Handling it includes retraining model 
again and again even if not needed, or increasing learning rate hoping drift disappears. Real-world systems 
drift naturally like boats so engineers just follow.
