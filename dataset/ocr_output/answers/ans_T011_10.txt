A-2. Define lazy learning and eager learning. What is reinforcement learning? 
Lazy learning is type of learning where system not make model during training time. 
It store data and when new query come it process at that time, like KNN. Eager 
learning build model first and then use it to predict new data fast, like decision tree 
or SVM. 
Reinforcement learning is method where agent learn by interacting with 
environment and getting feedback in form of rewards or punishment. 
1. Lazy learning slow while testing. 
2. Eager learning fast in testing but training take more time. 
3. Lazy learning not generalize early. 
4. Eager learning generalize before query. 
5. RL work with concept of reward. 
6. Agent, environment, action, reward are main parts. 
7. Learn from trial and error. 
8. Use value or policy based method. 
9. Used in robot control, gaming, navigation. 
A-3. Describe different types of learning algorithms in ML. 
There are mainly three main types of learning algorithm but more exist also 
depending on type of data. 
1. Supervised learning – algorithm trained using labeled dataset where output 
known. Example: Regression, Decision tree. 
2. Unsupervised learning – algorithm find structure and pattern in unlabeled 
data. Example: Clustering, PCA. 
3. Reinforcement learning – agent learn by performing action and receiving 
reward. 
4. Semi-supervised learning – mix of labeled and unlabeled data. 
5. Self-supervised learning – data itself used to generate labels. 
6. Online learning – model learn continuously as data come. 
7. Transfer learning – use knowledge of one task to another. 
8. Active learning – system choose data to ask for label. 
9. Deep learning – use neural networks with multiple layers to extract feature. 
A-4. What are evaluation metrics in ML? Explain accuracy, precision, recall, and F1
score. 
Evaluation metrics are used to measure model performance and to understand how 
well model predict correct values. 
Accuracy = (TP + TN) / (TP + TN + FP + FN) 
Precision = TP / (TP + FP) 
Recall = TP / (TP + FN) 
F1-score = 2 × (Precision × Recall) / (Precision + Recall) 
1. Accuracy show total correct prediction. 
2. Precision show correctness of positive prediction. 
3. Recall show how many actual positive found. 
4. F1-score balance between precision and recall. 
5. In imbalanced dataset accuracy may mislead. 
6. F1 is useful for uneven class problem. 
7. Use confusion matrix to calculate all. 
8. Used for classification models. 
9. High precision and recall mean good model.

B-1. Discuss Naive Bayes algorithm in detail. 
Naive Bayes is a probabilistic classifier based on Bayes theorem which assume that 
features are independent of each other given class. 
P(C|X) = P(X|C) * P(C) / P(X) 
1. It work on conditional probability. 
2. It assume all features are independent. 
3. It easy to implement and train very fast. 
4. Use prior and likelihood to compute posterior probability. 
5. Common type: Gaussian, Multinomial, Bernoulli. 
6. Mostly used in spam filtering, text classification. 
7. It perform well when independence assumption near true. 
8. For small data it still perform good. 
9. Handle categorical and continuous both features.

B-7. Describe Principal Component Analysis (PCA). 
PCA reduce dimension by transforming correlated features into new uncorrelated 
ones called principal components. 
1. Standardize data. 
2. Compute covariance matrix. 
3. Calculate eigenvalues and eigenvectors. 
4. Sort by eigenvalue descending order. 
5. Select top components. 
6. Transform data to new space. 
7. Keep maximum variance. 
8. Help visualization and speed up training. 
9. Use in image compression and bioinformatics. 
B-8. Explain Gradient Descent and its variants. 
Gradient Descent minimize cost by moving in direction of negative gradient. 
1. Formula: θ = θ - α * ∂J/∂θ 
2. Batch GD – use whole data each step. 
3. Stochastic GD – use single data each step. 
4. Mini-batch GD – use small subset each step. 
5. Help model converge faster. 
6. Need learning rate α control step. 
7. Too high α overshoot, too low slow. 
8. Used for neural network, regression. 
9. Converge to global or local minima.
