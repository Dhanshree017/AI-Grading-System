A-5. Explain Types of Search in AI. Explain Bidirectional Search in detail. 
Definition: 
Search in AI is when computer is looking for something. It may search file, data, goal, or 
answer. Like when we type in Google, it also search. So AI search means going from 
starting point to goal point but not always straight. 
Explanation & Points: 
1. Blind search – search without eye, it go random direction. 
2. Depth search – go down deep inside data but sometime lost. 
3. Breadth search – go wide but take long time. 
4. Mountain search – it go up then down like mountain algorithm (wrong name). 
5. Hill climbing – find top value like person climbing mountain. 
6. Bidirectional search – one search from start another from end and meet in middle 
like two friends meeting in park. 
7. Random search – pick random direction sometime reach goal by luck. 
8. Heuristic search – use some idea or guess to go near goal. 
9. Example – when we find lost file in computer both from desktop and from folder 
that is bidirectional search.
