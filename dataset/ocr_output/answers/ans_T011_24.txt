A-5. Explain types of search in AI. Explain Bidirectional Search in detail. 
Search in AI is way to find answer from start to goal. There are blind search and smart 
search. 
Blind search don’t know where is goal, it just try. Like DFS, BFS. 
Smart search know direction by heuristic. Like A star algorithm. 
Bidirectional search is where you search from both side same time. One from start and 
one from goal, and when both meet you find path. Example two friends walking from 
home and school, when they meet they know path. It is faster because it cover less 
nodes. But it use more memory.

B-1. Discuss Naive Bayes algorithm in detail. Include assumptions, mathematical formulation, 
and example. 
Naive Bayes is algorithm that use Bayes theory. It is called naive because it think all data 
features are not related but actually sometimes they are. Formula is: 
P(A|B) = P(B|A)*P(A)/P(B) 
It check which class have highest probability and then give answer. It is used in spam mail 
detection and sentiment analysis. 
Assumption is that all features independent and data is normal shape. Example if email 
has word “lottery”, “win”, “offer” then maybe spam. 
B-2. Explain the working of Artificial Neural Networks (ANNs) with architecture and 
learning process. 
Artificial Neural Network is like copy of human brain. It has neuron that connect to each 
other. Each connection has weight and bias. It learn by adjusting these weights. 
It has three layers: input, hidden, output. 
1. Input layer take data like number or picture. 
2. Hidden layer do calculation. 
3. Output layer give result. 
ANN learn by back propagation. It compare output and real answer, find error, and change 
weights little by little. Example, it can find picture of face. 
B-3. What are ensemble methods? Explain Bagging, Boosting, and Random Forest with 
examples. 
Ensemble mean many models together. It make performance better. Like group of student 
give better result than single one. 
Bagging: Each model trained with different sample, combine all. Example random forest. 
Boosting: Model trained one after another, next one fix previous one mistake. 
Random Forest: Many decision tree combined, each tree give one vote and final answer is 
majority. 
Example, use to predict if loan will be paid or not.

B-7. Describe the Principal Component Analysis (PCA) algorithm. Explain each step involved 
and discuss how PCA helps in dimensionality reduction. 
PCA is method that change data to small version. It remove repeated information. 
Steps: 
1. Normalize data. 
2. Make covariance matrix. 
3. Find eigenvector and eigenvalue. 
4. Choose big one. 
5. Make new data axis. 
Example use in face detection. PCA reduce many pixel to small features.
