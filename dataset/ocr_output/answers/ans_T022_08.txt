A-1. Explain the complete workflow of Feature Engineering. Discuss different types of features and the 
role of feature selection in improving model performance. 
Feature engineering is the steps where we take raw data and make it useful for machine learning. The 
workflow usually go like: 
1. First doing understanding of data, like what columns mean and which values looking weird. 
2. Cleaning part where missing values, outliers, noise are fixed or removed. 
3. Transforming features like scaling numeric, encoding categorical, splitting date columns into 
month/day. 
4. Making new features also, like ratios, interactions, text features, embeddings etc. 
5. Feature selection done to remove extra features which not helping model. This improve performance 
and reduce overfitting. 
6. Testing features with models and checking how pipeline running. 
Types of features include numerical, categorical, text, time-based, image features. Feature selection role is 
remove bad features and keep only useful ones so model train good and faster. 
A-3. Discuss the concept of Explainable AI (XAI). Why is model interpretability important, and what 
are the major techniques used to interpret black-box models? 
Explainable AI is about making model decisions understandable. Interpretability is needed so humans know 
why prediction done. It help in trust, fairness, debugging, and safety. 
Major techniques: 
1. SHAP values for showing contribution of each feature. 
2. LIME for local explanation. 
3. Feature importance from tree models. 
4. Grad-CAM for neural networks images. 
5. Partial dependence plots. 
A-4. Explain the importance of Data Pipelines in machine learning projects. Describe how automation, 
versioning, and data validation improve reliability. 
Data pipelines very important because without pipeline nothing run smooth. It control how data move from 
raw to model. Pipeline make work repeatable and always same steps. 
Automation make pipeline run on schedule and reduce human mistake. Versioning keep track of datasets, 
code, models so we can rollback. Data validation check schema, value ranges, missing values and stop 
pipeline if something wrong. 
A-5. Discuss different types of Data Drift (concept drift, feature drift, target drift). Explain how ML 
engineers detect drift and handle it in real-world systems. 
There is feature drift where X distribution changes, target drift where Y distribution changes, concept 
drift where relation between X and Y changes. 
Detection using statistical tests, PSI, KL divergence, distribution checks, or drop in model accuracy. 
Handling done with retraining, updating features, monitoring continuously, or using online learning. 
A-6. Explain Ensemble Learning in detail. Describe bagging, boosting, and stacking, and compare how 
each method improves model performance in different scenarios. 
Ensemble learning is method of combining models. Bagging use random subsets and reduce variance. 
Boosting fix errors step wise to reduce bias. Stacking combine outputs of many models and use meta model 
for final prediction. 
Bagging good for noisy data. Boosting good when want high accuracy. Stacking good when models diverse.
