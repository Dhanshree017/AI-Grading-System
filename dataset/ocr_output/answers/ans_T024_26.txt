A-1. Explain the difference between supervised and unsupervised learning with suitable 
real-world examples. 
Introduction 
Machine learning techniques are broadly classified based on the type of data available during 
training. Supervised and unsupervised learning represent two fundamental learning 
paradigms used to extract knowledge from data. 
Supervised Learning 
Supervised learning is a method where models are trained using labeled datasets. Each 
training example consists of input features along with the correct output label. The algorithm 
learns by minimizing the difference between predicted and actual outputs. 
Unsupervised Learning 
Unsupervised learning works with unlabeled data. The model is not provided with 
predefined outputs and instead identifies hidden patterns, relationships, or groupings within 
the data. 
Key Differences 
The primary difference lies in the presence of labeled outputs. Supervised learning focuses 
on predictive tasks, while unsupervised learning focuses on discovering underlying data 
structures. 
Real-World Examples 
Supervised learning is used in spam email filtering, medical diagnosis systems, and sales 
forecasting. Unsupervised learning is applied in customer segmentation, topic modeling, and 
anomaly detection. 
Advantages and Limitations 
Supervised learning generally provides higher accuracy but requires labeled data, which can 
be costly. Unsupervised learning requires no labels but may produce less interpretable 
results. 
Conclusion 
Both approaches are essential and are selected based on data availability and problem 
requirements. 
A-2. What is data preprocessing? Describe any four common preprocessing steps used 
before training an ML model. 
Definition of Data Preprocessing 
Data preprocessing is the process of converting raw data into a clean, structured, and 
machine-readable format suitable for training machine learning models. 
Need for Data Preprocessing 
Real-world data is often incomplete, inconsistent, and noisy. Preprocessing improves data 
quality and enhances model learning capability. 
Preprocessing Steps 
1. Data Cleaning: Removal of duplicate records, correction of inconsistent values, and 
handling missing data. 
2. Data Encoding: Conversion of categorical attributes into numerical values using 
encoding techniques. 
3. Data Normalization: Scaling numerical features to ensure uniform contribution 
during training. 
4. Outlier Treatment: Identification and handling of extreme values to avoid skewed 
model behavior. 
Impact on Model Performance 
Effective preprocessing leads to improved accuracy, stability, and generalization of models. 
Conclusion 
Data preprocessing is a crucial step that directly influences the success of machine learning 
systems. 
A-3. Explain classification and regression problems in machine learning. Give one 
example of each. 
Introduction 
Classification and regression are two major types of supervised learning problems, 
distinguished by the nature of their outputs. 
Classification Problems 
Classification involves predicting discrete output labels. The model assigns an input to one 
of several predefined classes. 
Regression Problems 
Regression involves predicting continuous numerical values based on relationships between 
input features and output variables. 
Differences Between Classification and Regression 
Classification outputs are categorical, whereas regression outputs are continuous values. 
Examples 
An example of classification is credit card fraud detection, where transactions are labeled as 
fraudulent or genuine. An example of regression is predicting house prices based on location 
and size. 
Applications 
Classification is widely used in healthcare, finance, and security, while regression is used in 
forecasting and estimation tasks. 
Conclusion 
Choosing the correct problem type is essential for accurate and meaningful predictions.
