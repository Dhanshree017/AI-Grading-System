A-2. What are the different types of machine learning? 
The types of machine learning they are three big ones. It depends on what kind of 
answer you are giving to the computer. 
1. Supervised Learning: Data is fully labeled, it has the correct answers already. It 
is like a teacher showing the computer the right way. 
2. Unsupervised Learning: Data is messy, it has no labels. The computer must find 
the secret groups by itself. 
3. Reinforcement Learning: This is like playing a video game, the computer gets 
points (rewards) for doing good actions and loses points for bad ones. 
4. There is also Semi-Supervised which is a mix of some labeled and much unlabeled 
data. 
5. The type of learning is very important for the result you want.

A-4. What is the bias-variance tradeoff? 
The Bias-Variance Tradeoff it is a major problem when you build a model. You cannot 
fix both errors at the same time, so you must choose. 
1. Bias is the error when the model is too simple. It is called underfitting. 
2. Variance is the error when the model is too complex. It is called overfitting. 
3. If you reduce Bias, the Variance will go up. This is the tradeoff rule. 
4. You must find the middle spot where the total error is lowest. 
5. The total error is the sum of all the errors that the model makes. 
A-5. What is overfitting, and how can it be avoided? 
Overfitting it is a big problem where the model learns the noise in training data too 
good. It becomes useless on new data. 
1. The training score is very high, but test score is very low. This is the sign. 
2. It can be avoided by getting much more training data, which is always the best 
fix. 
3. You can use Regularization, which is a penalty that punishes big parameters. 
4. You can use Early Stopping, which means you stop the training when the 
validation error starts getting worse. 
5. You can also simplify the model so it is not so smart.

B-2. How does a linear regression model work? 
Linear Regression it is the most important basic model that makes a straight line to 
predict a number. It is the base of all statistics. 
1. The model it works by finding the formula of the straight line, $\text{y} = 
\text{B} + \text{B}\text{X}$, but it uses the $\text{B}$ symbols for the 
parameters. 
2. The goal it is to put the line in a place where it is closest to all the data points. 
It is a balancing act on the chart. 
3. The closeness is measured by the Mean Squared Error (MSE). This MSE is what 
the model tries to get to the lowest number. This is the learning part. 
4. The model it uses an optimization algorithm like Gradient Descent to slowly 
move the line's parameters towards that lowest error point. 
5. The main idea is that the relationship between the input and output it must be 
exactly a straight line. If it is curvy, the model will not work and will suffer high 
bias. 
6. It is very easy to explain to people because you can show exactly how each feature 
makes the output number go up or down. Very transparent model. 
7. The model it is not good for data that is not straight, so you must check the 
plots before you use this model. If you don't check, you get bad results. 
8. There are some rules (assumptions) that the error must follow like the error is 
normal and the spread is constant. 
B-3. What is a decision tree, and how is it pruned? 
Decision Tree (DT) it is a model that uses easy rules like a flowchart to split the data 
until the answer is pure or almost pure. It is very easy for humans to read. 
1. The tree it starts at the top node and it picks the best question (split) that makes 
the data the cleanest at the next step. It is like a purity contest. 
2. The best split is chosen by maximizing the Information Gain. The Gain it measures 
how much the disorder (Entropy) is reduced after the split happens. 
3. The main problem is that the tree grows too big and gets too specific to the noise 
in the training data. This is the high variance problem and it is called overfitting. 
4. Pruning it is the method to cut the useless branches from the tree so it is not so 
overfit. Pruning it reduces the model complexity and makes it generalize better. 
5. Pre-pruning is when you stop the tree growing before it is finished, by setting 
limits like maximum depth or minimum samples in the leaf. You stop the growth 
early. 
6. Post-pruning is when you let the tree grow all the way first, and then you look 
at the validation set and you cut back the parts that don't help the score. This 
is usually better than pre-pruning. 
7. Pruning it finds the right balance by making the tree a bit simpler (higher bias) 
but much more reliable (lower variance). Balance is everything in models. 
8. DTs are very fast for training and predicting, but they are not stable because 
one tiny change in data can change the whole structure. 
B-5. Explain the Support Vector Machine (SVM) algorithm. 
Support Vector Machine (SVM) it is a very good classifier that draws the best straight 
line (hyperplane) to separate the two classes in the data. It is all about the biggest 
margin. 
1. The main idea it is to find the line that has the maximal margin or the largest 
gap between the two different classes of data points. A bigger margin is better 
generalization. 
2. The data points that are closest to this largest gap they are called Support 
Vectors (SVs). They are the only points that matter for the model. All other 
points are ignored by the line. 
3. Because it only cares about the SVs, the model it is very robust to outliers that 
are far away. It is also very efficient because it only stores the SVs and not all 
the data. 
4. For data that is all mixed up and not a straight line, the Kernel Trick is used to 
magically separate it. The Kernel Trick it transforms the data into a higher place 
where the separation is suddenly linear. 
5. The Kernel Trick it is actually a hidden shortcut that avoids the real high
dimension math, saving huge computer time. The RBF kernel is the most popular 
one for complex separation. 
6. When the data is messy, the Soft Margin it is used. This allows some points to 
cross the gap or be in the margin, but it gives better results on the test data. 
7. SVM it is a complex model but it has a guaranteed optimal solution because the 
math is convex. This is better than models that just find a local minimum. 
8. SVM it works best when the number of features is very high and the number of 
data points is not huge, like in text data or genetic data. 
B-6. What are kernels in SVM? 
Kernels in Support Vector Machine (SVM) they are special functions that make the 
SVM work on non-linear data by moving it to a higher dimension without actually 
doing the hard math. 
1. The Kernel Trick is the big idea. It lets the linear classifier (SVM) find a curvy 
boundary in the original data space. The boundary it can be any shape now. 
2. The problem is that most real data you cannot separate it with a straight line. 
You need a curvy line or a circle or something else. 
3. The Kernel function it calculates the similarity between two data points as if 
they were already in that high, invisible dimension. It is a computation shortcut. 
4. This trick it saves time and memory because it avoids the expensive calculation 
of all the data points into the higher space. Very smart idea. 
5. The Radial Basis Function (RBF) kernel it is the best and most popular one. It 
can handle very complex data that is mixed up a lot. 
6. The Polynomial kernel it is another type that calculates the relationship using a 
polynomial function. It is used for simpler curvy data. 
7. Kernels are very important because they make SVM so powerful. Without kernels, 
SVM is just a simple straight line drawer and not very useful for most 
applications. 
8. The choice of the right kernel it is a parameter you must tune, so you must try 
many different kernels and pick the one that gives the best score on the 
validation set.

C-1. What is Naive Bayes? 
Naïve Bayes (NB) it is a classification model that uses probability math. It is very simple 
and very fast for basic classification jobs. 
1. It is based on Bayes' Theorem which calculates the probability of a class being 
true given the input features. It is all about guessing likelihood. 
2. The naïve part is the big assumption that all the features are independent of 
each other, given the class. For example, the color of a car is independent of the 
size of the wheels. 
3. This naïve assumption it makes the math extremely simple, so the model it can 
be trained in very fast time, which is good for computers. 
4. The model training it is only calculating counts and how frequent the features 
are in the training data. No complex optimization is needed. 
5. NB it is very popular for text classification because it handles a huge number of 
features (words) well. Like spam filtering or sentiment analysis. 
6. There are different variants like Multinomial Naive Bayes (for text counts) and 
Gaussian Naive Bayes (for continuous numbers). You must choose the right 
variant. 
7. The model it does not work well when the features are strongly related because 
it violates the independence assumption. 
8. NB it is a great starting model to compare all other models against because it is 
so fast and gives a decent prediction score. 
C-2. How is k-Nearest Neighbors (KNN) different from k-means clustering? 
k-Nearest Neighbors (KNN) and k-Means Clustering they are two totally different 
things that only share the letter k. They are not similar at all. 
1. Learning Type: KNN it is a Supervised Learning model. It needs labeled data to 
predict a category. k-Means it is an Unsupervised Learning model. It only needs 
unlabeled data to find groups. 
2. Meaning of k: In KNN, the $k$ it is the number of neighbors that you use to vote 
for the new point's class. In k-Means, the $k$ it is the total number of clusters 
that you want the computer to find. 
3. Training: KNN is a lazy learner. It does not train anything; it just stores all the 
data. k-Means is an active learner. It iteratively moves the cluster centers during 
the training phase. 
4. Prediction: KNN predicts a new point by calculating the distance to all the stored 
points and taking the majority vote. k-Means it just groups the data and does 
not make a prediction for a new point in the same way. 
5. Output: KNN outputs a class label (a prediction). k-Means outputs $k$ centroid 
locations and cluster assignments for the old data. 
6. Distance Reliance: Both rely on distance metrics, so you must scale the features 
before you use either model. Scaling is very important. 
7. Curse of Dimensionality: KNN suffers badly from the curse of dimensionality 
when there are too many features. The distance becomes meaningless. 
8. Model Use: KNN is used for classification tasks. k-Means is used for customer 
segmentation and finding representative groups. 
C-3. What is gradient descent? 
Gradient Descent it is the engine of all modern machine learning. It is the optimization 
algorithm that finds the best set of parameters (weights) that minimizes the total 
mistake (loss function). 
1. It is an iterative method. It starts at a random spot and it moves slowly down 
the hill of the cost function. The goal it is to reach the lowest bottom. 
2. The gradient is the slope of the hill at the current point, and it tells you the 
direction of the steepest climb. 
3. The algorithm it moves in the opposite direction of the gradient. This is the 
steepest way down to the valley. 
4. The Learning Rate it is the hyperparameter that controls the size of the steps. If 
the rate is too big, it will jump over the bottom. If it is too small, it will take 
forever to reach the bottom. 
5. Gradient Descent it is used everywhere, in Linear Regression, in Logistic 
Regression, and it is the backbone of training all big Neural Networks. 
6. There are different types like Stochastic Gradient Descent (uses one point) and 
Batch Gradient Descent (uses all points). Mini-Batch Gradient Descent is the best 
one because it is a good compromise. 
7. The process it continues until the step size is almost zero, which means the model 
has found a good minimum. 
8. Without Gradient Descent, the computer would have to guess the billions of 
weights in a neural network, which is impossible. It makes learning possible. 
C-4. Explain the difference between Batch and Stochastic Gradient Descent. 
Batch Gradient Descent and Stochastic Gradient Descent they are two versions of the 
optimization algorithm. The difference is how much data they use for one update. 
1. Batch Gradient Descent (BGD) uses the entire training dataset to calculate the 
gradient and update the weights. It uses all the data in one big piece. 
2. Stochastic Gradient Descent (SGD) uses only one single example (one data point) 
to calculate the gradient and update the weights. It updates the weights for 
every single point. 
3. Speed: BGD is very slow per iteration because it must process the whole dataset. 
SGD is very fast per iteration because it only processes one point. 
4. Path to Minimum: BGD takes a smooth, stable path to the minimum because 
the gradient is the true average slope. SGD takes a noisy, jumpy path because 
the gradient is highly variable based on just one point. 
5. Convergence: BGD is guaranteed to settle exactly at the local minimum. SGD it 
oscillates around the minimum, never settling, but it can escape local minima. 
6. Memory: BGD requires a lot of memory to hold the entire dataset for one update. 
SGD requires very little memory, which is good for small computers. 
7. Mini-Batch Gradient Descent: The best version is Mini-Batch Gradient Descent, 
which uses a small subset of the data. It balances the stability of BGD with the 
speed of SGD. 
8. Application: BGD is not used much anymore because data is too big. SGD and 
Mini-Batch Gradient Descent are the standards for all modern deep learning 
because they are fast and memory efficient.
