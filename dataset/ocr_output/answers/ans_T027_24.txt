A-c. What is the bias–variance tradeoff? Explain how it affects model performance and 
generalization. 
The bias-variance tradeoff is the fundamental challenge in machine learning of balancing a 
model's simplicity (low complexity) against its ability to capture patterns, where high 
bias leads to underfitting (oversimplified model missing patterns) and high variance leads 
to overfitting (model too sensitive to training noise, failing on new data). The goal is to find 
the "sweet spot" of model complexity to minimize total error and 
maximize generalization (performance on unseen data).  
Bias vs. Variance 
 Bias Error (Underfitting): 
o Definition: Error from overly simplistic assumptions in the learning algorithm, making the 
model unable to capture the true underlying relationships in the data. 
o Effect: The model performs poorly on both training and test data because it's too simple 
(e.g., a straight line trying to fit a curve). 
 Variance Error (Overfitting): 
o Definition: Error from excessive sensitivity to small fluctuations or noise in the training 
data. 
o Effect: The model performs exceptionally well on training data but poorly on new, unseen 
data because it memorized noise instead of general patterns (e.g., a very complex, wiggly 
curve fitting every single training point).  
How it Affects Performance & Generalization 
 High Bias (Underfitting): The model is too rigid. It consistently misses the mark (high 
average error) because its fundamental assumptions are wrong, leading to poor 
generalization. 
 High Variance (Overfitting): The model is too flexible. Predictions jump around wildly 
with small changes in training data, making it unreliable and poor at generalizing. 
 The Tradeoff: As you increase model complexity (e.g., adding more layers to a neural 
network), bias decreases (model learns better) but variance increases (model becomes more 
sensitive to noise). Conversely, simplifying a model decreases variance but increases bias. 
 The Goal (Optimal Model): The ideal model finds the balance where total error (Bias² + 
Variance + Irreducible Error) is minimized, allowing it to perform well on training data 
without perfectly memorizing it, thus generalizing effectively to new data

A-e. Discuss the role of hyperparameters in machine learning models. Explain why 
hyperparameter tuning is necessary. 
Hyperparameters are parameters which are set before training starts. They control how 
model learns. Hyperparameters include learning rate, number of layers, depth of tree, number 
of neighbors, batch size, epochs and many more. 
Role of hyperparameters is very important because wrong hyperparameters can make model 
useless. If learning rate is too high then model diverges. If learning rate is too low then 
model learns very slowly. If number of layers is too many then overfitting happens. 
Hyperparameter tuning is necessary because there is no fixed value for hyperparameters. 
Different datasets need different hyperparameters. Tuning helps to find best combination. 
Methods like grid search, random search are used. 
Hyperparameter tuning improves accuracy, stability and convergence. Without tuning model 
performance is unpredictable. Hyperparameters control model behavior strongly. 
A-f. Explain the concept of model deployment. Discuss the challenges faced while 
deploying ML models in real-world applications. 
Model deployment means putting trained model into real world use. Deployment is when 
model is used by users through apps, websites, APIs or systems. Deployment is final step 
after training. 
Deployment can be done on cloud, server, mobile or embedded devices. Model must be 
converted into usable format. Deployment is not simple because many issues arise. 
Challenges include data drift where new data is different from training data. Model 
performance drops over time. Scalability is another challenge when many users use model. 
Latency is problem when prediction is slow. 
Security is challenge because data can be attacked. Privacy is challenge because user data 
must be protected. Model monitoring is required to check performance. Retraining is 
required when model becomes outdated. 
Deployment is continuous process and not one time task. It needs maintenance and updates 
regularly.
