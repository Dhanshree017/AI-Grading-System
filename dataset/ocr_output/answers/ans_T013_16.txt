A-1. Define Machine Learning and list its three main categories. 
Machine learning is like when a computer is learning something by itself, like 
a child learning how to ride a bicycle. It means we don’t teach the computer 
everything directly, but it learns from examples and patterns. Machine 
learning is part of artificial intelligence and used in robots and even in 
YouTube recommendation. 
The three main types of machine learning are: 
1. Linear learning – when the computer learns in a straight line way from 
data. 
2. Circular learning – when it learns again and again till it gets good. 
3. Super learning – which is like supervised, when we give correct answers 
and computer matches. 
4. What is the purpose of a confusion matrix in model evaluation? 
Confusion matrix is a big table that tells us where the model is confused. It 
is like when we check how many answers we wrote correct and how many we 
messed up. 
It has four parts like true and false and positive and negative.

A-5. Explain the term feature selection and why it is important. 
Feature selection means removing the things from data that are not needed. 
For example, when we have a dataset about students, we might remove the 
“shoe size” because it doesn’t affect marks. 
It is important because: 
 It helps in reducing training time. 
 It makes model less confused. 
 It also saves computer memory. 
Too many features can make a model crazy because it has to remember 
a lot.

Batch learning means the computer eats the whole data at one time, like 
eating a big meal. Online learning means it eats little by little, like snacks. 
Batch learning is done once, online is continuous. 
Example of batch learning is training a model on all data at night. Example

One-hot encoding is used for converting words to numbers so computer can

A-11. Explain cross-validation and its advantage over a single train-test split. 
Cross-validation divides the data into small small pieces and uses each piece 
once for testing and rest for training. 
This helps to get a more accurate result and prevents lucky or unlucky splits. 
It is better because every data gets a chance to become test once. It’s like

B-1. What is Feature Engineering? Discuss its role and techniques like encoding, 
scaling, and polynomial feature generation. 
Feature engineering means doing something to the data before giving it to 
model. Like cooking food before eating. 
It includes cleaning, changing, or making new columns. 
Role: 
It helps model to learn better and gives more accurate results. 
Without it, data may have missing values or big numbers that confuse the 
model. 
Techniques: 
 Encoding: Change words to numbers. Example: male = 0, female = 1. 
 Scaling: Make all numbers of similar size so that no one dominates. 
 Polynomial feature: Multiply or square existing values to make new 
patterns. 
If we do feature engineering well, even a simple model can perform like a 
deep one. 
B-3. Explain K-Means Clustering algorithm with step-by-step working and 
advantages. 
K-Means is a clustering algorithm. It divides data into K groups where each 
group has similar members. 
Steps: 
1. Choose K randomly. 
2. Pick random points as centers. 
3. Assign data points to nearest center. 
4. Calculate average (mean) for each group. 
5. Keep repeating until centers don’t move. 
Advantages: 
 Very easy to use. 
 Works fast for large datasets. 
 Can be used in image compression. 
Disadvantage: It can give wrong clusters if K is not chosen correctly. 
B-4. What is Early Stopping in ML training? Explain how it prevents overfitting. 
Early stopping means we stop training when model starts performing worse 
on validation data even though training accuracy is still increasing. 
For example, if training loss keeps decreasing but validation loss increases, 
that means overfitting. 
It helps because model doesn’t memorize the data after learning the pattern. 
It saves time and keeps model general. 
B-5. Explain Bias–Variance Tradeoff. Show how it impacts model generalization. 
Bias means when the model is too simple, like a line trying to fit a curve. 
Variance means when the model is too flexible and fits even noise. 
The tradeoff means we need a balance between both. 
If bias is high → model underfits. 
If variance is high → model overfits. 
A perfect balance gives best accuracy on new data. 
Example: decision tree with few splits has high bias; with many splits has 
high variance.
