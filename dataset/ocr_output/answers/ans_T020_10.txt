SECTION A —  
A-a) Explain how data drift and concept drift affect the long-term performance of 
machine learning models. Discuss the different types of drift and practical strategies to 
detect and handle them. 
Intro 
Machine learn model works good first time but after time data change so model no work 
good. This is data drift and concept drift. 
Data Drift 
Data drift is when input data change over time. Example, user buy in morning not evening 
like before. 
Concept Drift 
Concept drift is relation between feature and output change. Example, earlier age decide 
purchase now it depend on weather. 
Types of Drift 
 Sudden Drift: data change one time fast. 
 Gradual Drift: slowly data change. 
 Recurring Drift: pattern come again sometimes. 
 Incremental Drift: little by little change happen. 
Detection and Handling 
Check accuracy or feature histograms. Some students just retrain model all time which not 
always help. Online learning, retrain, or combine old new model can use.

A-e) Discuss the difference between batch learning and online learning. Explain the 
scenarios where online learning is preferred and the challenges involved. 
Batch Learning 
Train whole data, stable but slow, need retrain with new data. 
Online Learning 
Train step by step with new data. Good for sensor, click stream, stock. 
Challenge
