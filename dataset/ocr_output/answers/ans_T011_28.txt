A-1. Define Machine Learning. What is Hypothesis in ML? 
Hypothesis in ML: 
Hypothesis is like one assumption or guess which the algorithm make to map 
input and output. It is the model that tell how x relate to y. For example, 
in linear regression the hypothesis is y = mx + c which is line that best fit 
the data. The algorithm try to find best hypothesis that give minimum 
error. 
A-2. Define Lazy Learning and Eager Learning. What is Reinforcement Learning? 
Lazy Learning: 
In lazy learning, the system does not learn during training time. It store all 
training data and when the new query comes, then it process and find the 
result. It is lazy because it delay the learning work until it is needed. 
Example of lazy learning is K-Nearest Neighbour (KNN) where the system 
keep data and compute answer at the time of testing. 
Reinforcement Learning: 
Reinforcement learning is the type of learning in which an agent learn by 
doing actions in environment and getting feedback in the form of reward or 
penalty. It is based on the concept of trial and error. The main goal is to 
maximize the total reward in long run. 
Points: 
1. Lazy learning delay training and use data later. 
2. Eager learning train model early then predict fast. 
3. RL is feedback-based learning. 
4. It has agent, environment, reward, policy. 
5. The agent observe environment and act. 
6. Good action give reward and bad action give penalty. 
7. It use Q-learning and Markov Decision Process. 
8. RL used in games, robotics, control system. 
9. The main target is to get best reward possible. 
A-4. What are Evaluation Metrics in ML? Explain Accuracy, Precision, Recall and 
F1 Score. 
Evaluation metrics are the measures which tell how good or bad the machine 
learning model is performing. It check the correctness of prediction and 
performance of model. 
Accuracy: 
Accuracy is the most common metric which means number of correct 
prediction out of total prediction. It work best when data is balanced. 
Precision: 
Precision is ratio of correctly predicted positive observation to total 
predicted positive observation. 
Recall: 
Recall is ratio of correctly predicted positive observation to all actual positive 
observations. 
F1 Score: 
It is harmonic mean of precision and recall which give better single measure 
when we need balance between both. 
Points: 
1. Evaluation metric judge model quality. 
2. Accuracy = (TP + TN)/(TP + TN + FP + FN). 
3. Precision = TP / (TP + FP). 
4. Recall = TP / (TP + FN). 
5. F1 = 2 * (Precision * Recall) / (Precision + Recall). 
6. Confusion matrix used to see all outcomes. 
7. AUC ROC tell classification ability. 
8. F1 good when class imbalance exist. 
9. Good model have high precision and recall. 
A-5. Explain Feature Selection and Dimensionality Reduction. 
Feature selection and dimensionality reduction are both techniques used to 
reduce number of input variables in model and make learning simple. 
Feature Selection: 
Feature selection means choosing only those features which are most 
important for prediction and removing irrelevant ones. It reduce overfitting, 
improve accuracy and reduce computation time. 
Dimensionality Reduction: 
It means reducing overall number of variables or dimensions in dataset while 
keeping as much information as possible. 
Points: 
1. Feature selection remove useless features. 
2. Dimensionality reduction transform features to new space. 
3. PCA, LDA used for dimension reduce. 
4. Filter, Wrapper, Embedded used for selection. 
5. It improve speed of algorithm. 
6. Reduce overfit and noise. 
7. Make data easy to visualize.
