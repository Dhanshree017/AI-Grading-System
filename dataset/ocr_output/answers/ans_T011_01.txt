A-1. Define Machine Learning. What is a hypothesis in ML? 
Definition: 
Machine Learning (ML) is a subfield of Artificial Intelligence that enables systems to 
learn from experience without explicit programming. Instead of following hard-coded 
rules, ML algorithms identify patterns and relationships in data to make predictions 
or decisions. The goal of ML is to generalize from past examples to unseen data 
effectively. 
Hypothesis in ML: 
A hypothesis in Machine Learning represents a potential mapping function between 
input variables (X) and the output variable (Y). It defines the model’s assumed 
relationship, which the learning algorithm attempts to find by minimizing the error 
between predictions and actual outcomes. 
Key Points: 
1. ML systems automatically learn from data. 
2. Hypothesis acts as the model’s functional form. 
3. The learning algorithm selects the best hypothesis from a hypothesis space (H). 
4. The hypothesis defines how inputs are transformed into outputs. 
5. A good hypothesis minimizes generalization error. 
6. In supervised learning, it’s trained on labeled examples. 
7. In unsupervised learning, it represents discovered structures or clusters. 
8. The quality of a hypothesis depends on model complexity and data diversity. 
9. Examples: Linear regression’s hypothesis is h(x)=w0+w1xh(x) = w_0 + 
w_1xh(x)=w0+w1x. 
A-3. Describe different types of learning algorithms in ML 
Machine Learning algorithms are categorized based on how they learn from data and 
the kind of feedback they receive. 
Types: 
1. Supervised Learning – Learns from labeled data to predict outcomes (e.g., 
regression, classification). 
2. Unsupervised Learning – Finds hidden structures in unlabeled data (e.g., 
clustering, association). 
3. Semi-Supervised Learning – Uses a small labeled dataset with large unlabeled 
data. 
4. Reinforcement Learning – Learns by interacting with the environment via 
rewards. 
5. Self-Supervised Learning – Model generates its own labels (common in deep 
learning). 
6. Online Learning – Continuously updates the model as new data streams in. 
7. Batch Learning – Trains the model using a fixed dataset. 
8. Deep Learning – Uses multi-layer neural networks for complex 
representations. 
9. Transfer Learning – Reuses knowledge from one domain to another. 
These learning paradigms collectively enable machines to solve diverse real-world 
problems like recommendation, forecasting, and image recognition.

score. 
Definition: 
Evaluation metrics are used to measure the performance and effectiveness of a 
machine learning model. They help compare models and identify their strengths and 
weaknesses, especially in classification problems. 
Metrics: 
1. Accuracy – Ratio of correct predictions to total predictions. 
Accuracy=TP+TNTP+TN+FP+FNAccuracy = \frac{TP + TN}{TP + TN + FP + 
FN}Accuracy=TP+TN+FP+FNTP+TN

positives. 
Precision=TPTP+FPPrecision = \frac{TP}{TP + FP}Precision=TP+FPTP 
3. Recall (Sensitivity) – Measures how many actual positives were correctly 
predicted. 
Recall=TPTP+FNRecall = \frac{TP}{TP + FN}Recall=TP+FNTP 
4. F1-Score – Harmonic mean of precision and recall. 
F1=2×Precision×RecallPrecision+RecallF1 = 2 \times \frac{Precision \times

5. Confusion Matrix – Tabular visualization of true vs. predicted classes.

7. Specificity – Measures how well negatives are identified. 
8. Balanced Accuracy – Useful for imbalanced datasets. 
9. Macro and Micro Average – Used for multi-class evaluation. 
A-5. Explain feature selection and dimensionality reduction. 
Feature Selection: 
Feature selection is the process of identifying and choosing the most relevant input 
variables that contribute significantly to model prediction. It improves performance, 
reduces overfitting, and speeds up computation. 
Dimensionality Reduction: 
Dimensionality reduction transforms high-dimensional data into a lower-dimensional 
space while retaining essential information. 
Key Points: 
1. Reduces computational cost and training time. 
2. Enhances model interpretability and visualization. 
3. Prevents overfitting by removing noise and redundancy. 
4. Methods of Feature Selection: Filter, Wrapper, Embedded. 
5. Methods of Dimensionality Reduction: PCA, LDA, t-SNE. 
6. PCA captures maximum variance in fewer dimensions. 
7. Feature importance can be derived using tree-based models. 
8. Helps manage curse of dimensionality. 
9. Essential for big data and image processing applications.

B-1. Discuss Naive Bayes algorithm in detail. Include assumptions, mathematical 
formulation, and example. 
Definition: 
Naive Bayes is a probabilistic classifier based on Bayes’ theorem, assuming feature 
independence. It is simple yet effective for text classification, spam filtering, and 
sentiment analysis. 
Mathematical Formulation: 
P(C∣X)=P(X∣C)P(C)P(X)P(C|X) = \frac{P(X|C)P(C)}{P(X)}P(C∣X)=P(X)P(X∣C)P(C)  
Where: 
 CCC = class label 
 XXX = input features 
Assumptions & Points: 
1. All features are conditionally independent. 
2. Works well with categorical data. 
3. Trains efficiently on large datasets. 
4. Handles missing values using probabilities. 
5. Gaussian, Bernoulli, and Multinomial variants exist. 
6. Performs well with text and document classification. 
7. Despite independence assumption, gives good results. 
8. Example: Email spam classification. 
9. High bias, low variance model — suitable for quick decisions. 
B-2. Explain the working of Artificial Neural Networks (ANNs) with architecture and 
learning process. 
Definition: 
ANNs are computational models inspired by biological neurons. They consist of 
interconnected nodes organized in layers to process information and learn complex 
relationships. 
Architecture: 
1. Input Layer – Receives raw data. 
2. Hidden Layers – Perform transformations using activation functions. 
3. Output Layer – Produces predictions. 
Learning Process: 
1. Forward propagation computes predictions. 
2. Error calculated using loss function. 
3. Backpropagation adjusts weights to minimize loss. 
4. Activation functions (ReLU, Sigmoid) introduce non-linearity. 
5. Gradient Descent optimizes weights iteratively. 
6. Regularization prevents overfitting. 
7. Dropout used to improve generalization. 
8. Used in vision, NLP, and robotics. 
9. Example: Handwritten digit recognition (MNIST).

B-4. Explain unsupervised learning algorithms like K-Means Clustering and Hierarchical 
Clustering. 
Unsupervised Learning: 
Unsupervised learning finds hidden patterns in unlabeled data. 
K-Means Clustering: 
1. Divides data into K clusters. 
2. Each cluster has a centroid representing its mean. 
3. Algorithm minimizes intra-cluster variance. 
4. Steps: Initialize K centroids → Assign points → Update centroids → Repeat. 
5. Example: Customer segmentation. 
Hierarchical Clustering: 
1. Builds a hierarchy of clusters. 
2. Two types: Agglomerative (bottom-up) and Divisive (top-down). 
3. Dendrogram shows merging/splitting of clusters. 
4. No need to specify K beforehand. 
5. Example: Document grouping. 
Comparison: 
K-Means is efficient; Hierarchical gives structural relationships between clusters.

B-7. Describe the Principal Component Analysis (PCA) algorithm. Explain each step 
involved and discuss how PCA helps in dimensionality reduction. 
Definition: 
PCA is a linear dimensionality reduction technique that transforms data into new 
coordinates (principal components) maximizing variance while reducing redundancy. 
Steps: 
1. Standardize the dataset. 
2. Compute the covariance matrix. 
3. Calculate eigenvalues and eigenvectors. 
4. Sort eigenvectors by eigenvalues in descending order. 
5. Select top-k components. 
6. Project data onto new feature subspace. 
7. Reconstruct reduced dataset. 
8. Visualize principal components. 
9. Reduces storage, noise, and computational cost. 
Applications: Image compression, data visualization, and preprocessing for ML 
models. 
B-9. Explain the concept of Reinforcement Learning (RL). Discuss Markov Decision 
Processes (MDP), Q-learning, and the exploration–exploitation dilemma. 
Definition: 
Reinforcement Learning is a goal-oriented learning paradigm where agents learn 
optimal actions through interaction and feedback. 
Markov Decision Process (MDP): 
1. Framework for modeling RL problems. 
2. Defined by states (S), actions (A), transition probabilities (P), and rewards (R). 
3. Agent aims to maximize long-term cumulative reward. 
Q-Learning: 
1. Off-policy RL algorithm. 
2. Updates Q-values using Bellman Equation: 
Q(s,a)=Q(s,a)+α[r+γmax⁡Q(s′,a′)−Q(s,a)]Q(s,a) = Q(s,a) + \alpha [r + \gamma 
\max Q(s',a') - Q(s,a)]Q(s,a)=Q(s,a)+α[r+γmaxQ(s′,a′)−Q(s,a)]  
3. Learns optimal action-value function without model knowledge. 
Exploration–Exploitation Dilemma: 
1. Exploration – Try new actions to discover better rewards. 
2. Exploitation – Use known actions for best results. 
3. Balance ensures effective learning. 
Applications: Robotics, autonomous vehicles, and gaming (e.g., AlphaGo).
