A-2. Define the term overfitting and one solution for it 
Overfitting is something when model learn too much and memorize data and then 
when new data comes it cannot predict properly. Overfitting is bad, it happen in 
deep learning mostly and sometimes in normal regression too. Because model 
memorize all small noise and error also. So it is not good. I think solution is 
regularization or dropout, but also maybe add more data. Early stopping also 
possible. 
1. Overfitting is memorizing training data. 
2. Happens in deep learning and sometimes in small datasets. 
3. Bad for model performance. 
4. Use regularization, dropout, or early stopping. 
5. Increase dataset can reduce overfitting. 
Actually sometimes model still overfit even after solution, so it is tricky. Overfitting is 
confusing but important.

B-5. Explain Decision Tree in detail 
Decision tree is like tree, node questions, leaf answers. Split data and give result. 
Used in classification and regression. 
Root node start, internal nodes decisions, branches outcomes, leaf node final result. 
Algorithm split data recursively using info gain or gini. Stop when max depth or few 
samples. 
Decision tree used in finance, healthcare, marketing. Can predict loan approval, 
disease, customer segment. 
1. Easy to understand. 
2. Handle numeric/categorical. 
3. Little preprocessing. 
4. Recursive split. 
5. Root, internal, branch, leaf. 
6. Applications many areas. 
7. Base for Random Forest, Boosting. 
8. Sometimes overfit.
