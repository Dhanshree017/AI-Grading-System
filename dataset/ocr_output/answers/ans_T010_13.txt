A-3. What is Regression and Classification, explain types of Regression. 
Regression: 
Regression is a supervised learning technique used to predict continuous outcomes 
based on input variables. It helps to identify the relationship between dependent and 
independent variables. 
Types of Regression: 
1. Linear Regression: Establishes a straight-line relationship between dependent 
and independent variables. 
2. Multiple Linear Regression: Uses multiple input variables to predict a single 
output. 
3. Polynomial Regression: Models non-linear relationships using polynomial terms. 
4. Ridge Regression: Adds L2 regularization to prevent overfitting by penalizing 
large coefficients. 
5. Lasso Regression: Uses L1 regularization to shrink irrelevant features toward 
zero. 
6. Logistic Regression: Though named regression, it is used for binary classification 
problems. 
Example: Predicting house prices based on size and location. 
A-4. What is Intelligent Agent? Explain any 3 types of agent. 
Definition: 
An intelligent agent is an autonomous entity capable of perceiving its environment, 
processing information, and taking actions to achieve specific goals. It uses sensors for 
perception and actuators for performing actions. 
Types of Agents: 
1. Simple Reflex Agent: 
o Acts only based on the current situation using condition-action rules. 
o Example: A thermostat that turns on the heater when the temperature 
is low. 
2. Model-Based Reflex Agent: 
o Uses internal memory of past states to make better decisions. 
o Example: Self-driving cars that remember road structures. 
3. Goal-Based Agent: 
o Works toward achieving specific goals and evaluates possible outcomes 
before acting. 
o Example: Pathfinding robots or delivery drones. 
4. Utility-Based Agent: 
o Chooses actions based on utility (happiness/satisfaction level). 
o Example: Automated stock trading systems. 
5. Learning Agent: 
o Continuously improves performance through experience and feedback. 
o Example: AI game bots that improve over time. 
A-5. Explain Types of Search in AI. Explain Bidirectional Search in detail. 
Search in AI: 
Search algorithms help AI systems explore possible solutions to reach the desired goal 
efficiently. They are classified into two main types: 
1. Uninformed (Blind) Search: 
 Does not use any domain knowledge. 
 Examples: Breadth-First Search (BFS), Depth-First Search (DFS), Uniform Cost 
Search. 
2. Informed (Heuristic) Search: 
 Uses heuristics (knowledge-based estimates) to guide the search. 
 Examples: A* Search, Greedy Best-First Search. 
Bidirectional Search (in detail): 
 It runs two simultaneous searches — one forward from the initial state and 
one backward from the goal. 
 The search stops when both meet in the middle. 
 Advantages: Reduces time complexity drastically from O(b^d) to O(b^(d/2)), 
where b = branching factor, d = depth. 
 Example: Used in GPS navigation to find the shortest path between two 
locations.

B-1. Write a short note on Belief Networks. 
Belief Networks, or Bayesian Networks, are graphical models that represent 
probabilistic relationships among a set of variables. They use directed acyclic graphs 
where nodes represent variables and edges denote dependencies. These networks help 
in reasoning under uncertainty, such as medical diagnosis systems. 
B-3. What is Naïve Bayes? 
Naïve Bayes is a probabilistic classifier based on Bayes’ Theorem, assuming 
independence among features. It is simple yet effective for text classification, spam 
detection, and sentiment analysis tasks. 
B-4. What is Support Vector Machine? 
Support Vector Machine (SVM) is a supervised learning algorithm used for 
classification and regression. It finds the optimal hyperplane that maximally 
separates data points of different classes in a high-dimensional space. 
B-5. What is Ensemble Learning and its types. 
Types: 
1. Bagging: Builds multiple independent models and averages their predictions 
(e.g., Random Forest). 
2. Boosting: Sequentially trains models where each corrects the errors of the 
previous one (e.g., AdaBoost, XGBoost). 
3. Stacking: Combines outputs of multiple models using a meta-model for final 
prediction.
