A-1. Explain the concept of model drift. Discuss different types of drift and why continuous monitoring 
is required. 
Definition 
Model drift occurs when a trained machine learning model’s predictive accuracy declines over time due to 
changes in the input data, feature distribution, or the underlying relationships in the data. This can happen in 
dynamic real-world environments where patterns evolve. 
Types of Drift 
1. Covariate Drift (Feature Drift): Distribution of input features changes. 
Example: Traffic sensor data changes with season or construction work. 
2. Prior Probability Drift (Label Drift): Target class distribution shifts. 
Example: The number of fraudulent transactions rises during holidays. 
3. Concept Drift: Relationship between features and target changes. 
Example: Previously, “time spent on site” predicted purchase; now, mobile users browse longer but 
buy less. 
Continuous Monitoring 
 Detect early degradation before business impact. 
 Identify which drift type is occurring. 
 Decide when retraining or recalibration is needed. 
 Maintain fairness, reliability, and consistency of predictions. 
A-3. Describe the function of an embedding in machine learning. Why are embeddings useful for text, 
images, or categorical data? 
Function 
 Embeddings map high-dimensional or categorical data into dense vector spaces. 
 Capture semantic relationships and similarities among data points. 
 Reduce dimensionality while preserving information for learning. 
Usefulness 
 Text: Word embeddings (Word2Vec, GloVe) capture semantic meaning, e.g., “doctor” and “nurse” 
are close in vector space. 
 Images: Embeddings encode visual features like edges, shapes, and textures into compact vectors. 
 Categorical Data: Convert high-cardinality features like product IDs into vectors that reflect 
similarity. 
 Improve model efficiency, generalization, and similarity computations. 
A-4. What is concept learning in ML? Explain how hypothesis space and inductive bias influence 
concept learning. 
Definition 
Concept learning is the process by which a model generalizes a rule or pattern from examples to correctly 
classify unseen instances. 
Hypothesis Space 
 Set of all possible models or rules the algorithm can select. 
 Larger space allows complex rules but increases risk of overfitting. 
 Smaller space favors simplicity but may not capture complex patterns. 
Inductive Bias 
 Set of assumptions guiding hypothesis selection. 
 Examples: preference for simpler rules, linear boundaries, or smooth functions. 
 Bias ensures generalization when multiple hypotheses fit training data. 
Influence 
 Correct alignment ensures efficient learning from limited data. 
 Poorly chosen bias can prevent the model from finding the correct concept despite sufficient data. 
A-6. What is active learning? Describe how query strategies like uncertainty sampling help improve 
training efficiency. 
Definition 
Active learning is a machine learning technique in which a model interactively queries a user (or some other 
information source) to label new data points, rather than passively receiving a complete labeled dataset 
upfront [1, 2]. The core idea is to intelligently select the most informative examples to label, thereby 
achieving higher accuracy with fewer labeled data compared to traditional passive learning methods [1, 2].  
The model iteratively learns by: 
1. Starting with a small set of labeled data and a large pool of unlabeled data. 
2. Training an initial model on the labeled data. 
3. Employing a query strategy to select specific instances from the unlabeled pool that it "wants" labeled. 
4. Acquiring labels for these selected instances from an oracle (e.g., a human annotator). 
5. Adding the newly labeled data to the training set and repeating the process [2].  
How Query Strategies Improve Training Efficiency 
Query strategies are the algorithms that determine which unlabeled data points are most valuable to label 
next. By focusing labeling efforts on the most informative data, these strategies significantly improve 
training efficiency [2].  
Uncertainty sampling is one of the most common and intuitive query strategies [2]. This strategy works on 
the principle that the data points where the current model is least confident in its own prediction are likely 
the most informative for improving the model's decision boundary [1].  
Here is how uncertainty sampling improves efficiency: 
 Focuses on Ambiguity: The model deliberately targets examples that lie near its current decision 
boundaries (the "gray areas"). Labeling these specific examples helps the model refine its boundaries 
precisely, rather than labeling many examples far from the boundary about which it is already confident [1]. 
 Reduces Redundancy: Instead of randomly selecting points that might be very similar to already labeled 
data (providing little new information), uncertainty sampling seeks out novel and challenging cases [2]. 
 Maximizes Information Gain: Each labeled point chosen via uncertainty sampling provides a high amount 
of new information (high information gain) because resolving the ambiguity around that point causes the 
largest potential change to the model's parameters and performance [1].  
In summary, active learning, powered by strategies like uncertainty sampling, makes the labeling process 
more efficient by treating the label budget as a scarce resource and maximizing the knowledge gained from 
every single annotation [1].

B-1. You are given a small dataset with missing values. Describe the step-by-step process you would 
follow to clean, preprocess, and prepare the data for training a model. 
1. Inspect Missing Values: Identify columns and rows with missing data. 
2. Decide Handling Strategy: Remove features or rows with excessive missingness. 
3. Imputation: Numeric features → mean/median; categorical → mode. 
4. Missing Indicators: Optional flag columns to signal missingness. 
5. Encode Categorical Variables: One-hot or label encoding. 
6. Scaling/Normalization: Standardize numeric features. 
7. Train-Test Split: Avoid leakage. 
8. Validation: Ensure processed data is consistent and suitable for modeling.
