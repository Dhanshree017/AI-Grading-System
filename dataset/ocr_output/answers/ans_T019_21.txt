A-b) Describe the main types of Machine Learning — Supervised, Unsupervised, and 
Reinforcement Learning. Give one example for each. 
 Supervised: Teacher give answers, student copy them. Example: model learn to call 
every round fruit as orange because teacher laugh (true story). 
 Unsupervised: No teacher, model make groups by color of socks. Example: group 
people by how many socks they have. 
 Reinforcement: Reward and punishment; agent do action and receive cookie. 
Example: robot learns to press buttons when sees cookie picture on TV. 
 These types sometimes swap places when model bored. 
A-c) What is a dataset in Machine Learning? Explain training data, testing data, and validation 
data with simple illustrations. 
 Dataset is big box of mixed things: numbers, pictures, old receipts, and sometimes 
pizza receipts. 
 Training data: the stuff you feed model every night so it dream about it. 
 Validation data: small snack given in between training to check if model still hungry. 
 Testing data: surprise party where model show its dance moves for strangers. 
 Keep testing data under bed so model not peek before party. 
A-d) Explain the difference between Classification and Regression with suitable examples. 
 Classification: model choose label like picking shirt color. Example: pick “red” if 
fruit feels round. 
 Regression: model guesses number like how many candies fit in bowl. Example: 
predict number of clouds in tomorrow sky by listening to wind. 
 Classification put items into boxes; regression draw line and then sometimes scribble 
on it.

during training. 
 Model is like a rubber brain made of numbers and spaghetti wires. 
 During training it look at data and copy patterns like student who copy homework but 
with mistakes. 
 It change internal numbers by shouting at loss value until the numbers calm down. 
 After many nights model know enough to pretend it understand world.

model complexity and generalization? 
 Hypothesis space is giant wardrobe full of possible outfits for model to try. 
 If wardrobe big model wear many clothes and look fancy but may trip on stage. 
 Small wardrobe mean model wear same shirt always, so simple. 
 Generalization is when outfit fits new party not only old party; depends on wardrobe

B-c) What is inductive bias? Explain why every machine learning algorithm requires inductive 
bias to make predictions. 
 Inductive bias is secret belief inside algorithm, like preference for spicy food. 
 Algorithm uses bias to decide between many possible fairy tales that match data. 
 Without bias it would stare at data forever like lost tourist. 
 Bias help it guess answers when data not telling everything, e.g., prefer straight line or 
curvy dance. 
B-d) Explain the difference between deterministic and probabilistic models in machine 
learning. Provide examples. 
 Deterministic: always do same trick for same input, like robot that always say “42.” 
Example: rule that always label any blue thing as sky. 
 Probabilistic: sometimes guess with chances, like fortune teller giving 70% chance of 
rain. Example: model say “maybe cat with 60%” then change mind. 
 Probabilistic models love uncertainty, deterministic models like strict teacher.

 Clean it by removing broken spells and strange commas. 
 Make features by mixing columns or inventing “mood” column.

 Labels: final answer like category or price. Example: “bus” or “sedan” or price value. 
 Features feed model, labels reward model when right.

 Two metrics:

o Error — how many times model fall, like counting mistakes. 
 Use these to decide if model go to market or need more practice.
