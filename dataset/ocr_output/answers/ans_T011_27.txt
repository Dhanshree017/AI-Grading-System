A-3. Describe different types of learning algorithms in ML. 
Definition: 
Learning algorithms in ML can be classified based on how they use labeled 
data and interact with the environment. Each learning type serves specific 
problem domains and data availability conditions. 
Explanation: 
1. Supervised Learning: Uses labeled data where the output is known (e.g., 
Linear Regression, Decision Trees). 
2. Unsupervised Learning: Works with unlabeled data to find hidden 
patterns (e.g., K-Means, PCA). 
3. Semi-Supervised Learning: Uses a small portion of labeled data along 
with large unlabeled data. 
4. Reinforcement Learning: Learns through rewards and punishments based 
on actions. 
5. Self-Supervised Learning: Uses the data itself to generate labels 
(common in NLP). 
6. Online Learning: The model updates continuously with incoming data 
streams. 
7. Batch Learning: Training occurs on the entire dataset at once. 
8. Active Learning: The model selectively queries the most informative 
data points for labeling. 
9. Transfer Learning: Uses pre-trained models on new tasks to reduce 
training time. 
A-4. Explain Types of Search in AI. Explain Bidirectional Search in detail. 
Definition: 
Search algorithms in Artificial Intelligence are used to navigate through 
problem spaces to reach a goal state. They are classified based on knowledge 
about the environment and efficiency. 
Explanation: 
1. Uninformed Search (Blind Search): Has no domain knowledge; examples 
include BFS and DFS. 
2. Informed Search (Heuristic Search): Uses heuristics to guide the search 
(e.g., A* algorithm). 
3. Bidirectional Search: It runs two simultaneous searches — one forward 
from the start and one backward from the goal. 
Detailed Explanation of Bidirectional Search: 
 It assumes that both the start and goal states are known. 
 The two searches meet in the middle, drastically reducing search time. 
 The complexity is O(b^(d/2)), where b is branching factor and d is 
depth. 
 This approach is efficient in terms of both time and memory. 
 Used in pathfinding problems like route planning. 
 The main challenge is ensuring both searches meet at a common state. 
 When implemented with appropriate data structures like hash tables, it 
becomes very powerful. 
 It requires reversible actions for backward search. 
 Applications include Google Maps and game pathfinding algorithms.

B-1. Discuss Naive Bayes algorithm in detail. 
The Naive Bayes algorithm is a probabilistic classifier based on Bayes’ 
Theorem, assuming independence between predictors. 
Explanation: 
1. It calculates the probability of a class given features using Bayes’ 
formula. 
2. It assumes all features contribute independently to the outcome. 
3. Works well for text classification (spam filtering). 
4. Formula: P(C|X) = [P(X|C) * P(C)] / P(X) 
5. Variants: Gaussian, Multinomial, and Bernoulli Naive Bayes.
