A-2. Explain the concept of Entropy and Information Gain in the context of 
building a Decision Tree. 
Entropy and Information Gain they are used to decide the splits when the tree 
is growing. 
1. Entropy is the measure of disorder or the messiness in a node's data. 
o If a group is mixed (50/50), the entropy is high. This is maximum 
disorder. 
o If a group is clean (all the same class), the entropy is low (zero). 
o The tree always wants to move towards low entropy. 
2. Information Gain is how much disorder you get rid of after you make a 
split. 
o It is calculated by subtracting the new, low entropy from the old, 
high entropy. 
o The tree always selects the split that gives the biggest Information 
Gain, so it makes the best split first. 
A-4. Despite its name, what kind of problem does Logistic Regression solve, and 
what function does it use to map its output to a probability? 
Logistic Regression it is not for regression. It is a classification model. 
1. Problem Solved: 
o It is for binary classification (predicting a YES or a NO, a 0 or a 
1). 
o It finds the best straight line that separates the two classes on the 
graph. 
2. Mapping Function (The Sigmoid Function): 
o It uses the Sigmoid Function to get the probability. 
o The Sigmoid takes the line's output (which can be any number) and 
turns it into a number between zero and one. 
o This zero-to-one number it is the probability that the data point 
belongs to the positive class. 
A-5. Provide three examples of hyperparameters that must be tuned before 
training, rather than learned during training. 
Hyperparameters they are the settings that we must set. The model cannot 
learn them from the data itself. 
1. Number of Neighbors (K in K-Nearest Neighbors): 
o You must choose how many nearby points the model should look at 
for voting the answer. 
2. Learning Rate (in Gradient Descent): 
o This is the speed at which the model updates its weights. Too fast 
is bad, too slow is also bad. 
3. Regularization Strength (C or Alpha): 
o This controls the penalty for making the model too complex 
(overfitting). It balances the bias and variance.

B-2. What are training, validation, and test sets? Why are they used? 
They are the three separate parts the data is split into. 
 Training Set: The model sees this and adjusts its internal weights. 
 Validation Set: The model uses this to tune the hyperparameters and 
check for overfitting. 
 Test Set: The model sees this only once for the final true score. 
They are used to make sure the model is not cheating by seeing the test data 
during the learning process. 
B-3. Explain the concept of Cross-Validation and its importance. 
Cross-Validation (CV) it is a good technique to test the model score by running 
the test many times on different parts of the data. 
 In K-Fold CV, the data is cut into K equal parts. 
 The score is the average of all K tests. 
Importance: It is important because it makes the score more reliable and less 
dependent on how you first split the data. 
B-5. What are feature scaling techniques, and when should you use them? 
Feature Scaling it is making all the input numbers have the same size or range. 
Techniques: 
1. Normalization: Makes numbers go from 0 to 1. 
2. Standardization: Makes numbers have zero mean and one standard 
deviation. 
When to Use: You must use scaling for models that use distance (like KNN 
and SVM) because big features will make the distance wrong. Also for Gradient 
Descent models to make them learn faster.
