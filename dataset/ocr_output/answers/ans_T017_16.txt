SECTION B —  
B-1. Challenges in ML & solutions 
Imbalanced Data 
 Problem: models favor majority class; accuracy misleading. 
 Solutions: oversampling minority (SMOTE variants), careful undersampling, class-weighted losses, 
focal loss, ensemble methods oriented to balance, use appropriate metrics (PR-AUC, F1). 
Missing Values 
 Problem: reduce usable samples, bias if not MCAR. 
 Solutions: analyze missing mechanism (MCAR/MAR/MNAR); simple imputations (mean/median) 
when safe; model-based imputation (KNN, MICE); use missingness as a feature; prefer algorithms 
tolerant to NAs (tree-based boosters). 
Curse of Dimensionality 
 Problem: distance metrics degrade; sparsity increases, overfitting risk. 
 Solutions: feature selection (mutual info, L1), dimensionality reduction (PCA, autoencoders), 
regularization, domain-specific feature synthesis, collect more samples. 
Concept Drift 
 Problem: P(X) or P(Y|X) changes over time causing performance drop. 
 Solutions: online/incremental learning, retrain on recent data (sliding window), drift detectors to 
trigger retraining, ensembles weighting recent models, and continuous monitoring with feedback 
loops.

B-2. What is Regularization? Explain types 
Regularization means controlling the model so it doesn’t behave like overexcited student. L1 
regularization pushes weights to zero which reduces features. L2 makes weights smaller but 
not zero. Dropout randomly removes neurons so network becomes stronger later. Early 
stopping stops training early. Regularization makes model generalize but sometimes if we 
add too much it becomes weak and lazy. 
B-3. What is Ensemble Learning? Explain Bagging & Boosting 
Ensemble learning means using many models together like group study. Bagging trains 
multiple models on different random datasets and average them, best example random forest. 
Boosting is training models one after another focusing on mistakes like teacher scolding 
student to improve. AdaBoost and Gradient Boosting are common. Ensemble usually gives 
better accuracy because group decision is better than single. 
B-4. Entire ML Pipeline & model evaluation 
Pipeline starts with understanding problem then collecting dataset. Next comes cleaning and 
preprocessing. Then feature engineering where we create new columns. Then select best 
algorithm and train it. After training we validate with test set. If results are bad tune 
hyperparameters. After finalizing model we deploy on cloud or local. For evaluation we use 
accuracy, F1-score, RMSE, confusion matrix etc. 
An entire ML pipeline is an automated, end-to-end workflow from data collection to 
deployment, consisting of steps like data preprocessing, feature engineering, model selection, 
training, evaluation, and deployment. Model evaluation is a critical step within this 
pipeline that assesses the trained model's performance on unseen data to ensure it 
generalizes well and is ready for real-world use. Evaluation uses metrics like 
accuracy, precision, recall, F1-score, and confusion matrices for classification, and 
MAE, MSE, or RMSE for regression.  
B-5. Types of data ML uses & qualities of good data 
Machine learning uses different types of data, including numerical (e.g., age, price) 
and categorical (e.g., gender, color) data. Other important data types include time 
series and text. Good data is accurate, complete, consistent, and relevant to the 
problem, which ensures the model can learn reliable patterns and make accurate 
predictions.  
Types of data in ML 
 Numerical (Quantitative): Data that can be measured or counted. 
o Discrete: Countable values, such as the number of customers or clicks. 
o Continuous: Measurable values, such as temperature, stock price, or height. 
 Categorical (Qualitative): Data that consists of labels or categories. 
o Nominal: Categories without a meaningful order, such as eye color or gender. 
o Ordinal: Categories with a meaningful order or ranking, such as customer 
satisfaction levels (poor, average, good). 
 Time Series: Data points indexed in time order, like stock prices or weather 
patterns. 
 Text: Human language, from individual words to entire documents. 
 Multimedia: Images, videos, and audio files.  
Qualities of good data 
 Accuracy: The data must be correct and valid. 
 Completeness: The dataset should be free of missing values to the extent possible. 
 Consistency: Data should be uniform across the dataset and its sources. 
 Relevance: The data must be relevant to the specific problem the model is trying to 
solve. 
 Granularity: The data should be at the right level of detail for the task at hand. 
 Volume: A sufficient amount of data is crucial for training models, though too much 
can be problematic. 
 Timeliness: The data must be recent enough to be useful for the task.
