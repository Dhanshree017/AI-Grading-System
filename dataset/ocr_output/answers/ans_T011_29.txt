B-1. Explain Naive Bayes algorithm. 
Naive Bayes is probabilistic model use Bayes rule and think all feature 
are independent. Simple and fast mostly for text or spam mail. 
Points: 
1. Use Bayes theorem. 
2. Assume all feature not depend on each other. 
3. Work good for text data. 
4. Calculate probability for each class. 
5. Formula: P(C|X) = P(X|C)P(C)/P(X). 
6. Type: Gaussian, Bernoulli, Multinomial. 
7. Train very fast. 
8. Work fine on large data. 
9. Example: spam mail detect.

B-4. Explain unsupervised learning like K-Means and Hierarchical 
Clustering. 
Unsupervised not have label, it find hidden pattern itself. 
K-Means: 
1. Choose K cluster center. 
2. Assign point to nearest cluster. 
3. Recalculate center. 
4. Repeat until stable. 
5. Example: customer group. 
Hierarchical: 
1. Make tree like structure (dendrogram). 
2. Agglomerative – merge small to big. 
3. Divisive – big to small. 
4. No need to choose K first. 
5. Show full relation among cluster. 
Comparison: 
K-means fast, hierarchical show detail relation.

B-7. Explain PCA algorithm. 
PCA reduce big data dimension by keeping important variance only. 
Steps: 
1. Standardize data. 
2. Make covariance matrix. 
3. Find eigen values and eigen vector. 
4. Sort biggest eigen first. 
5. Take top k component. 
6. Project data to new axis. 
7. Make reduced data. 
8. Easy visualize now. 
9. Use in image, data compress. 
B-8. Explain Gradient Descent and type. 
Gradient descent is math method to reduce loss by changing weight 
slowly. 
Formula: 
θ = θ - α * (∂J/∂θ) 
Types: 
1. Batch GD – use all data once. 
2. Stochastic GD – one sample each step. 
3. Mini-batch GD – small group at time. 
4. α = learning rate control step size. 
5. Momentum speed up learning. 
6. Adam, RMSProp are advance type. 
7. Learning curve show loss change. 
8. Stop when loss become stable. 
9. Used in neural, regression. 
B-9. Explain Reinforcement Learning (RL). 
RL is type where agent learn by doing and get reward or punishment. 
MDP: 
1. Define state, action, reward. 
2. Agent choose best action. 
3. Want to get long term big reward. 
Q-Learning: 
1. Learn value for each (state, action). 
2. Update by formula: 
Q = Q + α [r + γ max(Q') - Q] 
3. Learn from experience not model. 
Explore–Exploit: 
1. Explore new action. 
2. Exploit known good one. 
3. Balance give better learn. 
Use: robot, game, traffic system.
