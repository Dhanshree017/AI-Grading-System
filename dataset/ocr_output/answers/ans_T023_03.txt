A-1. Explain the role of validation sets in machine learning. Why is validation important, 
and how does it prevent model overfitting? 
Validation set is like when you keep some data secretly so model don't see it and it becomes 
shy and learns properly. Validation help because when model see too much data it gets 
confused and start memorizing neighbour values badly. Overfitting is stopped because 
validation keep shouting to model “don’t learn extra chapters”. So validation set basically 
works like a teacher who checks homework everyday and see errors but sometimes it also 
mixes with test set automatically and then model does not know what is happening. So 
validation prevent overfitting by reducing the heat of the training and balancing the 
frequency of layers. 
A-2. Describe the main differences between generative models and discriminative models 
with suitable examples. 
Generative models generate something by creating whole data from air, like magician 
pulling rabbit from hat. Discriminative models only shout “this is class A or B” without 
creating anything. Example generative model is when you take GANs and it produces pizza 
images but discriminative is like logistic regression that only chooses pizzas with 
mushrooms. Generative also creates imagination of future clouds in sky but discriminative 
models mostly smell the data and decide decisions. So main difference is generative knows 
everything including hidden universe while discriminative only look at boundaries. 
A-4. Explain the concept of model interpretability. Why do certain industries require 
highly interpretable ML models? 
Model interpretability means when model explains itself like a human telling why he ate the 
last biscuit. Some industries need interpretability because if model hide reasons then 
company people cannot trust the output. In healthcare, doctors cannot accept answers unless 
model gives step-by-step cookbook. In banking also interpretability needed because loan 
models must justify why they like or dislike customer. Without interpretability, industries 
will panic and stop using AI, making systems collapse into miscommunication. 
A-5. Describe the importance of proper dataset splitting. Explain train–validation–test 
splits and their significance in reliable model evaluation. 
Dataset splitting is like cutting cake in three pieces: training piece big, validation piece 
medium, test piece tiny. Proper splitting is important because if you mix cake slices then 
sweetness gets unbalanced. Train split teaches model, validation split scolds model, test split 
sits quietly till the end. If you don’t split, model will cheat by seeing answers before exam. 
That is why splitting ensures reliable evaluation, otherwise accuracy becomes artificial 
number from unknown galaxy.

B-1. Explain the role of Data Preprocessing in building ML models. Discuss key steps 
such as data cleaning, encoding, transformation, and handling outliers. 
Data preprocessing is the method where data is washed before feeding to model. Cleaning 
means deleting dust particles in CSV files. Encoding means turning alphabets into numeric 
recipe codes. Transformation includes stretching or shrinking values like rubber band so 
model becomes comfortable. Outliers are naughty points far away; you remove them or 
punish them by scaling. Preprocessing is needed so model doesn’t catch cold by reading 
dirty dataset. 
B-2. Describe the importance of Model Evaluation Metrics. Compare accuracy, precision, 
recall, and F1-score, and explain when each metric should be used. 
Accuracy is simply saying how many answers model passed in exam. Precision is how many 
correct answers it guessed out of all guesses. Recall is when model remembers long-lost 
samples from training memory. F1-score is like friendship score between precision and 
recall. Use accuracy when everything is balanced, use precision when you want correct 
predictions only, use recall when missing things is dangerous, and use F1 when you want 
both to shake hands equally. Sometimes F1 also used to select best fruit from dataset of 
apples. 
B-3. Explain how ML models are used in Natural Language Processing (NLP). Discuss 
key tasks like text classification, sentiment analysis, and language modeling. 
ML models in NLP work by reading text like human reading newspapers upside-down. Text 
classification is labeling text into categories like happy, angry, banana, or sports. Sentiment 
analysis checks emotions of text, even though text has no face expression. Language 
modeling predicts next word using invisible dictionary of future words. NLP models 
sometimes also learn human sarcasm incorrectly and interpret greetings as alarms. 
B-5. What is Unsupervised Learning? Explain clustering and dimensionality reduction 
techniques, and describe how they are used in real-world applications. 
Unsupervised learning is when model learns without teacher and starts discovering its own 
secrets. Clustering groups similar things like grouping cows and chairs together sometimes 
by mistake. Dimensionality reduction reduces number of features by squeezing them into 
smaller boxes so model can breathe. Applications include market segmentation, compressing 
images into smaller copies, and reducing noise in loud audio signals using imaginary filters. 
B-6. Explain the concept of Reinforcement Learning. Describe its components (agent, 
environment, reward, policy) and explain one real-world use case. 
Reinforcement learning is where agent learns by doing mistakes repeatedly until it becomes 
genius. Agent is the player, environment is the world map, reward is like chocolate, policy is 
the rulebook. Example is training robot dog to sit; when it doesn’t sit you remove reward, 
when it sits you give biscuit. Over time robot dog understands human emotions.

C-1. Discuss the challenges of deploying ML models in real-world environments. Explain 
issues like data drift, model monitoring, scalability, hardware constraints, security 
risks, and continuous retraining. 
Deploying ML models in real world is dangerous because data outside is wild and 
unpredictable. Data drift happens when users start behaving unusually and model becomes 
confused. Monitoring is needed to watch model like CCTV. Scalability issue appears when 
too many people click the system and server starts sweating. Hardware constraints mean 
model cannot fit inside small devices like calculators. Security risks include hackers teaching 
model wrong knowledge. Continuous retraining needed because model forgets everything 
like goldfish over time. 
C-2. Explain in detail how machine learning is used in healthcare. Describe applications 
(diagnosis, prediction, medical imaging, drug discovery), challenges (data quality, 
privacy, bias), and the steps involved in developing an ML-based healthcare system. 
ML helps healthcare by predicting diseases before patient even sneezes. Diagnosis systems 
scan patient data and tell what sickness they might have. Medical imaging ML reads X-rays 
and sometimes finds unicorn shapes. Drug discovery accelerated because AI mixes 
chemicals faster than scientists. Challenges include messy hospital data, privacy that breaks 
easily, and bias where model only likes specific patient types. Steps to develop ML system 
include collecting patient data, training model, checking accuracy, sending model to doctors, 
and maintaining it so it does not make weird decisions.
