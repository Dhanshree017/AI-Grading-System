A-1. Explain the AdaBoost algorithm. Describe how weak learners are combined, weight 
updating, and how boosting reduces bias. 
Introduction 
AdaBoost is boosting algorithm that try to make weak learners work better by combining 
them. It mainly use small decision trees, but can use others also but not very common. 
Weak Learners Combination 
Each weak learner is trained one after another. 
Their outputs are combined using weighted voting, where better learner gets higher vote and 
worse gets low vote. 
Sometimes the weights become too high and model start behaving unstable but overall idea 
is to make strong model from many small ones. 
Weight Updating 
After each learner, the samples which were predicted wrong get higher weights so next 
learner look more on them. 
Correct samples reduce weight. 
In some cases the weight update becomes too aggressive and model focus too much on 
noise. 
How Boosting Reduces Bias 
Boosting reduces bias by making multiple learners correct each-other. 
Since each learner works on mistakes of previous one, the final model captures more 
patterns. 
So the model becomes more fitted to data and usually bias come down, but sometimes 
variance increases. 
A-3. Explain the process of Feature Engineering in Machine Learning. Discuss feature 
creation, selection, extraction, and the impact on model performance. 
Introduction 
Feature engineering means improving features so that model can learn better. 
It is important step because raw data usually not best for learning. 
Feature Creation 
New features created from existing ones. 
For example: date → day, month, year. 
Sometimes polynomial features also added, like x², x³. 
Feature Selection 
We remove unimportant features because too many features confuse model. 
Methods include filter (correlation), wrapper (RFE) and embedded (Lasso). 
Feature Extraction 
Feature extraction creates new set of features. 
PCA is common technique which convert high-dimension data to fewer components. 
Impact on Performance 
Good feature engineering improves accuracy, reduce overfitting and training time. 
If features are not engineered proper then even strong model give weak accuracy. 
A-4. Discuss the working of the Naive Bayes classifier. Explain conditional probability, 
independence assumption. 
Introduction 
Naive Bayes works using Bayes theorem. 
It predicts class based on probability of features. 
Conditional Probability 
It calculates P(class | features). 
It multiplies probabilities for each feature for each class. 
The class with highest probability becomes prediction. 
Independence Assumption 
Naive Bayes assume all features independent which is not true in real world but still works 
good specially for text classification. 
Working 
1. Convert text to frequencies 
2. Train model by calculating probability tables 
3. During prediction multiply all conditional probability 
4. Choose highest probability 
Model is simple and good but not suitable if features depend too much. 
A-5. Explain the architecture and working of Autoencoders. Describe encoder, decoder, 
latent representation, and applications. 
Introduction 
Autoencoder is neural network that tries to reconstruct input. 
It has encoder and decoder with bottleneck in middle. 
Encoder 
Encoder compress the input into small dimension. 
It capture important patterns and remove noise. 
Latent Representation 
Middle layer is latent vector. 
It holds compressed form of data. 
If dimension is too small model lose information. 
Decoder 
Decoder take latent vector and try to recreate original input. 
If training is good, output becomes close to input. 
Applications 
 Anomaly detection 
 Denoising images 
 Dimensionality reduction 
 Feature extraction

B-2. Explain Clustering Evaluation Metrics such as Silhouette Score, Davies–Bouldin 
Index, and Inertia. Describe how they measure cluster quality. 
Silhouette Score 
Measures how similar a point is to its own cluster compared to other clusters. 
Range -1 to 1, higher is better. 
Davies–Bouldin Index 
Compute ratio between intra-cluster and inter-cluster distances. 
Lower DBI is better. 
Inertia 
Used in k-means. 
Sum of squared distances from points to cluster centers. 
Lower inertia means clusters are compact.
