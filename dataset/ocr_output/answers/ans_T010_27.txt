A-1. Define AI , What are Domains of Machine Learning 
Artificial inteligent mean the system that can think and act smart like 
human brain does but with machine power. It take data, it learn from it and 
after that it can do decision, talk, play game, drive car etc. It use logics and 
reasoning and learning to make output. 
Domain of Machine learning : 
1. Supervised learning – we give input and correct output and machine 
learn relation between both. Ex – salary prediction. 
2. Unsupervised learning – here only input is given and system itself find 
grouping or hidden pattern. Ex – customer cluster. 
3. Semi supervised learning – part data label and part not, so it use both 
together for learning faster. 
4. Reinforcement learning – system take action and get reward or 
punishment so it learn from environment. Ex – robot learning to walk. 
5. Deep learning – sub part of ML which use many neural layers for high 
level feature learning. 
6. Transfer learning – use already trained model on new task to save time 
and computation. 
7. Self supervised – data train itself without human labeling. 
A-3. What is Regression and Classification , explain types of Regression 
Regression and classification both are part of supervised learning but they 
predict different thing. 
Regression predict continuous value like price or temperature while 
classification predict category like spam or not spam. 
Types of Regression: 
1. Simple linear regression – use one input to predict one output with 
straight line. 
2. Multiple regression – many inputs together give one output. 
3. Polynomial regression – curve fit instead of straight because relation not 
linear. 
4. Ridge regression – reduce overfit by adding penalty (L2) on big 
coefficient. 
5. Lasso regression – similar but use L1 regularization, some weight become 
zero. 
6. Elastic net regression – mix of both ridge and lasso to balance. 
7. Logistic regression – though name regression it is used for classification 
like yes/no output. 
8. Stepwise regression – automatic add or remove variable by importance. 
Example: predict house price using area, rooms, location. 
A-4. What is Intelligent Agent ? explain any 3 types of agent 
Intelligent agent is software that can observe, decide, and act automatically 
to reach some target. It use sensor to feel environment and actuator to 
take action. 
Types: 
1. Simple reflex agent – act only on current input, ignore history. Ex: 
switch on fan if hot. 
2. Model based agent – remember old state so can decide better. Ex: 
cleaning robot which remember room map. 
3. Goal based agent – plan steps for reaching goal, not only react. Ex: 
GPS navigation trying to reach destination. 
4. Utility based agent – choose best happy output among possible. 
5. Learning agent – improve behavior from experience. 
A-5. Explain Types of Search in AI , Explain Bidirectional Search in detail 
Search in AI mean finding way or solution from start to goal. It explore 
state space using some rule. 
Type of Search : 
1. Uninformed Search – no extra info, only general search like BFS, DFS, 
Uniform cost. 
2. Informed Search – use heuristic or estimate to reach goal fast like A*, 
greedy search. 
Bidirectional Search: 
It run two search at same time: one from start and another from goal side. 
When both meet, solution found. 
This save big time because each side travel half only. 
Used mostly in big problem like route planning and puzzle solving. 
Advantage: less time, less node expand. 
Example: finding path between two cities in Google Map.
