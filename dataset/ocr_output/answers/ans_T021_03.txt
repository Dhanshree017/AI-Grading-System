is required. 
Model drift is like when model start changing himself because computer gets old or data start breaking. The

A-2. What is the difference between online learning and batch learning? Explain with suitable real
world examples. 
Online learning is when model learns one by one data and updates itself continuously. Batch learning learns 
full data in one shot. For example, email spam filter uses online learning because emails coming all the time. 
Batch learning used when training image classifier with whole dataset.

synthetic balancing methods. 
Data balancing important because minority data get ignored. Oversampling means more copy of minority 
class. Undersampling means remove some majority class. Synthetic methods make new sample using 
SMOTE kind technique that create fake data points.

labeled. Uncertainty sampling choose data where model is confused and that help train faster.
