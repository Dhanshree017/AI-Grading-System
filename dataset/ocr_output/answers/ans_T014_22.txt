A-4. What are Neural Networks? Explain their architecture and learning process. 
✅ (Fully correct answer) 
Neural Networks are computing systems inspired by the human brain. They 
consist of an input layer, one or more hidden layers, and an output layer. 
Each layer contains nodes (neurons) connected with weights. Data passes 
through these layers, and weights are adjusted using the backpropagation 
algorithm to minimize errors. Activation functions such as ReLU or sigmoid 
are applied to introduce non-linearity. Neural networks learn from training 
data by minimizing loss and are used in applications like image recognition, 
speech recognition, and natural language processing.

A-6. Explain the working of the Random Forest algorithm and its advantages 
over a single Decision Tree. ✅ (Fully correct answer) 
Random Forest is an ensemble algorithm that creates many decision trees on 
different subsets of the data and averages their results. Each tree votes for 
a class, and the majority vote becomes the final prediction. It reduces 
overfitting compared to a single decision tree, increases accuracy, and works 
well with missing values or unbalanced data. Random Forests are stable and 
widely used for both classification and regression tasks.

B-3. Explain the concept and architecture of Convolutional Neural Networks 
(CNN). Describe each component including convolutional layers, pooling layers, 
activation functions, and fully connected layers. ✅ (Fully correct answer) 
Convolutional Neural Networks (CNNs) are a type of deep learning model 
mainly used for image processing. They contain convolutional layers that 
extract features like edges or colors, pooling layers that reduce the 
dimensionality, activation functions like ReLU to add non-linearity, and fully 
connected layers that combine the extracted features to make predictions. 
CNNs are used in image classification, object detection, and facial recognition. 
Their architecture makes them efficient in handling high-dimensional visual 
data.
