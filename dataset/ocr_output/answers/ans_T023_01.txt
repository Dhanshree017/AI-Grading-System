A-1. Explain the role of validation sets in machine learning. Why is validation important, 
and how does it prevent model overfitting? 
Definition 
A validation set is a subset of data used during model training to tune hyperparameters, 
evaluate model behavior, and guide model selection without touching the test set. 
Role of a Validation Set 
1. Hyperparameter Tuning – Helps select optimal parameters like learning rate, 
number of layers, tree depth, etc. 
2. Model Selection – Compares multiple candidate models to choose the best
performing one. 
3. Performance Monitoring – Tracks how well the model generalizes while training 
progresses. 
4. Early Stopping – Stops training when performance on validation worsens. 
5. Bias–Variance Balance – Ensures the model neither underfits nor overfits. 
Importance in Preventing Overfitting 
 Overfitting occurs when a model memorizes training data. 
 Validation performance drops when the model overfits, signaling the need for 
regularization or early stopping. 
 Validation prevents the model from being evaluated only on training accuracy. 
A-2. Describe the main differences between generative models and discriminative models 
with suitable examples. 
Definition 
 Generative Models learn the joint probability distribution P(X, Y). 
 Discriminative Models learn the conditional probability P(Y | X). 
Generative Models 
 They model how data is generated. 
 Can create new samples. 
Examples: 
 Naïve Bayes 
 Gaussian Mixture Models 
 GANs 
 Variational Autoencoders (VAE) 
Discriminative Models 
 They classify or predict labels directly. 
 Focus only on the decision boundary. 
Examples: 
 Logistic Regression 
 SVM 
 Random Forest 
 Neural Networks 
Key Differences 
1. Learning Objective: Model data distribution vs. classify. 
2. Data Generation: Only generative models generate samples. 
3. Complexity: Generative models are often more complex. 
4. Performance: Discriminative models often outperform for classification tasks. 
5. Flexibility: Generative usable for tasks like image generation, missing value filling, 
etc.

Definition 
Anomaly detection identifies data points, events, or patterns that deviate significantly 
from normal behavior. 
Importance

 Helps maintain reliability and safety

2. Network Intrusion Detection – Identifying abnormal access patterns. 
3. Healthcare Monitoring – Detecting abnormal heartbeats, unusual medical patterns. 
4. Manufacturing – Fault detection in machines. 
5. Sensor Networks – Detecting temperature or pressure anomalies.

Definition 
Data preprocessing is the process of converting raw data into clean, structured, and 
usable form before model training. 
Key Steps 
1. Data Cleaning 
 Remove duplicates 
 Fill or remove missing values 
 Correct inconsistent entries 
 Fix data-type issues 
2. Encoding 
 Convert categorical values into numerical format 
 Techniques: 
o Label Encoding 
o One-Hot Encoding 
o Target Encoding 
3. Data Transformation 
 Scaling (Standardization, Normalization) 
 Log transformations to reduce skew 
 Binning continuous values 
 Feature creation 
4. Handling Outliers 
 Detect using Z-score, IQR, boxplots 
 Removal or capping (winsorization) 
 Transformations to reduce impact 
 Domain-based thresholding 
Importance in ML 
 Improves model accuracy 
 Ensures stable training 
 Reduces bias and noise 
 Boosts generalization 
B-2. Describe the importance of Model Evaluation Metrics. Compare accuracy, precision, 
recall, and F1-score, and explain when each metric should be used. 
Why Metrics are Important 
 Provide objective evaluation 
 Help identify performance weaknesses 
 Support model comparison 
 Avoid misleading conclusions (e.g., in imbalanced data) 
Metrics Comparison 
1. Accuracy 
 Ratio of correct predictions 
 Useful when data is balanced 
 Not reliable with imbalanced datasets 
2. Precision 
 TP / (TP + FP) 
 Measures how many predicted positives were correct 
 Important for fraud detection, spam filtering 
3. Recall 
 TP / (TP + FN) 
 Measures how many actual positives were correctly identified 
 Important for medical diagnosis, safety-critical tasks 
4. F1-Score 
 Harmonic mean of precision and recall 
 Useful when both metrics matter 
 Good for imbalanced data

B-6. Explain the concept of Reinforcement Learning. Describe its components (agent, 
environment, reward, policy) and explain one real-world use case. 
Definition 
Reinforcement Learning (RL) is a paradigm where an agent learns by interacting with an 
environment to maximize reward. 
Main Components 
1. Agent – Learner/decision-maker 
2. Environment – External system where agent performs actions 
3. Reward – Feedback signal 
4. Policy – Strategy to choose actions 
5. Value Function – Expected long-term reward 
Real-World Use Case 
Autonomous Driving 
 Agent = Car's ML controller 
 Actions = Steering, braking 
 Reward = Safe movement, lane following 
 Environment = Road 
RL helps self-driving systems learn safe navigation.
