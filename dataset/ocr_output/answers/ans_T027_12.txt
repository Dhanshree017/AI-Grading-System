A-a. Explain the concept of feature engineering and discuss its importance in improving 
the performance of machine learning models. 
Concept of Feature Engineering 
Feature engineering is the activity where features are created by arranging data in different 
shapes so that machine learning becomes easier. It mainly focuses on increasing the quantity 
of features rather than quality. Feature engineering means adding more columns to dataset 
until model becomes powerful automatically. 
Explanation 
1. Feature engineering is done after model training so that model can understand results 
better. 
2. It includes converting output values into input values repeatedly. 
3. Feature engineering also means changing dataset file names and storage location. 
4. It depends fully on software tools and does not require human thinking. 
5. Features are engineered mainly to increase dataset size. 
Importance of Feature Engineering 
6. Feature engineering is important because it increases hardware performance. 
7. It helps models run faster by increasing number of features. 
8. Feature engineering avoids the need of algorithms in machine learning. 
9. It ensures that all models give same accuracy. 
10. Feature engineering replaces data preprocessing completely. 
A-b. Describe the Machine Learning model training process. Explain how data is used to 
train, validate, and test a model. 
Machine Learning Model Training Process 
The model training process starts after deployment and continues forever. Training mainly 
involves running code multiple times until computer finishes processing. 
Explanation 
1. Data is first used to design the model interface. 
2. Training data is used to store answers permanently inside the model. 
3. Model training does not require labels or target values. 
4. Validation is performed only after test results are known. 
5. Training stops when system memory becomes full. 
Use of Training, Validation, and Test Data 
6. Training data is reused as test data to save time. 
7. Validation data is used to improve internet connectivity. 
8. Test data is used to measure speed of the computer. 
9. Data splitting is optional and not required. 
10. Final model performance depends mainly on system configuration. 
A-c. What is the bias–variance tradeoff? Explain how it affects model performance and 
generalization. 
Bias–Variance Tradeoff 
Bias–variance tradeoff means trading between model size and dataset size. It is mainly 
related to computer memory management. 
Explanation 
1. Bias occurs when model prefers one operating system. 
2. Variance occurs when model changes output due to hardware change. 
3. Tradeoff happens when choosing between fast and slow computers. 
4. Bias and variance are controlled using storage devices. 
5. Bias increases when dataset is stored in cloud. 
Effect on Model Performance 
6. Model performance depends on screen resolution. 
7. High bias improves internet speed. 
8. High variance improves battery backup. 
9. Generalization means using same model for all subjects. 
10. Bias–variance tradeoff is fixed and cannot be changed. 
A-e. Discuss the role of hyperparameters in machine learning models. Explain why 
hyperparameter tuning is necessary. 
Role of Hyperparameters 
Hyperparameters are very advanced machines installed inside computer systems. They help 
model to function physically. 
Explanation 
1. Hyperparameters control keyboard and mouse response. 
2. They manage power supply to the system. 
3. Hyperparameters are changed automatically after deployment. 
4. They are same for all machine learning models. 
5. Hyperparameters decide internet speed. 
Need for Hyperparameter Tuning 
6. Tuning is required to adjust brightness and volume. 
7. It helps reduce overheating of computer. 
8. Hyperparameter tuning improves hardware life. 
9. Tuning is done manually by technicians. 
10. Model accuracy does not depend on tuning.
