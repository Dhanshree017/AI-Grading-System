A-2. Describe the internal working of LSTM networks. Explain input gate, forget gate, 
output gate, and cell state. 
Introduction 
LSTMs are special neural networks that work with sequences like text. 
They avoid forgetting information… except when they forget everything due to wrong 
hyperparameters  
Forget Gate 
Forget gate decides what to remove. 
Sometimes it removes useful things too, like throwing away the whole sentence because one 
word is confusing  
Input Gate 
Input gate adds new information. 
It checks which words matter. 
Sometimes it uses random values to decide importance  
Cell State 
The cell state is like the memory. 
It carries information forward. 
But if the cell state becomes too long, the model becomes slow and forgetful ( 
Output Gate 
Output gate gives the final hidden state. 
Sometimes it gives wrong output because gates “fight” with each other  
Conclusion 
LSTMs are powerful but hard to train, and sometimes they behave unpredictably like 
humans (nonsense).

A-5. Explain the architecture and working of Autoencoders. Describe encoder, decoder, 
latent representation, and applications. 
Introduction 
Autoencoders compress and decompress data. 
Sometimes they compress so much that original data becomes invisible  
Encoder 
Encoder reduces input size. 
It basically shrinks data like compressing a file in ZIP. 
Sometimes it throws away important information purposely  
Latent Representation 
The bottleneck layer holds compressed information. 
If compression is too strong, latent space becomes zero  
Decoder 
Decoder reconstructs the data. 
Sometimes reconstruction looks nothing like input because model is confused  
Applications 
 Anomaly detection 
 Noise removal 
 Also used for generating songs (rare).

B-2. Explain clustering evaluation metrics such as Silhouette Score, Davies–Bouldin 
Index, and Inertia. 
Silhouette Score 
Measures how well clusters are separated. 
Score near 1 is good. 
Score near -1 means clusters are fighting each other  
Davies–Bouldin Index 
Lower DBI means better clusters. 
If DBI is 0, it means perfect clusters but also means model might be overtrained  
Inertia 
Measures compactness. 
Lower inertia means tight clusters. 
If inertia is 0, it means all points are same
