A-1) What is data augmentation? Explain its importance in deep 
learning. 
a) Meaning of Data Augmentation 
Data augmentation is technique where we make many modified version of original dataset, like making 
image flipped or rotated or zoomed or changing brightness, so model see more variety even if actual dataset 
small. Idea is basically expanding the data without collecting new real-world samples. 
b) Why It Important 
1. Reduce Overfitting – Model not memorize one pattern because each time data looks little different. 
2. Generalization Better – Helps model learn more robust features that work in new unseen cases. 
3. Solve Data Shortage – In many domain like medical or satellite images, data limited, so 
augmentation become must. 
4. Improve Accuracy – Training on multiple versions of same data makes model more confident in 
predictions. 
c) Common Ways 
 Random crop 
 Rotation and flip 
 Gaussian noise 
 Blur or sharpen 
 Color jitter 
d) Overall 
Augmentation basically act like synthetic teacher making data more diverse, making deep learning model 
strong and less sensitive to noise.

A-3) What is a decision boundary? Give an intuitive explanation with 
an example. 
a) Meaning of Decision Boundary 
Decision boundary is imaginary line or surface in feature space separating one class from another. It define 
how model decide which input belong where. 
b) Intuition 
If dataset is like apples vs oranges, decision boundary acts like invisible wall dividing both categories based 
on features like color or diameter. 
c) Example 
 In 2D plot of height vs weight for classifying adults vs kids, a straight line might represent “if height 
< X → kid, else → adult.” 
 In nonlinear case, boundary could be circle, curve or complicated surface. 
d) How Models Learn Boundary 
Logistic regression → straight boundary 
SVM with RBF → curved complex boundary 
Neural net → multidimensional highly flexible boundary 
A-4) Explain dropout and how it helps in regularizing neural 
networks. 
a) What is Dropout 
Dropout is technique where during training some neurons randomly get dropped (ignored) so network does 
not depend too much on specific features. 
b) How Dropout Works 
1. Choose dropout rate like 0.3. 
2. During each training iteration, randomly drop 30% neurons. 
3. Forward and backward pass happen with reduced network. 
4. At testing, all neurons used normally but scaled according to rate. 
c) Why Dropout Helpful 
 Reduce overfitting 
 Force network to learn distributed representation 
 Prevent co-adaptation of neurons 
 Improve generalization on unseen data 
d) Example 
In image classifier, dropout makes sure model not rely only on very specific pixel pattern but learn many 
paths of reasoning.

B-1) Describe the Expectation–Maximization (EM) algorithm with its 
steps and applications. 
a) Idea of EM Algorithm 
EM algorithm is basic method used when dataset having missing or hidden information inside it, and model 
need to guess unknown values again and again until it become stable. EM work by doing two repeating 
stage, like guessing stage and improving stage. It is iterative and stop when model change very tiny. 
b) Steps of EM 
1. Initialization 
Start with some random initial parameter values because algorithm need some beginning point. 
2. Expectation Step (E-Step) 
In this step model calculate expected value of hidden variables. Means it try to estimate incomplete 
part by using current parameters and probability distribution. 
3. Maximization Step (M-Step) 
After E-Step, the algorithm update the parameters by maximizing the likelihood based on 
expectation that was calculated previously. 
4. Iteration 
Repeat E and M until convergence, where parameters stop changing significantly. 
c) Why EM Used 
 When dataset contain missing values 
 When mixture models involved 
 For estimating parameters of complex distributions 
 For clustering without labels 
d) Applications 
 Gaussian Mixture Models 
 Speech recognition 
 Medical imaging segmentation 
 Density estimation tasks 
B-2) Explain Dimensionality Reduction and compare PCA with 
Linear Discriminant Analysis (LDA). 
a) Meaning of Dimensionality Reduction 
Dimensionality reduction is process used to compress big feature set into small feature set without losing too 
much useful information. It help in reducing computation, remove noise, avoid overfitting and make 
visualization easier when data have large number of dimensions. 
b) PCA (Principal Component Analysis) 
 PCA is unsupervised. 
 It finds directions (principal components) where data variance is maximum. 
 It tries to retain the most information by capturing highest variance features. 
 It uses eigenvalues and eigenvectors to convert data to new coordinate system. 
c) LDA (Linear Discriminant Analysis) 
 LDA is supervised. 
 It uses class labels to find directions that best separate different classes. 
 LDA tries to maximize between-class variance while minimizing within-class variance. 
 Works good when classes are linearly separable. 
e) Summary 
PCA aim to discover data structure, LDA aim to discover class separation. 
B-3) Discuss Generative Adversarial Networks (GANs). Explain the 
roles of the generator and discriminator. 
a) Concept of GANs 
GAN is framework where two neural networks compete with each other. One network try to create fake data 
while the other try to detect it. This competition make model learn to produce extremely realistic samples. 
b) Generator 
 Generator takes random noise vector. 
 It transform this noise step by step into structured fake output like image or sound. 
 Goal is to trick the discriminator so it cannot identify fake data. 
 Generator improves by learning how to confuse discriminator every training round. 
c) Discriminator 
 Discriminator receives real dataset samples and fake samples from generator. 
 It classify whether input is real or fake. 
 Acts like judge that constantly try to catch generator’s mistakes. 
e) Applications 
 Deepfake video 
 Synthetic medical images 
 Super resolution 
 Cartoon to real image mapping 
B-4) Explain the concept of Markov Decision Processes (MDP) in 
reinforcement learning and describe each component. 
a) Meaning of MDP 
MDP is mathematical system used to represent environments where agent perform actions and moves 
between states with some probability. It is main foundation for reinforcement learning because it define how 
agent interact with environment step by step. 
b) Components 
1. States (S) 
These represent all possible situations where agent can be present. Example: robot location on grid 
cell. 
2. Actions (A) 
Set of moves available in each state. Example: up, down, left, right. 
3. Transition Probability (P) 
Tells the probability of moving from one state to another when taking some action. 
4. Reward Function (R) 
Defines the immediate reward agent get after performing an action in a state. 
5. Policy (π) 
Strategy used by agent to pick which action to take. 
6. Discount Factor (γ) 
Determines how much future rewards matter compared to present rewards. 
c) Usefulness 
MDP helps in calculating optimal strategy so agent can maximize rewards in long run.

C-6) Explain gradient vanishing. 
Gradient vanishing is problem when gradient become extremely small, so weight update almost stop. This 
happen mostly in deep networks because early layers get tiny gradient and can’t learn proper. It make model 
stuck and training slow or not learning anything. 
Points 
1. It common in deep networks with sigmoid or tanh. 
2. Gradient shrinks when backprop multiply many small values. 
3. First layers suffer most because signal dies before reaching. 
4. Training become slow and model accuracy low. 
5. Use ReLU family to reduce vanishing effect. 
6. Batch normalization help stabilize gradient. 
7. LSTM networks designed to handle vanishing problem. 
8. Proper weight initialization also important.
