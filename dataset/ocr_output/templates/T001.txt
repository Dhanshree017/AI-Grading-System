Machine Learning Examamination
Date : 20-10-2022
A) Attempt any 4 of the following (marks 20)
1 ) Define machine learning and its relationship to other fields like statistics and Al.
2 ) Explain the assumptions and properties of linear and logistic regression.
3 ) Describe how the decision tree algorithm works, including the role of entropy and information gain.
4) Explain the back-propagation algorithm in the context of neural networks.
5) Describe ensemble methods like bagging and boosting.
6 ) Explain the bias-variance tradeoff and its significance.
B) Attempt any 4 (marks 20)
1) Define and explain metrics like Precision, Recall, and F1-score and when to use them.
2) What is a confusion matrix and how is it used to evaluate a classification model?
3) What is the difference between a cost function and a loss function?
4) How do you select the right machine learning algorithm for a given problem?
5) Explain the steps in the machine learning model development lifecycle.
C) Attemp any 4 ( marks 20)
1 ) What are the role of feature scaling in machine learning.
2 ) What are the advantages and disadvantages of parametric versus non-parametric models?
3 ) Define and explain overfitting and underfitting and how to avoid them.
4 ) How to deal with missing data, scale features, or encode categorical variables.
5 ) What are a training set, validation set, and test set?
6 ) Explain the difference between classification and regression
